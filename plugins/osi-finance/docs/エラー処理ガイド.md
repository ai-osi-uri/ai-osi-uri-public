# OSI Finance — エラー処理ガイド（共通）

各 keiri スキル・osi-finance-setup が**実行中に詰まりやすいポイント**と、その回避・復旧手順を1枚に集約する。
各スキルの SKILL.md 末尾「## エラー処理」節からここを参照する（正本＝このファイル）。

> 大原則：**詰まったら止めて人に報告する。**推測で送金・台帳確定・上書きをしない。
> 機微値（口座番号・登録番号・実在支払先名）はエラー報告にもエコーしない。

---

## 1. 大容量PDF・xlsx の Drive 格納が失敗する

**症状**：Drive コネクタからの直アップロード／ダウンロードが、容量の大きい契約PDF・請求書PDF・
台帳xlsx でタイムアウト・途中で失敗する。クラウド同期 repo 上で in-place 編集すると
`.fuse_hidden*` が残り `rm` が効かないことがある。

**対処（推奨：ローカル同期フォルダ経由）**

1. 対象ファイルを Google Drive の**デスクトップ版ローカル同期フォルダ**に**コピー**して配置する
   （コネクタ直アップロードではなく、OSの同期に上げさせる）。大容量はこちらが確実。
2. 配置後、ファイルが Drive 側で開けること（xlsx は既定シートが揃っていること）を必ず確認する。
3. repo 内ファイルを差し替える場合は **in-place 編集を避け、新規 Write で置き換える**
   （`.fuse_hidden*` 残り対策。`.fuse_hidden*` は `.gitignore` 済み）。
4. それでも失敗するときは、ファイルパスと容量を添えて人に「手動配置」を依頼し、処理を止める。

**やってはいけないこと**：失敗を握りつぶして「配置済み」と報告する／既存の台帳・契約PDFを上書きする。

## 2. メール添付（受領請求書PDF）が取得できない

**症状**：受領請求書の添付PDFをダウンロードしようとして取得できない／空で返る。

**原因と対処**

- **標準の Gmail コネクタでは添付の取得ができない。**添付起点の AP 運用（keiri-payment-intake /
  keiri-payment-detect）には **Superhuman が必須**。Superhuman の `get_attachment` で取得する。
- Superhuman 未接続なら、その旨を報告し、(a) Superhuman を接続するか、(b) 該当PDFを
  **Drive 手置き**（受領請求書フォルダ）に置いてもらう、の二択を案内して止める。
- Gmail は契約・請求メールの**検索・本文確認**には使える（添付取得だけが不可）。

## 3. 会計SaaS（MoneyForward）の対象事業者・期間ズレ

**症状**：複数事業者が見える／取得期間がずれて数字が合わない。

**対処**

- 処理前に `mfc_ca_currentOffice` 等で**対象事業者を社名で確認**する（取り違えは事故）。
- レポート系（試算表・PL/BS）は会計年度開始日〜本日で取り、`keiri-settings` の会計年度開始月に合わせる。
- ページング系は必要件数まで繰り返し取得する（1回で取り切れない前提）。
- 不一致が出たら確定せず、差分を一覧化して人に報告する。

---

## 4. `keiri-settings.md`（実値版）が無い

**症状**：組織固有値（社名・採番・Drive ルート・台帳名・支払先マッピング等）が読めない。

**対処**

- まず `config/keiri-settings.md`（実値版・gitignore対象）を探す。無ければ
  `config/keiri-settings.example.md` を雛形に**作成を案内**する（または `osi-finance-setup` を案内）。
- 機微値はチャットに貼らせず、ユーザーに設定ファイルへ直接書いてもらう。
- 設定が埋まるまで、その値に依存する処理（採番・格納先確定など）は止める。

---

## 5. 台帳の行・列が想定と違う／読めない

**症状**：シート名・列が `ledger-schema.md` と違う、行が読み取れない。

**対処**

- 列定義は `keiri-mf-sync/references/ledger-schema.md` を正とし、差異を一覧化して人に確認する。
- 読めない値は**推測せず「要確認」**にする。台帳の自動確定・自動補正はしない。
- 同一キー（請求書ID＝支払先ID+対象月+請求書番号 等）の重複は二重起票防止のためスキップする。

---

## 6. 共通の安全フォールバック

- **送金しない／台帳を自動確定しない。**起票・更新は案として提示し、人の確認後に反映。
- コネクタ未接続・権限エラーは、どのコネクタが必要か（MoneyForward／Google Drive＋ローカル同期／
  Gmail or Superhuman）を明示して止める。
- 失敗は握りつぶさず、**何が・どこで・なぜ詰まったか**と次アクションを添えて報告する。
