# OSI Finance 導入手順書

> 判断の分担・既存データの移行・受け入れ判定・切り戻しは [`導入マニュアル.md`](./導入マニュアル.md) にあります。本番導入ではそちらも読んでください。

OSI Finance は、請求書の発行・受け取った請求書の支払準備・会計との突き合わせを Claude（Cowork）に任せるための道具です。
この手順書は **はじめて自社に入れる方** のためのものです。プログラミングの知識は要りません。

**基本は、Cowork に話しかけるだけです。**

> 「**OSI Finance を入れたい**」

AI が、いまどこまで進んでいるかを自分で確かめ、残りを一緒に進めます。
途中であなたにお願いするのは次の3つだけです。

1. ご自身でログインする
2. 「同意」「許可」「発行」のボタンを押す
3. 鍵（API の値）をコピーして、指定の場所に貼る

それ以外（画面まで行く、置き場を用意する、貼れたかを確かめる、記録する）は AI がやります。
途中で会話が切れても、もう一度「OSI Finance を入れたい」と言えば続きから始まります。

> **安全設計**
> - お金は動かしません。振込は必ず人がネットバンキングで行います
> - 台帳を勝手に確定しません。AI は案を出し、確定するのは人です
> - データはお客様の Google Drive とマネーフォワードにだけ置かれます。提供元のサーバーにはありません

## 事前に用意するもの

| サービス | 必須／任意 | 用途 |
|---|---|---|
| Claude（Team プラン） | 必須 | AI 本体（Cowork）。組織へのプラグイン配布に必要 |
| マネーフォワード クラウド会計＋クラウド請求書 | 必須 | 会計の正本・請求書の発行 |
| Google Workspace（共有ドライブ推奨） | 必須 | 台帳・契約書・証憑の保管 |
| Google Drive デスクトップアプリ | 必須 | 大きなファイルを安定して保存する |
| Superhuman | 条件付き | メール添付の請求書を自動で取り込む場合のみ |
| DocuSign | 任意 | 自社から送った契約の情報補完 |

**導入キット**（ツールポータルからダウンロード）
`01_osi-finance-plugin.zip`（プラグイン本体）／`02_AI-OSI-URI-Finance.mcpb`（デスクトップ拡張）／本手順書
ポータルの URL は提供元からの案内に書いてあります。キットの中に鍵やお客様の情報は入っていません。

全体の目安は約2時間。第1部は管理者、第2部・第3部は経理のご担当者が行います（同じ方でも構いません）。

---

## 第1部　会社の準備（管理者・約30分）

### 1-1. 契約と招待

Claude の Team プランを契約し、経理担当者を招待します。担当者の PC に Claude デスクトップアプリを入れてもらいます。

### 1-2. プラグインの登録

Cowork に「OSI Finance を入れたい」と話しかけると、AI が Chrome で組織設定のプラグイン登録画面まで進みます。
あなたがするのは、キットの `01_osi-finance-plugin.zip` を選んでアップロードすることだけです。
配布方法は「Installed by default（既定でインストール）」を選びます。対象メンバー全員に自動で配られます。

### 1-3. 運用モードを決める

- **編集可**（通常）：請求書の下書き・台帳の起票案・会計登録（いずれも人の確認つき）まで任せる
- **参照専用**：AI は読み取りと報告だけ。経営者・税理士の閲覧用や、お試し期間向け

迷ったら「まず参照専用で2週間、慣れたら編集可」で構いません。あとから変えられます。

---

## 第2部　経理担当者の PC の準備（担当者・約30〜60分）

### 2-1. デスクトップ拡張

キットの `02_AI-OSI-URI-Finance.mcpb` をダブルクリックし、インストールを許可します。
入ったかどうかは AI が確かめます。

### 2-2. 各サービスの接続

Claude の設定 → コネクタから、AI が案内する順に接続します。あなたがするのはログインと許可のボタンだけです。

- マネーフォワード クラウド会計
- Google Drive（＋ Google Drive デスクトップアプリ）
- Gmail または Superhuman（メール添付の請求書を自動で取り込むなら Superhuman）
- DocuSign（任意）

### 2-3. マネーフォワード クラウド請求書の API 接続（鍵）

請求書の発行と台帳の読み書きには、もうひと手間の接続が要ります。手順を覚える必要はありません。

> 「**OSI Finance の MF 連携をして**」

AI が Chrome で、アプリ登録 → 認可 → 動作確認まで一緒に進めます。
アプリはお客様ご自身のマネーフォワードのアカウントで登録します（鍵もデータもお客様の中で完結し、提供元は持ちません）。
あなたに渡されるのは次の3行だけです。

```
【何の鍵か】請求書の発行と台帳の読み書きのため（書き込み権限）
ここからコピー：（開いている画面のどこを押すと値が出るか）
ここに貼る：（用意してある拡張の設定欄）
```

鍵の値はチャットに貼らないでください。AI は値を見ずに、つながったことだけを確かめます。

## 第3部　初期設定（担当者＋Cowork・約60分）

> 「**OSI Finance を導入して**」

AI が対話で、設定ファイルの作成 → Drive のフォルダ作成 → 台帳（Excel）の配置 → 接続の確認 →
毎日・毎月の自動チェックの登録 → 動作確認 → **導入完了レポート** まで進めます。

### 手元に用意しておくもの

- 会社名（請求書の発行者名義）・インボイス登録番号（T＋13桁）・本店住所
- 入金用の銀行口座（銀行・支店・種別・番号・名義）
- 請求書番号の付け方（決まっていなければ既定の INV-YYYY-MM-連番）
- 台帳を置くフォルダ（PC 上のフォルダを1つ。Google Drive の同期フォルダの中で構いません）
- 第1部で決めた運用モード

口座番号などの大事な値は、チャットに残さず設定ファイルに書かれます。

### この部であなたがすること

- 台帳フォルダの場所を、拡張の設定に入れる（AI が画面まで案内します）。
  入れたら **Claude Desktop を完全に終了して開き直してください**（Mac は ⌘Q、Windows はトレイのアイコンから終了）。
  閉じ直さないと設定が読まれません
- Drive の共有ボタンを押す（経理担当＝編集、AI の実行主体＝編集、税理士など＝閲覧。組織全体には共有しない）
- 自動チェックの登録後に一度「Run now（今すぐ実行）」を押して、接続の許可を先に済ませる

## 完了の確認（約15分）

最後に出る **導入完了レポート**（9項目の OK／要対応）を見て、「要対応」を上から片づけます。
AI が次にやることを添えて示します。税理士への確認など、人の判断が要るものはそのまま残して構いません。

導入が済んだら、経理に関わる全員で [`運用ルール.md`](./運用ルール.md) を読んでください。次の3つは守らないと壊れます。

- 台帳に書き込むのは常に1人。見るだけの人は「参照専用」にする
- Excel で台帳を開いたままにしない（開いている間は書き込みが拒否されます）
- 「下書き済」で止めない。送ったら「請求済」に進める

## 導入後の使い方（話しかけるだけ）

- 「契約を取り込んで」→ 契約書から毎月の請求予定を作る
- 「今月の請求書を作って」→ 請求書 PDF とメール下書きを用意する
- 「この請求書、払って」→ 受け取った請求書を読み取り、支払予定を下書きする（送金はしません）
- 「払い忘れがないか確認して」→ 未処理の請求書を一覧にする
- 「今月の経理を締めて」→ 月次クローズを順に進める
- 「会計ダッシュボードを出して」→ 請求・支払・経費を1枚で見る

## 困ったとき

まず Cowork に「**OSI Finance の導入がどこまで終わっているか見て**」と話しかけてください。状態を調べて、残りを案内します。

- 台帳が見つからないと言われる → 拡張の設定の台帳フォルダを確認（前後に引用符が入っていると読めません）。台帳は xlsx のまま置き、Google スプレッドシートに変換しないでください
- メール添付の請求書が取り込めない → Superhuman の接続が必要です（標準の Gmail では添付を取れません）
- 会計データが見えない → マネーフォワードの「データ連携 ＞ 登録済一覧」で銀行・カードの連携状況を確認
- 設定をやり直したい → 「OSI Finance の設定をやり直したい」
- 運用モードを変えたい → 「運用モードを編集可に変えたい」（Drive 共有と MF 接続の権限もあわせて変わります）

> 会計・税務の最終判断はお客様（必要に応じて顧問税理士）にてお願いします。本ツールは判断の準備と作業の下書きまでを担当します。
