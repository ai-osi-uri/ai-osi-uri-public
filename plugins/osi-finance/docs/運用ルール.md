# OSI Finance 運用ルール

台帳をローカルの Excel で持ち、複数人で使うための決めごと。導入が済んだら、経理に関わる全員がこれだけ読めばよい。

## 1. 台帳はどこにあるか

拡張の設定で指定したフォルダ（例 `06.会計`）に、Excel が3つ置いてある。

```
請求管理台帳.xlsx   契約・請求（AR）
支払管理台帳.xlsx   支払先・支払（AP）・経費・源泉
仕訳台帳.xlsx       仕訳・勘定科目・月次サマリ
コンソールを開く.html  ← 画面を開くとき、これをダブルクリック
```

Google Drive などの同期フォルダに置いてあれば、他のメンバーにも同じファイルが見える。

## 2. 書き手は1人

**これが一番大事なルール。**

同期フォルダは同時編集を解決しない。2人が同時に書くと「競合コピー」が生まれ、どちらかの更新が消える。ファイル名に相手の名前が付いた複製が増えていたら、それが起きたサイン。

なので、**台帳に書き込むのは常に1人**に決める。他のメンバーは見るだけにする。

見る専門の人には、拡張の設定で **運用モード＝`参照専用`** を入れてもらう。コンソールから更新ボタンが消え、チャット側から書き込もうとしても拒否される。うっかり書いてしまう事故が起きなくなる。

## 3. Excel で台帳を開いたままにしない

誰かが Excel で台帳を開いていると、拡張は書き込みを拒否する（ロックファイルを見ている）。

```
台帳が Excel で開かれています（請求管理台帳.xlsx）。閉じてから再実行してください
```

このメッセージが出たら、開いている人に閉じてもらう。同期フォルダの場合、**他の人が開いていても自分の環境からロックが見える**ので、自分は開いていないのに出ることがある。

Excel で直接編集するのは避けて、コンソールかチャットから触るほうが安全。

## 4. 画面（コンソール）の開き方

台帳フォルダの **「コンソールを開く.html」をダブルクリック**するのが一番早い。ブラウザで開いたら、ブックマークしておくとよい。

見失ったら、Cowork で「コンソールを開きたい」と言えば URL が返る。

**Claude Desktop を起動している間しか開けない。** ブックマークが繋がらないときは、まずそこを疑う。

## 5. コンソールとチャットの使い分け

**コンソール**は、見ることと、ステータスを直すこと。契約・請求・支払・支払実績・経費・仕訳・各種マスタが一覧できる。請求を「請求済」にする、支払を「支払済」にする、といった状態の更新はここから。

**チャット**は、作ることと、外に出すこと。請求書 PDF が届いたら Cowork にドロップして起票、契約書から請求スケジュールを展開、仕訳の生成、MF との突合、DocuSign 送付。

コンソールの「DocuSignで発送を依頼」のようなボタンは、その場では実行せず**依頼として積むだけ**。実際に送るのはチャット側で、人の目が一度入る。溜まった依頼は「溜まっている依頼を処理して」で処理できる。

## 6. バックアップ

台帳に書き込むたび、書く直前の状態が自動でバックアップされる。保存先は `~/.local/share/ai-osi-uri/backup/`（同期フォルダの外）。既定で10世代。

**同期フォルダの外に置いてあるのは意図的。** 台帳の隣に置くと、書き込みのたびに同期が走って鬱陶しいため。

間違えて上書きしたときは、ここから戻せる。

## 7. MoneyForward との関係

**請求書の発行**は MF クラウド請求書が担う（採番・適格請求書フォーマット・PDF）。台帳は番号と状態を持つ正本。

**会計への計上**は MF クラウド会計。台帳と突合して計上漏れを検出する。

どちらも任意。使わないなら台帳だけで完結する。

MF の接続が切れたら、Cowork で「MF を接続して」と言えばリンクが返る。開いて許可を押すだけ。権限に「書き込み」が含まれることを確認すること（「参照」だけだと請求書を発行できない）。

## 8. やらないこと

**送金しない。** 振込は必ず人がネットバンキングで行う。台帳は「いくら払う予定か」「払ったか」を記録するだけ。

**台帳の状態を勝手に確定しない。** 請求済・入金済・支払済への遷移は、人のボタン操作か、銀行明細で裏取りできた場合に限る。スキルが推測で進めることはない。

**ステータスを勝手に戻さない。** 差し戻し（入金済 → 未請求 など）は人の操作のみ。

## 9. 困ったときの見分け方

| 症状 | 見るところ |
| --- | --- |
| コンソールが開かない | Claude Desktop が起動しているか。「コンソールを開く.html」から開き直す |
| 台帳未接続と出る | 拡張の設定の台帳フォルダのパス。前後に引用符が入っていないか |
| 書き込みが拒否される | Excel で台帳を開いていないか。運用モードが参照専用になっていないか |
| 「読み取り後に台帳が変更されています」 | 誰かが同時に書いた。コンソールを再読込してやり直す |
| 請求書の発行が 403 | MF の権限が読み取りのみ。「MF を接続して」で write を含めて再認可する |
| 競合コピーが増えている | 書き手が複数になっている。§2 を決め直す |
