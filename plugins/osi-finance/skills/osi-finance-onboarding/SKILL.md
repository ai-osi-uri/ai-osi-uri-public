# osi-finance-onboarding（OSI Finance を話しかけるだけで導入する）

## 原則

**人にしかできないことだけを人に残し、それ以外を全部やる。**

人にしかできないことは3つ：本人としてログインする／発行・同意・許可のボタンを押す／鍵の値を
コピーして貼る（値は Claude を通さない）。
「○○の画面で設定してください」と文章で説明して止まるのは、仕事を人に投げ返している状態なので禁止。
画面までは Claude in Chrome で連れて行き、置き場は先に整え、貼れたことは値を見ずに確かめる。

**安全原則（全 osi-finance スキルと共通）**：送金しない。台帳を自動確定しない。
機微値（登録番号・口座番号・鍵）はチャットに貼らせず、設定ファイルか各サービスの画面にだけ置く。

## 全体像（3部＋確認）

| 部 | 誰が | 何をする | 目安 |
|---|---|---|---|
| 第1部 会社の準備 | 管理者 | Claude Team の契約とメンバー招待／プラグインの組織登録／運用モードの決定 | 30分 |
| 第2部 担当者の PC | 経理担当 | デスクトップ拡張／各サービスの接続／MF 請求書 API の接続（鍵） | 30〜60分 |
| 第3部 初期設定 | 経理担当＋Cowork | `osi-finance-setup`（設定・フォルダ・台帳・確認・スケジュール・スモーク・完了レポート） | 60分 |
| 完了の確認 | 経理担当 | 導入完了レポートの「要対応」を潰す／運用ルールの共有 | 15分 |

相手は管理者と担当者が同じ人のことも多い。**最初に「あなたは管理者ですか、経理のご担当ですか、両方ですか」を1問だけ聞き**、
関係ない部は飛ばす。

## 手順

### 0. 今どこまで進んでいるかを自分で確かめる（毎回）

話しかけられたら、まず状態を調べて「残り」だけを進める。人に「どこまでやりましたか」と聞かない。

| 確認すること | 調べ方 | 未了なら |
|---|---|---|
| プラグインが入っているか | この会話で `osi-finance-*` スキルが呼べるか（呼べているなら入っている） | 第1部 1-2 |
| 拡張（AI OSI URI Finance）が入っているか | `health_check` を呼ぶ。ツールが無ければ未導入 | 第2部 2-1 |
| 台帳フォルダが設定されているか | `sheets_list_tabs` が台帳のパスを返すか | 第3部 3-1 |
| MF 請求書 API がつながっているか | `health_check` の `moneyforward_invoice` | 第2部 2-3 |
| 各コネクタ（MF会計／Drive／Gmail or Superhuman／DocuSign） | それぞれ read 系を1回（`currentOffice`、ファイル一覧、スレッド検索） | 第2部 2-2 |
| 設定ファイル `osi-finance-settings.md` があるか | 経理フォルダ（`{{paths.finance}}/`）直下を読む（旧版の `_shared/`・`config/` にあれば後方互換で読み、移すよう案内） | 第3部 |
| 導入完了レポートがあるか | 台帳ルート直下を探す | 完了の確認 |

結果を「済／未」の一覧で1回だけ示し、未のうち最初の項目から始める。

### 第1部 会社の準備（管理者）

**1-1 契約と招待**：Claude Team の契約、経理担当の招待、担当 PC への Claude デスクトップアプリ。
ここは人の決断と契約なので、必要な情報（プラン名・招待の画面の場所）を添えて渡す。

**1-2 プラグインの組織登録**：Claude in Chrome で **Organization settings → Plugins → Add plugins → Upload a file**
の画面まで進め、キットの `01_osi-finance-plugin.zip` を選ぶところで止めて渡す。
「Installed by default」を選ぶ理由（対象メンバー全員に自動配布）を1行で添える。
アップロード後、この会話で `osi-finance-setup` が呼べるようになっているかで確かめる（再起動が要ることがある）。

**1-3 運用モードの決定**：編集可（既定）／参照専用（読み取りと報告のみ）。
迷ったら「まず参照専用で2週間、慣れたら編集可」を提案する。決めた値は第3部で `OPERATION_MODE` に入る。

### 第2部 担当者の PC の準備（経理担当）

**2-1 デスクトップ拡張**：キットの `02_AI-OSI-URI-Finance.mcpb` を開く（ダブルクリック）ところだけ人。
入ったかは `health_check` が返るかで確かめる。拡張の設定「台帳フォルダ【必須】」はまだ空でよい（第3部で入れる）。

**2-2 各サービスの接続**：Claude の設定 → コネクタ。必要なものだけを、上から順に1つずつ：
- MF クラウド会計（会計との突合。`ACCOUNTING_SYNC=mf` の組織のみ）
- Google Drive（台帳を同期フォルダに置く場合）＋ Google Drive デスクトップアプリ
- Gmail または Superhuman（**メール添付の請求書を自動で取り込むなら Superhuman**。標準 Gmail は添付を取れない）
- DocuSign（任意）
各接続は「ログインと許可のボタン」だけ人。つながったかは read 系を1回呼んで確かめる。

**2-3 MF クラウド請求書の API 接続（鍵）**：`osi-finance-connect` に委ねる（Claude in Chrome で
アプリ登録 → 認可 → refresh_token → 拡張に貼る → `health_check`）。受け渡しの型は
`credential-handoff` の3行（【何の鍵か】／ここからコピー／ここに貼る）。
運用モードが参照専用なら read スコープで通す。

### 第3部 初期設定

`osi-finance-setup` を呼ぶ。その前に、聞かれる値を一覧で先に示しておく（会社名・登録番号・
本店住所・入金口座・請求書番号の付け方・台帳を置くフォルダの絶対パス・運用モード）。
**値はチャットに貼らせず、setup が設定ファイルに書く。**

setup の中で人に残るのは：台帳フォルダのパスを拡張の設定に入れる（Claude Desktop の完全終了と再起動が要る）、
Drive の共有ボタン、スケジュール登録後の「Run now」。それぞれ画面まで連れて行く。

### 完了の確認

導入完了レポート（B表9項目）の「要対応」を上から潰す。潰し方が人の判断（税理士確認・
フォルダ体系の選択）なら、そのまま人に渡す。
最後に `docs/運用ルール.md` の3つ（書き手は1人／Excel で開いたままにしない／「下書き済」で止めない）を
そのままの言葉で伝えて終える。

## 導入キット（提供元が渡すもの）

| ファイル | 中身 | 使う場面 |
|---|---|---|
| `01_osi-finance-plugin.zip` | このプラグイン本体 | 第1部 1-2 |
| `02_AI-OSI-URI-Finance.mcpb` | デスクトップ拡張 | 第2部 2-1 |
| `docs/導入手順書.md`（または .docx） | 人が読む版の手順 | 全体 |

キットは **ツールポータル** からダウンロードする（更新も1か所）。ポータルの URL は相手に渡す案内に書く。
**キットの中に鍵や実値は入れない**（`osi-finance-settings.md` は example だけを同梱）。

## 配布の方針（決定済み）

- **MF クラウド請求書の OAuth アプリは会社ごとに登録する。** 相手の MF アカウントで相手が自分のアプリを作り、
  鍵もデータも相手の中で完結する。提供元は何も持たない（手順書の「データは提供元のサーバーにない」を守る）。
  `osi-finance-connect` はこの前提で画面まで連れて行く。提供元のアプリを共用しない
- **導入キットはツールポータルから配る**（メール添付・Drive 共有は使わない）
- 伴走の範囲：第1部・第2部は相手だけで進められる想定。詰まった点は下の表に1行ずつ足す

## 学びの残し方

手順は事前に書き足さない。実際に詰まった1点だけをここに追記する。

| 場面 | 詰まった点 | 対処 |
|---|---|---|
| 第3部 台帳フォルダ設定 | 設定を入れてもコンソールの全タブが「XLSX_LEDGER_DIR が未設定」 | Claude Desktop を完全終了（Mac ⌘Q／Windows はトレイから終了）して開き直す |
| 第2部 メール添付 | 標準 Gmail コネクタでは添付 PDF を取れない | 添付起点の AP 運用なら Superhuman を接続 |
| 第3部 台帳の置き場 | パスの前後に引用符が入って読めない | 引用符なしの絶対パスを入れ直す |

## やらないこと

- 鍵の値・登録番号・口座番号をチャット・ログ・レポートに残す
- 「設定してください」と説明だけして止まる
- 相手に「どこまでやったか」を聞く（自分で確かめる）
- 送金・台帳の自動確定
