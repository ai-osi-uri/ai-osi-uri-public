# 決算整理のルール（osi-finance-year-end-close）

最終確認日: 2026-09-22（期限・税率は毎年の税制改正で変わる。期末ごとに国税庁・地方自治体のページで確かめ直す）

## §1 仮勘定の整理

- 仮払金・仮受金・諸口・未確定勘定は期末に0にする。1件ずつ中身を確かめ、本来の科目に振り替える。
- **新株式申込証拠金**：払込期日（効力発生日）が来たら、資本金と資本準備金に振り替える。
  - 資本準備金にできるのは払込額の2分の1まで。いくらを資本準備金にするかは、募集事項を決めた決議（株主総会・取締役会）の内容に従う。
  - 仕訳: (借)新株式申込証拠金 ／ (貸)資本金・資本準備金。日付は効力発生日。
  - 変更登記は効力発生日から2週間以内。登記が済んでいるかを要確認に挙げる（遅れると過料の対象になりうる）。
  - 増資後の資本金が1億円を超えると、中小法人向けの特例（軽減税率・交際費の定額控除・少額減価償却の特例など）が使えなくなる。
    資本金の額を仕訳の前に必ず確かめる。
- 期末をまたいで効力が発生する増資は、期末時点では新株式申込証拠金のまま残す（純資産の部に表示）。

## §2 利息の見越し

- 貸付金：契約の利率×期間で、期末までに発生した未収の利息を計上する。(借)未収収益 ／ (貸)受取利息。
  利率の定めが無い貸付は仕訳を出さず、税務調整の候補（認定利息）に回す。
- 借入金：返済予定表から、期末までに発生した未払の利息を計上する。(借)支払利息 ／ (貸)未払費用。

## §3 消費税の精算（税抜経理の場合）

- 税額は申告ソフトか税理士の計算結果を使う（計算方法＝原則課税／簡易課税／2割特例 はプロファイルを見る）。
- 仕訳: (借)仮受消費税等 ／ (貸)仮払消費税等・未払消費税等。差額は 雑収入 または 雑損失。
- 中間納付をしていれば、その額（仮払金や仮払税金で持っているもの）も精算に入れる。
- 精算前に、税区分のチェック（osi-finance-tax-class-check）で要確認が0であること。

## §4 法人税・住民税・事業税

- 税額は申告ソフトか税理士の計算結果を使う。
- 仕訳: (借)法人税、住民税及び事業税 ／ (貸)未払法人税等（中間納付・預金利息の源泉所得税があれば、それを差し引いた額を未払に）。
- 赤字でも住民税の均等割はかかる。0円で計上しない。
- 事業税のうち、所得に応じない部分（外形標準課税の対象法人のみ）は租税公課。対象かどうかはプロファイルの資本金で判定する。

## §5 決算書一式

| 書類 | 作り方 |
|---|---|
| 貸借対照表・損益計算書 | MFから出力。残高の説明表と数字が合っていること |
| 株主資本等変動計算書 | MFから出力。期首残高・増資・当期純利益・期末残高が、登記と仕訳に合っていること |
| 個別注記表 | 本スキルで作る。中小企業の会計に関する指針に沿って、少なくとも「重要な会計方針（固定資産の減価償却の方法、引当金、消費税等の会計処理＝税抜など）」「株主資本等変動計算書に関する注記（期末の発行済株式の種類と数）」を書く。役員・関係会社への貸付など、読む人の判断に影響する事項は税理士と相談して載せる |
| 勘定科目内訳明細書 | 残高の説明表（osi-finance-balance-schedule §10）から写す |
| 法人事業概況説明書 | 申告ソフト・税理士が作る。本スキルは、従業員数・主な取引先・月別の売上など元の数字をまとめて渡す |

## §6 受け渡しと期限

| 何を | 期限（原則） | 誰が |
|---|---|---|
| 株主総会での決算の承認 | 申告より前 | 会社 |
| 法人税・地方法人税・住民税・事業税の申告と納付 | 期末日の翌日から2か月以内（申告期限の延長の届出があれば、申告は延長されるが納付は2か月以内。延長中は利子税がかかる） | 税理士／会社 |
| 消費税の申告と納付 | 期末日の翌日から2か月以内（延長の届出があれば申告は3か月以内） | 税理士／会社 |
| 償却資産の申告 | 毎年1月31日（資産の所在する市区町村。東京23区は都税事務所） | 会社（fixed-assets の一覧を使う） |

期限は届出の有無で変わるので、プロファイルの届出の記録を見て、その会社の実際の期限を書く。
