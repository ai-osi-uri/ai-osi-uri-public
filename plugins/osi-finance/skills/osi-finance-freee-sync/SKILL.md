# osi-finance-freee-sync（freee 仕訳CSV ⇔ 台帳 突合）

> **組織固有値（台帳ID・フォルダ・採番）は `config/osi-finance-settings.md` を参照。**
> 発動条件: `INTEGRATIONS.ACCOUNTING_SYNC = freee`。それ以外の値なら案内して止まる
> （mf → mf-sync/ar-sync、none → 台帳のみ運用で突合対象なし）。

freee の公式コネクタを前提にせず、**CSV の受け渡し**で突合する。会計帳簿の正本は freee、
台帳は資金管理（請求予定・支払予定）の正本。本スキルは両者のズレを検出する突合役に徹する。

## 役割と非役割

- やる：`04.連携データ/freee/`（DRIVE_SYNC_FREEE）の仕訳CSVを読込 → 台帳の請求済/入金済（AR）・
  支払済（AP）と照合 → 計上済/未計上/除外を報告 → 台帳の突合結果・突合日時に書き戻し。
- やらない：**freee への書き込み・API接続**、送金、台帳ステータスの自動確定、請求書発行。
- 未計上分の freee 起票は人が freee 画面で行う（依頼があれば freee のインポート形式に整形した
  CSV 案を生成して渡すまでは可。投入は人）。

## 手順

### 1. 前提確認
- settings の `ACCOUNTING_SYNC=freee` を確認。`04.連携データ/freee/` に対象期間のCSVがあるか確認し、
  無ければ「freee の［レポート→仕訳帳］等からCSVをエクスポートしてこのフォルダに置く」手順を案内して止まる。
- CSVの期間（開始〜終了）を読み取り、突合対象期間として明示する。期間外の台帳行は「検証不能」と報告する。

### 2. CSV読込
- 仕訳帳CSV（日付・借方/貸方科目・金額・摘要・取引先）を読み込む。文字コード（Shift_JIS/UTF-8）と
  freee のエクスポート形式差は自動判別し、判別できない列は推測せず報告する。

### 3. 台帳読込と突合キー
- AR：請求管理台帳「月次請求スケジュール」の `請求ステータス=請求済/入金済` の行。キーは請求書番号（INV-…）。
  摘要に INV が無い freee 運用では `取引先名＋金額＋対象月` を代替キーにする（曖昧一致は「要確認」）。
- AP：支払管理台帳の支払済行。キーは請求書ID（`支払先ID+対象月+請求書番号`）、代替キーは同上。

### 4. 判定・報告
- **計上済**（freee に対応仕訳あり）／**未計上**（台帳にあるのに freee に無い＝計上漏れ候補・最優先で強調）／
  **除外**（カード・振替など別ルート処理）に分類し、件数・金額合計つきで一覧報告する。
- freee 側にだけあり台帳に無い売上/支払も「台帳未記載の疑い」として逆方向でも報告する。

### 5. 台帳書き戻し（人レビュー後）
- 突合結果（一致/未計上）・突合日時を該当行に書き戻す。**列はヘッダ名で解決**する。
- **操作者トラッキング（v3）**：書き戻した各行の**更新者・更新日時（JST）**を記録する
  （正本: `assets/schema/data-layout.yaml` の `operator_tracking`）。
  **値はコネクタが自動で押すので `actor` を渡さないこと**（拡張の設定「操作者【必須】」→ env `OPERATOR`）。
  ログインユーザーのメールを自分で入れない——経路ごとに違う文字列が入り、操作者が割れる。

## 留意

- freee へ書き込まない。送金しない。台帳ステータス（請求済/入金済/支払済）の遷移はしない（人のボタンのみ）。
- CSV は Drive の `04.連携データ/freee/` から動かさない。チャット出力に取引先の機微値を並べすぎない。
- CSVが古い（対象期間が突合対象月をカバーしない）場合は「再エクスポートが必要」と明示する。

## エラー処理

詳細は **[`docs/エラー処理ガイド.md`](../../docs/エラー処理ガイド.md)** を正本とする。
- フォルダ未作成・CSVなし → 導入手順（エクスポート→配置）を案内して止まる（`osi-finance-setup` が
  フォルダを作る。無ければ作成を提案）。
- 列形式が判別できない → 推測せず、先頭数行のヘッダを提示して人に確認。
- 代替キーの曖昧一致（同名・同額が複数）→ 自動判定せず「要確認」に分類。
