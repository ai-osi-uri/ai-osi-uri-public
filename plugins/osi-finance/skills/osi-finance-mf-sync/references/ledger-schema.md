# 支払管理台帳スキーマ（連携で使う列）

正本＝支払管理台帳（Googleスプレッドシート）。連携で参照・更新する主な列のみ抜粋。
全列の定義は別紙「支払管理台帳_列設計」を参照。

## 共通キー

`請求書ID = 支払先ID + 対象月(YYYYMM) + 請求書番号`
請求書番号が無い証憑は `支払先ID + 対象月 + 金額 + 連番`。
このIDを仕訳の摘要に必ず含め、台帳・MFの突合キーにする。

## シート「月次支払管理」（請求書由来）

| 列 | 用途 | 連携での扱い |
|---|---|---|
| 請求書ID | 主キー | 行特定・摘要に付与 |
| 支払先ID | 取引先紐付け | MF取引先マッチングの起点 |
| 支払先名 | 取引先名 | MF取引先名に突合 |
| 対象月 | 期間 | 重複チェックの対象月 |
| 勘定科目 | 借方科目 | 仕訳の借方 |
| 税区分(MF) | 税区分 | MF税区分コードに対応 |
| 金額(税抜) | 本体 | 借方（科目）金額 |
| 消費税額 | 消費税 | 借方（仮払消費税）金額 |
| 金額(税込) | 合計 | 借貸の総額 |
| 源泉徴収税額 | 源泉 | 貸方（預り金）金額 |
| 振込額 | 手取り | 貸方（普通預金）金額 |
| 支払日 | 計上日 | 仕訳日付 |
| 状態 | 進捗 | 抽出条件＝支払済／更新先＝仕訳連携済 |
| MF連携状態 | 連携可否 | 抽出条件＝未連携／更新先＝連携済 |
| MF仕訳ID | 連携結果 | 空＝未連携／成功時に書き戻し |

## シート「経費一覧」（請求書を伴わない経費）

| 列 | 用途 | 連携での扱い |
|---|---|---|
| 経費ID | 主キー | 行特定・摘要に付与 |
| 支払先ID | 任意紐付け | あればMF取引先に突合 |
| 発生日 | 計上日 | 仕訳日付 |
| 勘定科目 | 借方科目 | 仕訳の借方 |
| 税区分(MF) | 税区分 | MF税区分コード |

| 状態 / MF連携状態 / MF仕訳ID | 進捗・結果 | 月次支払管理と同様 |

## シート「月次支払スケジュール」（契約由来・AP予定）

AR 側「月次請求スケジュール」の対称版。**発注契約（方向=発注・状態=締結済）** を起点に、契約期間の各月へ支払予定を展開する。`osi-finance-payment-detect` は「受領請求書 × 本予定」を突合し、予定にあるのに請求書未着＝督促、予定に無い実請求＝新規、を検出する。

| 列 | 用途 | 連携での扱い |
|---|---|---|
| 予定ID | 主キー | `支払先ID + 対象月(YYYYMM)` |
| 契約ID | 契約紐付け | 契約マスタ（方向=発注）の `AP-C-###` |
| 取引先ID | 名寄せ | 取引先マスタ（3桁）。双方向先の相殺突合キー |
| 支払先ID | 取引先紐付け | 支払先マスタ（V-）。取引先IDと対応 |
| 支払先名 | 表示 | |
| 対象月 | 期間 | 重複展開防止（同 契約ID×対象月 は作らない） |
| 予定額(税込) | 金額 | 月額固定は各月、一括は該当月のみ |
| 支払予定日 | 期日 | 契約の支払サイトから算出 |
| 状態 | 進捗 | 未払予定／請求書受領済／支払済 |
| 受領請求書ID | 突合 | payment-detect が受領AP請求書と結び付け |

> **初月日割り**：契約開始が月途中なら初月は日割り（AR の請求スケジュールと同ルール）。

## 契約マスタ（請求管理台帳）の拡張列（AR/AP 共通）

契約マスタは AR/AP 双方を1表で持つ。既存列に加え次を持つ：
`取引先ID`（3桁・取引先マスタ）／`方向`（受注/発注）／`状態`（ドラフト/締結済）。
**状態=締結済のみスケジュール展開**（AR=月次請求スケジュール／AP=月次支払スケジュール）。契約IDは方向接頭辞つき（`AR-C-###`／`AP-C-###`、既存 `C-###` は AR とみなし移行）。

## 抽出条件（再掲）

`状態 = 支払済` かつ `MF連携状態 = 未連携`（実質 MF仕訳ID が空）。
