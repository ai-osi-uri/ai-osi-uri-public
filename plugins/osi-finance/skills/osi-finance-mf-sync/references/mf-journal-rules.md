# 仕訳ルール（AP：支払済取引のMF会計連携）

支払時点で費用計上する前提（支払日＝取引日）。MFの `postJournals` 実仕様に合わせる。

## MF仕訳の作り方（重要）

- 仕訳は `branches`（明細行）の配列。各行に `debitor`（借方）または `creditor`（貸方）を持つ。
  複合仕訳は1行=片側のbranchを複数並べて表現する（借方合計＝貸方合計）。
- **消費税は税区分から自動計算される。** 金額（`value`）＋税区分（`tax_id`）を渡せばMFが内税を計算する。
  → **「仮払消費税」を別行で作らない。** 費用行に税込金額＋課税仕入の税区分を入れるだけ。
- 各行に必要: `account_id`（勘定科目ID）, `value`（金額）, `tax_id`（税区分ID, 課税行のみ）,
  `sub_account_id`（補助科目ID, 必要時）, `trade_partner_code`（取引先コード, あれば）。
- `transaction_date`（取引日＝支払日）, `remark`（摘要）を付ける。

## 金額の扱い

- 費用行の `value` は **税込金額**。MFが内消費税を自動算出する。
- 貸方は 普通預金＝振込額、源泉がある場合は 預り金（補助:所得税）＝源泉徴収税額。

> **経理方式との関係（混同しやすいので注意）**
> MFの経理方式が **税抜(内税)** でも、`postJournals` に渡すのは**税込金額**でよい。MFが内税を分解する。
> ただし **GET・レポートで返る値は分解後（税抜）**になる。「post に渡す値」と「レポートで返る値」は
> 税基準が違う。突合の際は下の「税基準」に従うこと。
>
> 経理方式が **税抜(別記)** の会社では post 側の値の取り方も変わる。初回連携時に1件で必ず確認する。

## 基本パターン（請求書 / 経費 共通）

借方:
- 勘定科目（台帳の「勘定科目」）＝ 税込金額 ／ 税区分＝課税仕入 10% など

貸方:
- 普通預金 ＝ 振込額
- 預り金〔補助:所得税〕＝ 源泉徴収税額（源泉が0なら作らない）

検算: 借方合計（税込）＝ 貸方合計（振込額＋源泉）。

### 例1：源泉なし（税込220,000）
- (借) 業務委託料 220,000〔課仕10%〕／ (貸) 普通預金 220,000

### 例2：源泉あり（税込132,000・源泉12,252）
- (借) 支払手数料 132,000〔課仕10%〕
- (貸) 普通預金 119,748 ／ (貸) 預り金〔所得税〕12,252

## 勘定科目の対応（この会計に実在する科目へ）

**正本は 仕訳台帳「勘定科目マスタ」の `MF科目名` 列。** ローカル科目名をそのまま送らず、必ずこの列で変換する
（freee は `freee科目名` 列）。マスタに無い科目は「要確認」で止める。
そのうえで、getAccounts で取得した実在科目に突き合わせる。下表は台帳が手書きだったころの目安。

| ローカル／台帳の表現 | MFの実在科目 |
|---|---|
| 業務委託費 | 業務委託料 |
| 外注費 / 外注 | 業務委託料 |
| 消耗品費 | 備品・消耗品費 |
| 交際費 | 接待交際費 |
| 支払報酬料 | 支払報酬 |
| 手数料 | 支払手数料 |
| 報酬（士業・デザイン等） | 支払報酬 |
| 交通費 | 旅費交通費 |
| 源泉預り | 預り金（補助科目:所得税） |
| 振込元口座 | 普通預金 |

科目名がローカルとMFで違うことを忘れると、突合で「ローカルにしか無い科目／MFにしか無い科目」が
両側に立ち、差の原因を見誤る。迷う科目は推測で確定せず、ユーザーに確認する。

## 税区分の対応

台帳「税区分(MF)」を getTaxes のIDに対応づける。例：「課税仕入 10%」=（課仕 10%）。

## 取引先（trade_partner）

- 現在、取引先マスタは0件。`trade_partner_code` は任意なので**無くても仕訳は作成できる**。
- 継続取引先は getTradePartners で確認し、無ければ postTradePartners で登録してから紐付けるのが望ましい。
  登録は会計データに残るため、必ずユーザー確認のうえ行う。

## 摘要（必須）

`{請求書IDまたは経費ID} / {取引先名} / {対象月}` を必ず入れる。
重複チェックは摘要中の請求書IDで行う（getJournals に摘要検索が無いため、期間で取得して摘要を走査）。

## 源泉税

- 源泉徴収税額は台帳の確定値（源泉徴収管理シートと一致）を使う。MFは源泉を自動計算しないため明示する。
- 税率・納期特例の判断は会計・税務の領域。曖昧な場合は確定せず確認する。
