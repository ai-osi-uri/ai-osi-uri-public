# 連携明細 棚卸し 判断辞書（osi-finance-feed-recon）

MFの連携明細（未仕訳）を「対象外／登録／要確認」に振り分けるための辞書。
※会計・税務の最終判断は人（必要なら税理士・司法書士）。本辞書は初期値・運用の目安。

## 0. 大前提（必読）

- **MFのAI自動推定科目は誤りが多い。** 特に**入金は何でも「売上高/売掛金」に寄せる**。鵜呑みにしない。
- **「一括登録」ボタンは押さない。** 大型入金は人確認まで保留。
- **連携明細の対象外/登録はMF画面専用（MCP不可）。仕訳削除もMCP不可。**

## 1. 出金（マイナス明細）の振り分け

| パターン | 判定 | 対応 |
|---|---|---|
| 既存仕訳（手入力バックフィル等）と同額・同支払先・近接日 | **対象外** | 手入力を正本に残し、重複未仕訳を対象外（手入力は科目/税区分/源泉/金額調整が正確） |
| 振込手数料（▲数百円）で既存に無い | **登録** | 支払手数料・課税仕入10%（少額特例で控除可）。計上漏れ |
| 既存バックフィルの締め後（例：6/9以降）の新規出金 | **登録** | 支払先別マッピングで科目判定（monthly-rules 参照） |
| 貸付の実行（追加貸付） | **登録** | (借)短期貸付金/(貸)普通預金 |
| 保証金の差入 | **登録** | (借)差入保証金/(貸)普通預金・対象外 |
| 法人カードの引き落とし | **登録** | (借)未払金/(貸)普通預金・対象外（カード経費はカード連携側） |

## 2. 入金（プラス明細）の振り分け — ここが事故りやすい

MF推定は全て「売上高/売掛金」になっているが、**売上はごく一部**。金額・相手先で判定し、**非ARの大型入金は人確認**。

| パターン | 正しい区分 | あるべき仕訳 | 備考 |
|---|---|---|---|
| 顧客からの請求入金（台帳の請求先・請求額に一致） | 売掛金消込 | (借)普通預金/(貸)売掛金 | 売掛金が無ければ先に osi-finance-ar-sync で売上計上 |
| 金融機関の融資実行（例：日本政策金融公庫） | **借入金** | (借)普通預金〔＋手数料差額は(借)支払手数料〕/(貸)長期借入金=額面 | 短期/長期は契約。額面と入金差は手数料 |
| 個人名・関係者からの大型round入金 | **出資 or 役員等借入** | 出資なら下記3、借入なら(貸)短期/長期借入金 | **要人確認**。売上ではない |
| 取引先（自社が支払っている先）からの入金 | **要確認** | 返金/立替精算/貸付回収/借入 のいずれか | 売上ではない可能性大 |
| 自社が貸し付けた先からの入金 | 貸付金の回収 | (借)普通預金/(貸)短期貸付金 | 貸付の取崩し |
| 振込手数料キャッシュバック等の少額 | 雑収入/対象外 | (借)普通預金/(貸)雑収入 等 | 少額 |

**運用：非ARの大型入金は「大型入金 要確認リスト」を作り、相手先・金額・想定区分を添えて人（経営/出資者）に確認 → 確定区分で計上。**

## 3. 出資（増資）の受入

- **登記前**：(借)普通預金/(貸)**新株式申込証拠金**（純資産の仮勘定）。
- **登記後**：新株式申込証拠金 → **資本金／資本準備金**へ振替。資本金と資本準備金の振り分けは募集事項・登記内容に従う。
- **必ず司法書士/税理士確認**（資本金額は登記・税務に直結）。確定まで売上高には絶対に入れない。

## 4. 借入金（融資実行）

- 基本：(借)普通預金/(貸)長期借入金（または短期借入金。返済期間で判断）。
- **入金額が額面と違う**（手数料・保証料を差し引いて入金）場合：
  - (借)普通預金 ＝ 入金額 ＋ (借)支払手数料/支払利息等 ＝ 差額 ／ (貸)長期借入金 ＝ **額面**。
  - 例：額面7,000,000・入金6,999,780・差220＝振込手数料 → (借)普通預金6,999,780＋(借)支払手数料220/(貸)長期借入金7,000,000。
  - 既に入金額で連携計上済みなら、差額だけ調整仕訳 (借)支払手数料/(貸)長期借入金 を1本足して額面に補正（連携明細の普通預金額は触らない）。

## 5. 二重計上を避ける（要）

- **連携明細をMCPで振替伝票計上したら、必ずその明細を画面で対象外**にする（しないと後で登録され二重）。
- 既存手入力バックフィル × 連携未仕訳の重複は、**種別ごとに正本を決める**：
  - 銀行振込の支払・貸付・入金 → 連携明細を正本に（または既に正確な手入力を残し連携を対象外）。
  - カード経費 → カード連携を正本に（未払金経由）。手入力の集約は過去分のみ残し、個別カード未仕訳は対象外。
  - 売上(AR) → 台帳から発生主義で手当て（連携では取れない）。
- **検算**：普通預金の貸借が「既存仕訳＋今回計上＋手数料＋入金消込」と一致するか。残高試算表で確認。

## 6. カード未仕訳の日付境界

- 法人カード連携は最新まで取り込むため、過去分の手入力集約（例：〜6/8）の**締め後（6/9以降）**の利用が混じる。
- 全件を一括対象外にすると締め後の経費が消える。**締め日までは対象外（集約済）、締め後は登録（自動仕訳ルール推奨）**。
