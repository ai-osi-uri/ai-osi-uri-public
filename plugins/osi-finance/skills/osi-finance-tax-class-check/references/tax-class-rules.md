# 消費税区分の判定ルール（osi-finance-tax-class-check）

最終確認日: 2026-09-22（§3 の経過措置は令和8年度税制改正後のもの。国税庁「令和８年度税制改正特集」で確かめること）

## §1 科目と税区分の組み合わせ

| 科目の例 | 正しい税区分 | よくある誤り |
|---|---|---|
| 給料手当・役員報酬・賞与・法定福利費 | 不課税（対象外） | 課税仕入にしている |
| 通勤手当 | 課税仕入（通常必要な範囲） | 不課税にしている |
| 租税公課（印紙・登録免許税・固定資産税など） | 不課税 | 課税仕入にしている |
| 支払利息・保証料（信用保証協会など） | 非課税 | 課税仕入にしている |
| 保険料（損害保険・生命保険） | 非課税 | 課税仕入にしている |
| 地代家賃（事務所） | 課税仕入 | — |
| 地代家賃（住宅＝社宅として借りたもの） | 非課税 | 課税仕入にしている |
| 地代家賃（土地そのものの貸借） | 非課税 | 課税仕入にしている（駐車場は設備があれば課税） |
| 敷金・保証金（返ってくる分） | 不課税 | 課税仕入にしている |
| 礼金・更新料（返ってこない分） | 事務所は課税仕入、住宅は非課税 | — |
| 寄附金・贈与 | 不課税 | — |
| 会費（対価性の無い通常会費） | 不課税 | 課税仕入にしている |
| 慶弔費（祝金・香典） | 不課税 | 課税仕入にしている |
| 商品券・プリペイドカードの購入 | 非課税（使ったときに課税仕入） | 購入時に課税仕入にしている |
| 切手・収入印紙 | 郵便局等で買った切手は非課税（使ったときに課税仕入）。収入印紙は不課税 | — |

## §2 税率

- 飲食料品（酒類・外食を除く）と、定期購読の新聞は軽減税率8%。会議用の弁当・飲み物の買い物は8%、店内での飲食（外食）は10%。
- 1枚の請求書に10%と8%が混ざっているときは、税率ごとに行を分ける。

## §3 インボイス

- 課税仕入の仕入税額控除には、相手が発行した適格請求書（登録番号・税率ごとの対価と税額の記載があるもの）の保存が要る。
- 相手が登録事業者でない（免税事業者・消費者など）課税仕入は、経過措置の割合だけ控除できる:

| 課税仕入を行った日 | 控除できる割合 |
|---|---|
| 2023-10-01 〜 2026-09-30 | 80% |
| 2026-10-01 〜 2028-09-30 | 70% |
| 2028-10-01 〜 2030-09-30 | 50% |
| 2030-10-01 〜 2031-09-30 | 30% |
| 2031-10-01 以降 | 0% |

  MFの税区分は、日付に合った割合のもの（「課税仕入 10%（80%控除）」「…（70%控除）」など、getTaxes の実在名）を使う。
  **月をまたぐ継続取引は、課税仕入を行った日で割合が変わる**ので、2026年9月分と10月分で税区分を分ける。
- 少額特例（税込1万円未満の課税仕入はインボイスが無くても帳簿の記載で控除できる）は、基準期間の課税売上高などの要件がある。
  settings の SMALL_AMOUNT_SPECIAL が「あり」のときだけ当てる。
- インボイスが要らない取引（公共交通機関の3万円未満の運賃、自動販売機の3万円未満の購入、郵便ポストに出した郵便など）は、帳簿にその旨を書く。
- 登録番号は国税庁の公表サイトで確かめる。番号が請求書にあっても、登録の取消・失効があれば経過措置側になる。

## §4 国外の相手

- 国外事業者からの電気通信利用役務（海外SaaS・クラウド・広告など）:
  - 消費者向け（誰でも申し込めるSaaSなど）: 相手が登録国外事業者なら課税仕入（インボイスが要る）。登録が無ければ控除できない。
  - 事業者向け（広告配信・事業者専用のクラウドなど）: リバースチャージの対象。ただし、課税売上割合が95%以上の期間、
    または簡易課税・2割特例を使う期間は、リバースチャージの処理をしなくてよい（その仕入はなかったものとして扱う）。
- どちらに当たるかは契約・利用規約で決まるので、相手ごとに一度決めて settings §7-2 に書く。

## §5 売上側

- 売上の税区分は通常「課税売上 10%」。国外の相手への役務の提供は、内容によって免税（輸出免税）や不課税になるので要確認。
- 立替金の精算（実費の立替を請求したもの）は売上に混ぜない。立替金の科目で不課税。
- 受取利息は非課税売上、受取配当金は不課税。
