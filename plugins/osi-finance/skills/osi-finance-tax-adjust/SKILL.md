# 税務調整の候補（osi-finance-tax-adjust）

> **組織固有値はプロファイルから読む。** 資本金の額（1億円以下か）、株主構成（大法人の子会社でないか）、
> 青色申告の承認の有無、従業員数、役員の一覧と役員給与の決め方（株主総会・取締役会の決議）は
> `osi-profile.md` と `{{paths.finance}}/osi-finance-settings.md` を正とする。
> 判断ルールの正本は `references/tax-adjust-rules.md`。税制は毎年変わるので、同ファイルの最終確認日から
> 1年以上たっていたら国税庁のページで確かめ直してから使う。

## なぜ候補を出すのか

税務調整そのものは税理士か申告ソフトが行う。けれども、どの取引が論点になるかは帳簿を毎日見ている側が一番よく知っている。
期末に税理士が1年分の仕訳から探すより、こちらが根拠付きで候補を出したほうが早く、漏れも少ない。
役員給与や貸付の利率のように、期中に決め方を変えないと直せないものは、月次で早めに知らせる。

## 手順

```
0. 対象事業者・会計期間・プロファイル（資本金・株主構成・青色申告・役員）を確かめる
1. 読む：当期の仕訳（getJournals）、残高試算表、固定資産の資産タグ、前払の按分タグ、台帳の契約マスタ
2. 当てる：references/tax-adjust-rules.md の §1〜§9 を順に当てる
3. 一覧にする：項目・金額・根拠（仕訳No・資料）・関わる別表・会社が決めること・税理士に確かめること
4. 報告：期末は year-end-close の出力フォルダに xlsx で置く。月次は「期中に手を打てるもの」だけを画面に出す
```

## 出力の形

| 項目 | 金額 | 根拠 | 別表 | 会社が決めること | 税理士に確かめること |
|---|---|---|---|---|---|

## 注意

- 候補を出すだけ。「損金にならない」「特例を使える」と断定しない。最終判断は税理士。
- 役員・株主の個人の事情（家族関係・個人の所得）には踏み込まない。会社の帳簿から分かることだけを書く。
