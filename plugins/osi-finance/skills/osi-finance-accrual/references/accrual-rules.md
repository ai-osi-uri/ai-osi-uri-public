# 期ズレ計上 判断辞書（accrual-rules）

月末ごとに「どの月の売上・費用か」を置き直すためのルール集。会計・税務の最終判断は人（必要なら税理士）。
ここにあるのは初期値と運用の目安。金額は台帳にならい税込で扱い、MFへの登録時に税区分を付ける。

---

## §0 共通の考え方

- **売上は役務を提供した月、費用は役務を受けた月。** 入金月・支払月・請求書の日付では決めない。
- 判定の順番は「契約の支払条件 → 台帳の行 → MFの既存仕訳」。契約に書いてあることを最優先にする。
- 決まらないものは計上しない。「何が決まれば計上できるか」を1行で書いて要確認に回す。
- 同じ根拠から二度計上しない。摘要キー（SKILL.md）で既存仕訳を必ず引く。

---

## §1 前受金（受注側の先払い）

### 1-1 前受金にするもの

請求・入金が役務の完了より先に来るもの。月次請求スケジュールの件名・契約マスタの支払条件で見分ける。

- 着手金・準備金・前金・「着手時半金」など、完了前に請求する分
- 期間の途中で一括請求した前払いの利用料（翌月以降の分）
- 回数券・チケット型（課金パターン prepaid）の購入代金（消化時に売上。`消化記録` タブで管理）

仕訳（入金時または請求時）:

```
(借)売掛金 または 普通預金   /(貸)前受金   税込・対象外   摘要: ACR-前受 {契約ID} {対象月} …
```

**既に売上高で計上してしまった着手金**は、完了月が当月でなければ当月末に振り替える:

```
(借)売上高（課税売上10%）  /(貸)前受金（対象外）   税込
```

### 1-2 売上に振り替える月（完了の決め方）

| 契約の種類 | 売上にする月 | 台帳での合図 |
|---|---|---|
| 請負（成果物の納品・検収） | 検収を受けた月 | 残金行が「請求済」になった月、または検収書の日付 |
| 準委任で完了条件がある（回数・成果物の提供など） | 完了条件を満たした月 | 同上（完了後に残金を請求する契約が多い） |
| 準委任で期間に対して均等に役務を提供 | 期間で按分（毎月） | 契約期間と一括額 |

振替仕訳（完了月末）:

```
(借)前受金（対象外）       前受の額
(借)売掛金（対象外）       残金の額（未請求でも計上する）
      /(貸)売上高（課税売上10%）  総額（税込）
```

- 残金を同じ月に請求するなら、`osi-finance-ar-sync` が残金の請求書IDで売掛金を計上する。**その場合この仕訳は
  前受金→売上の部分だけにし、残金は ar-sync に任せる。** どちらで計上したかを摘要に書く。
- 期日までに完成しなければ返金する条項がある契約は、完了前に売上にしない（返金リスクが消えていない）。
- 完了が確認できないまま月を越えたら、前受金のまま残して要確認に出す（推測で振り替えない）。

## §2 前払費用（支払側の先払い）

### 2-1 前払費用にするか、支払時の費用にするか

| ケース | 扱い |
|---|---|
| 支払日から1年以内に役務を受け終わる、毎月同じ内容の継続サービス（家賃・顧問料・保守料など）で、毎期同じ扱いを続ける | 支払時に費用でよい（短期前払費用の特例）。取崩し不要 |
| 1年を超える期間の分をまとめて払った（複数年のSaaS利用料など） | 前払費用に置き、月割で取崩す。特例は使えない |
| 翌月分の家賃を当月に払ったが、上の特例を使わない運用にしている | 前払費用に置き、翌月に取崩す |

どちらの運用にしたかは組織で1つに決めて変えない（継続適用が条件）。決めた内容は `config/osi-finance-settings.md` に書く。

### 2-2 按分タグ

前払費用を計上する仕訳の摘要末尾に付ける。取崩しはこのタグだけを見て出す。

```
[按分 {開始月}..{終了月} {回数}回 月{1回の額} {費用科目} {税区分}]
例: [按分 2026-06..2028-05 24回 月110000 通信費 課仕10%]
```

- 端数は最終回で調整する。
- 取崩し仕訳: `(借){費用科目}（{税区分}）/(貸)前払費用（対象外）  月{1回の額}   摘要: ACR-前払 {元仕訳No} {n}/{回数}`
- 仕入税額控除を取崩し時に取る運用（前払費用を税込・対象外で置く）が既定。支払時に控除する運用にした組織は、
  取崩しの税区分を対象外にする（二重控除にしない）。
- 前払費用を置いた月が遅れた（例：6月開始の分を8月に前払費用へ振り替えた）ときは、過ぎた月の分を振替月にまとめて取崩す。

### 2-3 検算

当月の取崩し後に、按分タグの残回数×1回の額 ＝ 前払費用の補助科目（または摘要キー）ごとの残高 になるかを見る。
合わなければ取崩しを出さず、差額と候補原因（取崩し漏れ・二重・期間の誤り）を報告する。

## §3 長期前払費用（税法上の繰延資産）

| もの | 償却期間の目安 |
|---|---|
| 建物を借りるときの礼金・権利金・更新料 | 5年。ただし賃借期間が5年未満で、更新時に再び支払う必要がある契約は賃借期間 |
| 1年を超える保証会社の保証料 | 保証期間 |
| 1年を超える期間の前払い（§2で1年超の部分） | その期間（§6で組替え） |

- 1件20万円未満の礼金などは、支出時の費用でよい（償却しない）。
- 月割で償却する: `(借)地代家賃 等 /(貸)長期前払費用  摘要: ACR-長前 {元仕訳No} {対象月}`。
  償却の開始は役務を受け始めた月（入居月）。遅れて始めた場合は、過ぎた月の分を当月にまとめる。
- **償却期間は契約書で確かめる。** 賃借期間・更新時の再支払の有無が分からないうちは要確認にし、償却を出さない。
- 会社法上の繰延資産（創立費・開業費）は任意償却なので月次では触らない。期末に償却額を決める（税理士と相談）。

---

## §4 未払費用（当月に役務を受けたが、請求書がまだ来ていないもの）

### 4-1 対象

月次支払スケジュールのうち、対象月＝当月で、締めの時点で状態が「請求書受領済」「支払済」になっていない行。
請求書が届いている行は、見積ではなく実額で `osi-finance-mf-sync` が計上する（本スキルは出さない）。

### 4-2 見積額の決め方（上から順に使う）

| 根拠 | 使う条件 |
|---|---|
| 契約の定額 | 契約マスタの月額固定、または支払スケジュールの予定額が入っている |
| 算定式 | レベニューシェア等、契約で式が決まっている（例：相手先の対象月の対象売上×率）。式と入力値を摘要に書く |
| 直近の実績 | 都度払いで、前月（無ければ直近）に同じ支払先の実額がある |
| 見積しない | 実績も定額も無い／稼働があったか分からない → 要確認（「稼働の有無と金額」を担当者に確認） |

仕訳（当月末）と振戻し（翌月1日）:

```
当月末:  (借)業務委託料 等（課仕10%・前月と同じ適格区分）/(貸)未払費用（対象外）  見積額  摘要: ACR-見積 {予定ID} 根拠=…
翌月1日: (借)未払費用 /(貸)業務委託料 等   同額   摘要: ACR-振戻 {予定ID}
```

実額は請求書を受け取った月の日付で mf-sync が計上する（対象月末に入れない）。見積と実額の差は翌月の損益に出る。

### 4-3 期末月の扱い

期末月だけは振戻しで翌期に回すと、差額が翌期に出る。期末は請求書が揃うまで締めを待ち、できるだけ実額で計上する。
間に合わない分だけ見積にし、差額が大きいもの（目安：1件10万円超）は決算確定前に実額へ直す。

## §5 計上漏れの検出（行が無い）

仕訳を出すのではなく「台帳の行が無い」ことを見つける。ここで見つけたものは、行を作ってから通常の流れ（請求・支払）に乗せる。

| 見る組み合わせ | 漏れと判定する条件 |
|---|---|
| 契約マスタ（受注・締結済・月額固定）× 月次請求スケジュール | 対象月が契約期間内なのに、その契約IDの対象月の行が無い |
| 契約マスタ（受注・自動更新あり・契約終了が空）× 月次請求スケジュール | 直近まで毎月行があったのに当月の行が無い |
| 契約マスタ（発注・締結済）× 月次支払スケジュール | 契約期間内・前月まで支払実績があるのに当月の行が無い |
| 前月の支払スケジュールで予定額が空のまま、MFにも発生計上が無い行 | 前月分の計上漏れ候補（稼働の有無を確認） |
| 契約マスタの状態がドラフト・送付済なのに、備考や議事録で作業開始が確認できる | 無契約のまま役務提供が進んでいる。締結と請求の段取りを要確認に出す |

契約終了月を迎える契約（更新の判断が要るもの）も、このタイミングで一覧にして添える。

---

## §6 期末組替え（期末月だけ）

- 前払費用の残高のうち、期末日の翌日から1年を超えて役務を受ける分を長期前払費用へ振り替える:
  `(借)長期前払費用 /(貸)前払費用  摘要: ACR-組替 {元仕訳No} {期末}`。
  翌期の月次取崩しは前払費用から按分タグどおりに続け、長期前払費用のうち1年以内になった分はその都度前払費用へ戻す。
- 前受金・未払費用・長期前払費用の残高を内訳付きで一覧にし、決算整理パッケージ（税理士へ渡す一式）に入れる。
