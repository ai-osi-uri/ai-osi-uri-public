# 月次経理 判断辞書

毎月の仕訳化で、科目・税区分・インボイス・源泉をブレなく判断するためのルール集。
※会計・税務の最終判断は人（必要なら税理士）。本辞書は初期値・運用の目安。

> **判断ロジック・税区分ルールは汎用**だが、**自社固有の「支払先→勘定科目」対応表は組織ごとに異なる。**
> 自組織の実値は `config/keiri-settings.md`（テンプレ：`config/keiri-settings.example.md`）の
> 「7. 判断辞書（科目マッピング）」に定義し、本辞書の下表は**雛形（`例:`）**として扱う。

## 1. 支払先別 勘定科目マッピング（振込支払）— 雛形

下表は**書き方の例**。自組織の確定値は `keiri-settings` の「7-1. 支払先別 勘定科目マッピング」に置く。

| 支払先（例） | 勘定科目 | 税区分 | 備考 |
|---|---|---|---|
| 例: 不動産・オフィス賃貸先 | 地代家賃 | 課税仕入10% | 月額固定 |
| 例: 法人の士業（弁護士法人等） | 支払報酬 | 課税仕入10% | 法人=源泉なし |
| 例: 開発・運用の業務委託先（法人） | 業務委託料 | 課税仕入10% | |
| 例: 個人事業主の業務委託先 | 業務委託料 | 課税仕入10% | システム開発=源泉なし。インボイス登録番号は要確認 |
| 例: 貸付先 | 短期貸付金 | 対象外 | 貸付（BS・損益でない） |
| 例: グループ内振替分 | 短期貸付金 | 対象外 | 振替。※役務提供の請求は業務委託料・課税10% |

## 2. カード（自動課金SaaS等）加盟店別マッピング — 雛形

下表は**書き方の例**。自組織の確定値は `keiri-settings` の「7-2. カード加盟店マッピング」に置く。

| 加盟店（例の分類） | 勘定科目 | 税区分 |
|---|---|---|
| 例: 国外SaaS（AI/開発/動画/コミュニケーション等） | 通信費 | **対象外（国外SaaS・要確認）** |
| 例: 国内クラウド（国内事業者） | 通信費 | 課税仕入10%（国内） |
| 例: 広告出稿 | 広告宣伝費 | 課税仕入10% |
| 例: タクシー・交通 | 旅費交通費 | 課税仕入10% |
| 例: 出張（航空・宿泊） | 旅費交通費 | 課税仕入10% |
| 例: 会議用スペース | 会議費 | 課税仕入10% |
| 例: 備品・消耗品の購入 | 備品・消耗品費 | 課税仕入10% |
| 例: 飲食 | 会議費 or 接待交際費 | 課税仕入10% |

## 3. 税区分ルール

- 国内の課税仕入 → **課税仕入10%**。
- **国外SaaS（電気通信利用役務）→ 暫定「対象外」**（控除しない安全側）。リバースチャージ／登録国外事業者
  の扱いで変わるため、**税理士の方針に従って確定**。確定後にMFで一括変更。
- 貸付金・借入返済・グループ内振替・カードの引き落とし → **対象外**（資金/財務取引）。

## 4. インボイス区分

- 法人の取引先 → **適格（全額控除）を初期値**（MF既定）。
- 個人事業主・小規模先 → 請求書の**登録番号（T＋13桁）を確認**。無ければ **80%控除（経過措置）**。

## 5. 源泉徴収

- 法人への支払い → **源泉なし**。
- 個人（個人事業主含む）→ 支払内容が所得税法204条の「報酬・料金」に該当する場合のみ源泉。
  原稿・デザイン・講演・士業報酬等は対象。**システム開発・プログラミングは対象外**。

## 6. カードの未払金構造（法人カード／例: UPSIDER）

- 利用時：(借) 各経費 /(貸) 未払金（カード負債）。
- 引き落とし時：(借) 未払金 /(貸) 普通預金（対象外）。
- 未払金がブリッジ。利用で積み上がり、引き落としで消える。月末の未払金＝未精算残。
- **銀行明細のカード引き落としは必ず未払金へ**。経費にすると二重計上。
  （カード会社の自動仕訳連携を使う場合、利用明細はカード連携側で経費化される前提。）

## 7. 重複防止・登録の作法（重要な教訓）

- 仕訳の摘要に必ずキー（請求書ID＝支払先ID＋対象月＋請求書番号、無ければ代替キー／カードは加盟店＋月）を入れる。
- 登録前に `getJournals` で同キーの仕訳が無いか確認（二重連携防止）。
- **大量を並列で一気にpostしない。** 結果が返らず二重登録が起きやすい。少数ずつ→**直後に
  getJournals／残高試算表で件数・金額を検算**してから次へ。
- **MCPに仕訳削除は無い。** 重複したらMF画面で該当番号を削除する。
- **当会計年度外（前期）の取引日はpostできない**（期間外エラー）。前期分は前会計年度で処理。

## 8. 連携対象外（自動連携・突合の除外）

- 法人カード決済（例: UPSIDER）→ カード明細連携で経費化。台帳行は資金管理のみ。
- 貸付金／借入返済／グループ内振替 → 財務取引（対象外）。経費連携の対象にしない。

## 9. 連携明細（未仕訳）の棚卸し・MCP/画面の境界（重要な教訓）

連携明細（未仕訳）の整理そのものは **`keiri-feed-recon` スキル**＋`recon-rules.md` を正本にする。要点：

- **MFのAI自動推定科目は誤りが多い。** 特に**入金は何でも「売上高/売掛金」に寄せる**。**「一括登録」ボタンは押さない。**
- **連携明細の「対象外／登録」はMF画面専用（MCP不可）。仕訳の削除もMCP不可**（MF画面で番号指定）。
  - 画面：科目を直して「登録」（明細も同時にクリア）／重複は「一括対象外」／取消は「明細一覧」でステータス=対象外を絞り「対象外を解除」。
  - MCP：明細に紐づけない計上（借入・貸付・保証金・差額補正・売上計上・入金消込）は postJournals で振替伝票化。
- **MF画面の自動操作（ブラウザ自動化）は不安定**（クリックがフリーズ／拡張切断で未反映）。書込は**人の画面操作**か
  **MCP（明細非依存の仕訳）**を優先し、自動クリックは安定時のみ1操作ずつ検証。反映確認できないまま連打しない。
- **二重計上防止**：連携明細をMCPで振替伝票計上したら、**必ずその明細を画面で対象外**にする（しないと後で登録され二重）。
  既存の手入力バックフィル × 連携未仕訳の重複は、種別ごとに正本を決める（重複する未仕訳は対象外）。

## 10. 財務的入金の作法（売上にしない）

詳細は `keiri-feed-recon/references/recon-rules.md`。代表のみ：

- **顧客入金（AR）** → (借)普通預金/(貸)売掛金（売掛金が無ければ先に売上計上）。
- **借入金（融資実行）** → (借)普通預金/(貸)長期借入金（短/長は契約）。**入金額が額面と違う**ときは
  (借)普通預金＋(借)支払手数料 等 ＝差額 /(貸)長期借入金＝**額面**。既に入金額で計上済みなら差額の調整仕訳1本で額面に補正。
- **貸付金の回収** → (借)普通預金/(貸)短期貸付金。
- **保証金の差入** → (借)差入保証金/(貸)普通預金（対象外）。
- **出資（増資）** → 登記前は(貸)新株式申込証拠金、登記後に資本金/資本準備金へ振替。**司法書士/税理士確認**。売上高に絶対入れない。
- いずれも**非ARの大型入金は人（経営/出資者）確認**を挟む（MF推定「売上高/売掛金」は誤り）。
