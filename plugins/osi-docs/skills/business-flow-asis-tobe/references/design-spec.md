# デザイン仕様（Midnight Executive）

このスキルが生成する pptx の見た目は、配色・タイポ・レイアウトの3つの軸で固定されている。これらを崩すと「業務の鏡」としての真剣さが失われるので、原則変更しない。

## 配色

| 役割       | カラー名     | HEX       | 使い所 |
|-----------|------------|-----------|--------|
| Primary   | NAVY        | `1E2761` | 表紙背景・セクション番号バッジ・主たるカード |
| Primary darker | NAVY_DK | `151B47` | 表紙ベース・レーンラベル背景 |
| Secondary | ICE         | `CADCFC` | 副次的テキスト・薄い背景 |
| Accent    | GOLD        | `F5B700` | 強調・AI Agent カード・効果バッジ |
| AS-IS pain | RED        | `C73E1D` | AS-IS 側のヘッダー・アラート |
| TO-BE good | GREEN      | `2E8B57` | TO-BE 側のヘッダー・改善 |
| Muted     | SLATE       | `64748B` | 本文の補足説明 |
| Muted lt  | SLATE_LT    | `94A3B8` | グレーアウト・「触らない」セル |
| Surface   | CREAM       | `F8F9FB` | スライド背景（表紙・まとめ以外） |
| Border    | BORDER      | `E2E8F0` | カード枠・テーブル罫線 |

## タイポグラフィ

| 用途         | フォント    | サイズ |
|-------------|------------|-------|
| 表紙タイトル  | Georgia     | 56pt bold |
| セクションタイトル | Calibri     | 22pt bold |
| サブタイトル / リード | Calibri     | 14-18pt |
| 本文        | Calibri     | 9-12pt |
| 大きな数字    | Georgia     | 26-32pt bold |
| キャプション・タグ | Calibri     | 7-9pt italic |

**注意**：日本語を含む本文に Georgia を使うと、文字が抜ける場合がある（LibreOffice の CJK フォールバックの問題）。**本文・セクション見出しは Calibri** で統一する。Georgia は数字・タイトル装飾のみ。

## レイアウト

スライドサイズは `LAYOUT_16x9`（10" × 5.625"）固定。

### セクション見出し（全スライド共通）

```
[01] セクション名                                   ← y=0.5, h=0.5
─────────────────────────────                       ← y=1.12, 細い罫線
```

### 表紙

- 背景：NAVY_DK（紺）
- 左端に縦のゴールドバー（アクセント）
- 上部に EYEBROW（小さな白抜きラベル）
- タイトル：Georgia 56pt
- サブタイトル：ICE 18pt
- 下部に想定読者・日付・クライアント名

### 1行サマリ

- 左：白カード＋赤の上線、ヘッドライン Georgia 24pt navy bold
- 真ん中：ゴールドの右矢印アイコン
- 右：紺カード＋ゴールドの上線、ヘッドライン Georgia 24pt white bold

### 登場人物

- 4枚のカードを横並び（カード幅 2.15"、ギャップ 0.13"）
- 各カード：上半分が紺背景（アイコン白）、下半分が白（タイトル/数字/説明）
- 数字は Georgia 32pt ゴールド

### 全体像（AS-IS / TO-BE）

3段構成：
1. 上：代理店ボックス（ROUNDED_RECTANGLE、白）
2. 中：NEXT ONE / プラットフォーム（紺塗り、4ツール or 3ステージ）
3. 下：外部システム（白カード + 色の枠線）

### スイムレーン（ステップ詳細）

スライドの上下を AS-IS / TO-BE に分割：

| 領域       | y範囲       | 高さ |
|-----------|------------|------|
| AS-IS スイムレーン | 1.30 - 3.15 | 1.85" |
| ゴールドリボン     | 3.18 - 3.24 | 0.06" |
| TO-BE スイムレーン | 3.25 - 5.20 | 1.95" |
| 効果バッジ         | 5.27 - 5.59 | 右下 |

各スイムレーン内：
- レーンラベル列：x=0.45 - 1.90、紺背景＋白文字
- 工程列：x=1.90 - 9.70 を slots（4-6）等分
- レーン高：4本なら 0.39"、5本なら 0.31"
- カードの内パディング：x方向 0.06"、y方向 0.06"

### カード（アクション）

- 矩形、塗り色は `fill` フィールドに従う
- ラベルは中央・縦中央揃え、Calibri 9pt bold
- `tag`：上部レーン（lane=0）では下に、それ以外では上に配置（タイトルバーとの被り回避）

### 矢印

- Line shape、太さ 1.6pt
- 端に三角矢印（`endArrowType: "triangle"`）
- 双方向の場合は両端に矢印（`beginArrowType: "triangle"`）
- **必ず `flipH` / `flipV` で向きを表現する**。`w` や `h` を負にしない（pptxgenjs の既知バグで描画されない）

### ステップごとの効果バッジ

スライド右下、ROUNDED_RECTANGLE のゴールド塗り：
```
効果: マッピング作業ほぼ消滅
```

### 横軸の構造変化

3列のテーブル：観点 / AS-IS / TO-BE。
- 観点列：紺背景＋白文字
- AS-IS 列：赤 30% 透明背景の見出し
- TO-BE 列：緑 30% 透明背景の見出し
- 大きな数字は Georgia 26pt（AS-IS は赤、TO-BE は緑）

### まとめ

- 背景：NAVY_DK
- ヘッドライン：Georgia 36pt 白
- 中段：3つの統計カード（紺背景＋ゴールド枠）
- 下段：ゴールドのリボンに決め台詞（紺文字 16pt bold）

## 視覚的モチーフ

このデザインは以下のモチーフを反復させている：

1. **ゴールドの細いライン / バー** — タイトルの下、表紙左、まとめのリボン。「視線の起点」を作る
2. **紺の塗り＋ゴールドの文字** — 主役カードの定型。AI Agent カードはこの組み合わせで強調
3. **赤系（AS-IS） vs 緑系（TO-BE）** — 全スライドで対比を一貫させる
4. **カード型** — 情報単位はすべて矩形（角丸はステージのみ）。情報の粒度を視覚的に統一

## やってはいけないこと

- **Georgia で日本語本文を書く** → 文字抜けが起こる
- **fill: GOLD のカードに color: WHITE** → コントラスト不足。`color: NAVY_DK` を指定する
- **AS-IS 側を緑、TO-BE 側を赤** → 一貫性が壊れる
- **矢印を `w: x2-x1` で描く** → 負値だと描画されない。`Math.abs` + `flipH/flipV`
- **タグを上部レーンの上に配置** → タイトルバーと被る（`scripts/generate_deck.js` で自動回避済み）
- **タイトル下にアクセント線を入れる** → AI生成スライドの典型的なアンチパターン。空白で表現する
