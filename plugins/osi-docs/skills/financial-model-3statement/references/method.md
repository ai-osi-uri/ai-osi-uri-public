# 財務3表 フル連動の作法（method）

このスキルの核心は「PL・BS・CF を別々に書いたうえで、最終的に CF が BS の現金に一致する」3表連動を、月次60ヶ月で関数だけで成立させること。AI OSI URI の事業計画モデル（参照フォーマット）に準拠する。`reference-format.md` も併読のこと。

## 1. 連動のさせ方（最重要）

一般的な簡易モデルは「CF を先に作り、その期末現金を BS の現金にプラグ（代入）」する。本スキルは逆で、**参照モデルと同じ作法**を採る。

1. **PL** … 売上・原価を「ドライバー階層（ファネル）」で積み上げ、当期純利益まで出す。
2. **BS** … 現金以外の各勘定を独立に転がす（売掛金は入金サイト、仮払/仮受消費税は累積→決算期で納付/還付、繰越利益剰余金＝前月＋当期純利益、資本金＝前月＋増資…）。そのうえで

   **現金及び預金(t) = 前月現金 − Σ(現金以外の資産の増減) + Σ(負債・純資産の増減)**

   とする。現金が他の全勘定の動きを吸収するので、**資産 = 負債 + 純資産 が構造上成立** → `Balance Check（資産−負債−純資産）= 0` が常に成り立つ。
3. **CF** … BS の前月差分から営業/投資/財務CFを**独立に再構築**し、CF 自身の期末現金を持つ。

   - 営業CF = 当期純利益 − Δ売掛金 − Δ仮払消費税 + Δ買掛金 + Δ未払法人税 + Δ仮受消費税
   - 投資CF = −Δ固定資産（本テンプレはアセットライトで 0）
   - 財務CF = Δ資本金 + Δ資本準備金（＝増資）
   - CF期末現金 = 前月BS現金 + 当月CF
4. **連動Check** … `CF期末現金 − BS現金 = 0`。BS現金を同じ差分から組んでいるので必ず一致する。**この2本のCheck（Balance Check と 連動Check）が全60ヶ月で0であることを必ず検証する**（`verify.py`）。浮動小数の丸めで 1e-6 以下の残差は許容。

> なぜ2本のCheckか: 「BSが独立して閉じている」ことと「独立に組んだCFがBSに一致する」ことを別々に保証するため。これが参照モデルの“正しい3表連動”。

## 2. コンサバな立ち上がり

- **採用 ≠ 即戦力**。`採用→稼働 成熟ラグ（月）`（既定3ヶ月）と `成熟稼働率`（既定90%）で、稼働CAを `稼働CA(t) = INDEX(月末CA人数, t − ラグ) × 稼働率` と遅らせる。初月から売上が立たない。
- コストは月末CA人数（実数）で先に発生する（人件費・ロイヤリティ）。よって**先行赤字→資金トラフ**が必ず出る。これが資金需要の本質。

## 3. 消費税（仮払/仮受）と入金サイト

- 仮受消費税 = 売上 × 税率を会計年度内で累積、決算期替わり（`MOD(月番号−1,12)=0`）にリセット（＝前年度分を納付）。
- 仮払消費税 = 課税仕入（FCロイヤリティ＋スクール運営費＋課税対象の販管費）× 税率を同様に累積・リセット。給与・法定福利は非課税のため課税仕入に含めない（`taxable_sga` で制御）。
- 売掛金 = 前月 + 当月売上 − 消し込み（`売上回収サイト` ヶ月前の売上を回収）。
- 注：納付/還付の現金影響は「現金=全勘定増減」式が自動で捕捉する。タイミングは決算期一括の簡易版。

## 4. 税

参照モデルに合わせ `法人税 = IF(税引前>0, 税引前×実効税率, 0)` を月次で適用（年内の損益通算はしない）。黒字月に課税されるため保守的。年内通算を厳密化したい場合は FY累計税引前ベースに変更する。

## 5. 必要資金（資金トラフ）の出し方

- 「現金残高（増資ゼロ想定）」行＝創業資本＋Σ(営業CF＋投資CF)（増資を入れない現金推移）。
- その **最小値が資金トラフ＝必要資金**。サマリーに「必要資金」「推奨調達額（＋20%バッファ・1千万円切上）」を自動表示。
- 運用：まず `raise` を全0で生成→`verify.py` でトラフ確認→必要額（＋バッファ）を `raise` の該当月に入れて再生成→「調達後 最低現金 > 0」を確認。

## 6. 他業種への転用

BS/CF の連動機構（§1）と消費税・運転資本・税・資金トラフ（§3〜5）は**業種非依存**でそのまま使える。差し替えるのは **PL の売上・原価ドライバー行ブロックだけ**（本テンプレは「稼働CA→送客→成約→紹介売上／受講料売上」「CA人数→人件費・ロイヤリティ／受講者→スクール費」）。SaaS なら「新規/継続社数→MRR」、受託なら「案件数×単価」等にドライバー行を置き換え、原価も人員ドライバーに合わせる。`generate_model.py` の `# PL funnel` ブロックを編集する。
