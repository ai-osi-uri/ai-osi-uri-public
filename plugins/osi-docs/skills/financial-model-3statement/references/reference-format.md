# 参照フォーマット（AI OSI URI 事業計画モデル）の構造メモ

本スキルは AI OSI URI の `事業計画_r7.xlsx`（財務三表・月次/年次）の作法を踏襲している。原本の要点を記録しておく（将来、原本に寄せて拡張する際の参照）。

## シート構成
- `【計画】財務三表（月次）` … 期初(基準値)列＋72ヶ月。1シートに IncomeStatement → Balance Sheet → CacheFlow Statement を縦に並べる。
- `受託売上` … 受注案件一覧（パイプライン）。
- `【計画】財務三表（年次）` … FY 列（2月決算, FY25〜）に月次を集約。

## ドライバー階層
- A〜I 列のインデント深さで階層を表現（c2=表合計／c3=区分／c4=科目／c5以下=ドライバー）。
- 数値は階層に関わらず同じ値列（期初列＝J、月列＝K..）に入る。
- 売上は単価×社数ではなく「累積リード→成約率→新規契約→継続→契約社数」のファネルで積む。原価は「契約数→内製可能数→外注案件数(CEILING)→単価」。

## 3表連動の肝（原本の該当行）
- BS 現金（行179）= 前月現金 + Σ(他BS勘定の増減)。→ Balance Check（行261）= 資産−負債−純資産 = 0 が構造的に成立。
- CF（行265〜）= BS差分から独立に再構築。CF期末現金（行302）。
- 連動Check（行303）= CF期末現金 − BS現金 = 0。
- 消費税：仮払（196-199）/仮受（237-240）を累積し、決算期替わり `IF(L$3<>K$3,…)` で納付/還付。
- 法人税（行170）= `IF(税引前>0, ×税率, 0)`。
- 売掛金（183-185）= 当月売上 + 消し込み（入金サイト）。

## 本スキルでの簡略化（原本との差分）
- 月数を 60（5カ年）に、決算は単純な12ヶ月区切り（原本は2月決算72ヶ月）。
- インデントは列分割ではなく全角スペースで表現（可読性は同等、編集が容易）。
- 固定資産・借入・営業外は 0（アセットライト前提）。必要時に行を足す。
- 消費税の納付/還付は決算期一括の簡易タイミング。

原本に完全準拠（2月決算・72ヶ月・固定資産/借入あり）へ拡張する場合は、`generate_model.py` の月数・決算月判定・BS勘定行を原本に合わせて追加する。
