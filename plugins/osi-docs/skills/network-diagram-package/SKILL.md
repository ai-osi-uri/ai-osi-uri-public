# Network Diagram Package

一つの構造化正本から全成果物を生成し、図ごとの転記差を防ぐ。

## 前提

- 入力は確認済み `network-source.json`
- P0不確実点が0件
- 出力形式、用紙、言語、機密表示が確定

## 成果物

1. **物理構成図** — 拠点、部屋、ラック、設置位置、実ケーブル。
2. **論理構成図** — L2/L3境界、ネットワーク、VLAN、回線、冗長系。
3. **接続表** — From/To機器・ポート、媒体、長さ、ラベル。
4. **BOM** — メーカー、型番、品名、数量、単位、確定状態、根拠。
5. **未確定一覧** — 仮型番、未計測長、支給品、施工確認事項。

## ワークフロー

1. 入力スキーマとID重複、孤立接続、数量を検査する。
2. 物理図は設置場所を主軸に、論理図は通信関係を主軸にレイアウトする。
3. エッジ交差を減らし、長距離・別ページ接続には同一参照IDを付ける。
4. BOMは機器、モジュール、ケーブル、ラック用品、電源用品を別カテゴリに集計する。
5. 型番が未確定なら候補とせず `TBD` にし、必要仕様を記載する。
6. PPTX/XLSXをレンダリングして切れ、重なり、読めない文字を確認する。
7. 図、接続表、BOMのID・台数・接続数を相互照合する。

## 表現規則

- 機器ID、接続ID、BOM IDは全成果物で共通。
- 色だけで状態を区別せず、線種・ラベルも併用。
- 物理接続と論理接続を同じ線で混在させない。
- 推奨品と現有品、確定とTBDを明確に分ける。
- Webで型番を補完する場合はメーカー公式情報と確認日を残す。

## 完了条件

- JSON上の全機器が物理図または除外一覧に存在する。
- 全接続の両端が解決されている。
- BOM数量が機器・接続表と一致する。
- P0未確定がなく、P1/P2が一覧化されている。
- PPTX/PDF/XLSXを実際に開いて視覚確認済み。
