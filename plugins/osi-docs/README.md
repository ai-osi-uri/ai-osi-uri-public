# osi-docs

AI OSI URI の文書・契約・業務フロー・事業計画・構成図作成。

## スキル一覧

- `pptx-custom`
- `nda-creation`
- `business-flow-asis-tobe`
- `business-plan-builder`
- `financial-model-3statement`
- `architecture-proposal`
- `deck-composition`
- `storyline-gate`
- `company-financial-report` — 対象企業の業績・財務分析レポート（証券アナリスト形式・出資/買収検討用）をWeb一次情報調査からWord納品まで一気通貫で作成
- `wiring-diagram-intake` — 手描き配線図や現場メモを構造化
- `network-diagram-package` — 物理・論理ネットワーク構成図とBOMを生成
- `wiring-diagram-package` — 入力整理から構成図・BOM・確認事項まで一括生成
