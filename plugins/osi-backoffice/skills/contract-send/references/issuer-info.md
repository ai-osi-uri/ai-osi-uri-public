# 自社情報（契約チェック用の正本）

契約書の「自社（多くは乙、または甲）」欄が自社情報と一致しているかを確認するために使う。
相違があれば「要確認」として人に提示する（勝手に書き換えない）。

> 値は **連結フォルダ直下の `osi-profile.md`**（雛形: `config/osi-profile.example.md`）から読む。
> このファイルには実値を書かない。プロファイルが無い、または `{{ }}` のプレースホルダのままの場合は、
> 契約処理に入る前に停止し、利用者の自社情報を確認してプロファイルを作る。

| 項目 | 参照キー | 備考 |
|------|-----|-----|
| 正式法人名 | `{{company.name}}` | 登記どおり（全角/半角・スペース・記号を含めてそのまま） |
| 読み | `{{company.name_kana}}` | |
| 表示用の社名 | `{{company.name_display}}` | 書類タイトル等の読みやすい表記。契約当事者欄には使わない |
| 法人番号 | `{{company.corporate_number}}` | 13桁 |
| 本社所在地 | `{{company.address}}` | 登記上の表記と一致させる（階数の有無に注意） |
| 電話番号 | `{{company.phone}}` | |
| 代表者 | `{{company.representative}}` | 例: 代表取締役 山田 太郎 |
| インボイス登録番号 | `{{company.invoice_registration_no}}` | T+13桁。適格請求書発行事業者公表サイトで確認済みの値を入れる |

## 表記ルール（重要）

- **契約当事者欄は登記どおりの正式名称**（`{{company.name}}`）を使う。全角/半角・スペース・ハイフンの種類まで一致させる。
- 表示用の表記（`{{company.name_display}}`）を書類タイトル等で使う場合があるが、契約当事者欄には使わない。
- 過去の書類に別表記が混ざっていても、それに合わせない（登記名が正）。

## 既定の社内署名者（自社側）

- 既定：`{{company.representative}}`（メールは送付時に `AskUserQuestion` で確認）。
- 案件により担当者が署名する場合は人に確認する。

## チェック時の注意

- 社名の表記ゆれ（全角/半角・スペース・ハイフン・「株式会社」の前後）に注意。**登記どおりの正式名称**と一致しているかを見る。
- 住所が旧住所のままになっていないか（移転履歴があれば人に確認）。
- 上記の値が変わった場合は、プロファイル（`osi-profile.md`）を更新する。このファイルは更新しない。
