# contract-send セットアップ

**電子署名の道具は AI電子契約（URL でつなぐコネクタの `esign_*`）です（2026-11-02〜）。** DocuSign からは移行しました。

---

## 1. 会社で1回：AI電子契約をオンにする（運営）

管理コンソールの「会社」→ その会社 →「電子契約」タブで「使う」にする。送り手の名前・月の上限もここで決める。
オンにした会社のメンバーには、URL でつなぐコネクタに `esign_*` の道具が出る（新しい会話から）。

## 2. 各自：設定は要らない

URL でつなぐコネクタにつないでいれば、そのまま使える。チャットで `esign_status` が `enabled: true` を返せば準備完了。
画面で送るときは `https://sign.ai-osi-uri.info`（ツールポータルのアカウントでそのまま入れる）。

## 3. DocuSign で送付中のもの

新しくは送らない。送付中の封筒だけ、DocuSign の中で最後まで終わらせる（`ds_status`・`ds_get_envelope`・`ds_save_documents`）。
送付中がなくなったら DocuSign は解約してよい。
