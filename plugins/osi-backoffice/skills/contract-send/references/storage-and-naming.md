# 格納先・命名・送付メタ

契約の正本は Drive の**契約書フォルダ**（`{契約書ルート}`）。マウント済み共有ドライブに書くと Drive に同期される。

> **`{契約書ルート}` は組織ごとに違う。**値はプロファイルの `{{paths.contracts}}`（または
> `osi-finance-settings` の契約書フォルダ）から読む。**具体名をスキルに直書きしない**——移行のたびに壊れる。
> 実際の値は台帳の「雛形マスタ」のファイルパス先頭、または `osi-finance-settings.md` から解決する。

## ディレクトリ方針

```
{契約書ルート}/
├─ 01.契約書雛形/                     # 比較用の自社雛形（読み取り）
├─ 02.締結済み契約（発注）/           # 自社が「受け取る／発注する」側の契約
│   └─ {カテゴリ}/                    # 例: 01. 開発外注契約 / 02.税理士顧問契約 …
│       └─ _送付中/                   # ← 送付ドラフト/送付中のPDFとメタ（本スキルが作成）
└─ 03.締結済み契約（受注）/           # 自社が「顧客に署名依頼する」側の契約
    └─ {ID}.{企業名}/                 # 例: 30.NITOH（PJT番号と揃える）
        └─ _送付中/                   # ← 送付ドラフト/送付中のPDFとメタ（本スキルが作成）
```

### どちらに入れるか
- **受注（自社が顧客へ署名依頼を送る）**：`03.締結済み契約（受注）/{ID}.{企業名}/_送付中/`
  - `{ID}.{企業名}` は営業管理表のZ列（案件ID）＝ `{{paths.projects}}/` のフォルダ番号に合わせる。該当フォルダが無ければ作成（既存の命名に倣う）。
- **発注（顧問・外注など自社が受け取る側）**：`02.締結済み契約（発注）/{カテゴリ}/_送付中/`
- 判断に迷うときは人に確認する。

### 署名完了後
- 署名完了を確認できたら、`_送付中/` から該当の確定フォルダ直下へ移し、**完成（署名済）PDF**を保存する。
- 本スキルは送付までが主担当。完了確認・移動は別途（人 or 後続運用）で行ってよい。

## ファイル命名
- 送付PDF：`{相手先}_{契約名}_{YYYYMMDD}.pdf`
  - 例：`株式会社EveryWiLL_秘密保持契約書_20260624.pdf`
- 送付メタ：`_送付メタ_{契約名}_{YYYYMMDD}.md`

## 送付メタ テンプレート
`_送付中/` に置く（任意。AI電子契約の契約の画面と記録に同じことが残るので、台帳で追うなら省いてよい）。**一時的に開けるリンク（10 分のダウンロード URL など）は書かない**。

```markdown
# 送付メタ：{契約名}

- 相手先：{会社名}
- 区分：受注 / 発注
- 契約種別：NDA / 業務委託 / レベニューシェア / その他
- 送付日時：{YYYY-MM-DD HH:MM JST}
- AI電子契約の契約 ID：{id}（画面 https://sign.ai-osi-uri.info/{id}）
- ステータス：draft（下書き）/ sent / partially_signed / completed / declined / canceled / expired
- 署名者：
  - 甲：{氏名}（{会社名} / {肩書}）<{email}> 順番=1
  - 乙：{{company.representative}}（{{company.name}}）<{email}> 順番=2
- CC：{あれば}
- 書類の置き場の相対パス：03.契約書/送付前/{相手先}_{契約名}_{YYYYMMDD}.pdf（締結済みは 03.契約書/締結済/ に自動で置かれる）
- チェック結果：問題なし {n} / 要確認 {n} / 要修正 {n}（主な論点：…）
- 備考：
```
