# ホテルの予約

本人の出張のホテルを取る。Claude は **調べる・選ぶ・確定の手前まで進める** ところまでを受け持つ。
パスワード・認証コード・カードの番号やセキュリティコード・本人認証は、本人が自分で入れる。
使うブラウザは本人の Chrome（Claude in Chrome）。本人のログインがそのまま使えるため。

## 前提（本人ごとに違うもの）

初めて使うとき、次を確かめて Claude のメモ（本人の記憶）に残す。2 回目からは聞き直さない。

- 使っている予約サイト：まずメールを `(ホテル OR 宿泊) (予約確認 OR 予約完了)` で探し、実際に使っているサイトを並べる。登録済みのサイトで新規登録をさせない
- 会社で決まった予約サイト・1 泊の上限金額・支払い方（会社のカードか立替か）・領収書の宛名があるか（osi-profile か会社の決まりにあれば、それに従う）
- 好み：予算、禁煙、朝食、大浴場、シングルかダブルか、駅からの近さと行き先からの近さのどちらを優先するか

## 手順

### 1. 何を取るかを決める（聞く前に調べる）
- カレンダーで、その日の予定から行き先（住所・会場）・チェックインの目安（最後の予定の終わり）・泊数を読む
- 新幹線も同じ出張で取るなら、着く駅と時刻をそろえる
- 本人に確かめるのは、泊数と人数が予定から読めないときだけ

### 2. 候補を 3 つ出す
- 本人の使うサイトで、日付・人数・場所で探す（ログインしなくても見られることが多い）
- 好みと上限で絞り、次を表にして 3 つ出す：ホテル名／1 泊の金額（税込・合計）／行き先までの距離と行き方／キャンセルの期限と料金／朝食・禁煙
- 一番のおすすめに理由を一言添える（例：会場まで徒歩 5 分、キャンセルは前日まで無料）
- 場所は地図でも出す
- 検索画面の金額は参考。確定の画面の金額が最終

### 3. 選んでもらい、ログインを先に済ませてもらう
- 本人が番号で選んで OK したら、そのサイトにログインしてもらう。ログインは本人の 1 か所の操作だけにし、その間 Claude はサイトを触らない

### 4. 確定の手前まで進める（間を空けない）
- プラン・部屋・人数・日付を選び、宿泊者の情報は会員情報のまま（無いところは本人に聞く）
- 領収書の宛名欄があれば、会社の決まりの宛名を入れる
- 支払いは登録済みのカードか現地払いを、会社の決まりに合わせて選ぶ
- 確認画面で止めて、ホテル・日付・部屋・金額・キャンセルの期限を添えて「準備できた」と知らせる

### 5. 確定は本人が押す
- カードのセキュリティコード・本人認証（3D セキュア）・確定ボタンは本人

### 6. 確かめて報告する
- 予約完了のメールで、予約番号・ホテル・日付・部屋・金額・キャンセルの期限を確かめて報告する
- カレンダーに宿泊の予定（チェックイン〜チェックアウト、住所、予約番号、キャンセルの期限）を作る（社外の人は招かない）
- 領収書が出たら、OSI Finance があれば receipt-intake に回すよう一言添える

## 落とし穴

- **確認画面は時間切れになる**：知らせたらすぐ押してもらう
- **ログインの取り合い**：本人のログインと Claude の操作が重なると戻れなくなる。同じ操作を 3 回以上くり返さず、タブを閉じて 1 か所からログインし直すよう案内する
- **「返金不可」プラン**：安くてもキャンセルできない。出す候補には、返金不可かどうかを必ず書く
- **金額の見え方**：サイトによって税・サービス料・宿泊税が別。比べるときは合計で並べる

## やらないこと

- パスワード・認証コード・カード番号・セキュリティコード・本人認証を Claude が入れること
- 本人の OK なしに確定ボタンを押すこと、新しいアカウントを作ること
- カード番号をメモやカレンダーに残すこと（カードは呼び名と下 4 桁まで）
