# 旧版（S3 経由の署名付きURL方式）— 2026-08-17 に廃止

DocuSign への契約書の渡し方を、**自前コネクタ（ai-osi-uri-finance の `ds_create_envelope`）が
base64 で直接送る方式**に変えたため、ここにあるものは使わない。

## なぜ廃止したか
汎用 DocuSign MCP コネクタの `createEnvelope` が `documents[].remoteUrl` しか受け付けず、
base64 の入り口が無かった。そのため「非公開S3に一時的に置いて署名付きURLを教える」という
回避策を組んでいた。

**しかしこれは DocuSign の制約ではない。** eSignature REST API 本体は
`documents[].documentBase64` を受け取る。回避策そのものが不要だった。

## 何が要らなくなったか
- AWS（S3 バケット `aiosiuri-contract-staging-135728714359`・federation token・`call_aws`）
- Supabase Storage（代替として検討していたもの）
- 一時ファイル・一時公開URL・その有効期限管理・事後削除
- `call_aws` の提供終了（2026-08-31）という期限

## 残してある理由
同じ回避策を将来また必要とする API に出会ったときの参考。
**S3 バケットは残っているので、不要なら削除してよい**（このスキルからは参照していない）。
