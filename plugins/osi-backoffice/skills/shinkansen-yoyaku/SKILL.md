# 新幹線の予約（えきねっと／スマートEX）

本人の移動の新幹線・特急を、JR の公式のネット予約で取る。Claude は **調べる・選ぶ・確定の手前まで進める** ところまでを受け持つ。
パスワード・認証コード・カードの番号やセキュリティコード・カード会社の本人認証（3Dセキュア）は、本人が自分で入れる。
使うブラウザは本人の Chrome（Claude in Chrome）。本人のログインがそのまま使えるため。

## 0. どこで取るか（行き先で分ける）

| 乗る路線 | 使うもの | 理由 |
|---|---|---|
| 東北・北海道・上越・北陸・山形・秋田新幹線、JR東日本の特急 | **えきねっと**（新幹線eチケット） | 東日本はえきねっとが公式で割引もある |
| 東海道・山陽・九州新幹線（名古屋・京都・大阪・博多方面） | **スマートEX** | この区間はスマートEXが安く、仕事向けの車両（S Work）も取れる。えきねっとでは S Work 車両は取れない |
| 東京をまたいで両方に乗る（例：仙台→大阪） | 路線ごとに分けて取るか、えきねっとで通しで取るかを、金額を並べて本人に聞く | |

どちらも早めに取ると安くなる割引がある。日程が決まっているなら早めに取ることを勧める。

## 前提（本人ごとに違うもの）

初めて使うとき、次を本人に確かめ、Claude のメモ（本人の記憶）に残す。2 回目からは聞き直さない。

- 予約に使うサイトのアカウントがあるか（えきねっとは JRE ID、スマートEX は会員登録）。無ければ「初回の登録」へ
- 登録しているメールアドレス（認証コード・申込完了のメールが届く先。つながっている Gmail で読めるか）
- 支払いに使う登録済みのカード（呼び名と下 4 桁だけ。番号は控えない）
- 乗るときに使う IC カード（Suica など）が登録済みか
- 席の好み（普通車／グリーン、窓側／通路側、移動中に仕事をするか）

移動中に仕事をする人には、仕事向けの車両（東日本は TRAIN DESK、東海道は S Work）を案として出す。

## 手順（どちらも同じ流れ）

### 1. 何を取るかを決める（聞く前に調べる）
- 本人のカレンダーで、その日の予定から行き先・時刻を読む（予定の説明欄に「東京駅12:36発」のような便が書いてあることが多い）
- 行き先から、えきねっとかスマートEXかを決める（0. の表）
- 予約サイトのトップに出ている「荒天」「運休」のお知らせを開き、その路線が対象かを見る
- 空席を調べる（ログインしなくても見られることが多い）
- 予定とぶつかる会議があれば一言添える
- 本人に確かめるのは、席の種類と、同行者の分も取るか、だけ。便は予定から出した案を見せて「それでいいか」を聞く

### 2. 購入のOKをもらう
- 使うサイト・列車名・区間・時刻・席の種類・1 本あたりの金額・合計を表で見せて、購入してよいか聞く
- 検索画面の金額は参考。確定の画面の金額が最終

### 3. ログインを先に済ませてもらう（ここが大事）
- 列車を選ぶ前に、本人にログインしてもらう
  - えきねっと：トップ右上の「ログイン」→「JRE IDでログイン」。右上に「マイメニュー」が出ていればログイン済み
  - スマートEX：トップのログインから。会員メニューが出ていればログイン済み
- ログインは本人の 1 か所の操作だけにする。Claude は本人がログインしている間、そのサイトを触らない
- 途中でログインを求められても、Claude がログインボタンを何度も押し直さない

### 4. 確定の手前まで進める（間を空けない）

**えきねっと**
1. JRきっぷ申込 → 乗車駅・降車駅・日付・時刻（発車の数分前）を入れて検索
2. 目的の列車の「きっぷ・座席の種類選択へ進む」
3. 「新幹線eチケット」→「指定席から選ぶ」→ おとなの料金を選ぶ
4. 座席の指定（「どの座席でもよい」か、窓側・通路側）→「申込内容を確認する」
5. 確認画面で、登録済みのカードを選んだ状態にする

**スマートEX**
1. 新規予約 → 乗車駅・降車駅・日付・時刻を入れて検索
2. 目的の列車と席の種類（普通車指定席・S Work など）を選ぶ
3. 座席を選ぶ（希望がなければおまかせ）
4. 確認画面まで進める
- スマートEXは乗車券と特急券がセットで、特急券だけは買えない

どちらも、ここで止めて本人に「準備できた」と知らせる。号車・席番号・金額を添える。

### 5. 確定は本人が押す
- えきねっと：セキュリティコード（カード裏の 3 桁）を入れて「この内容で確定」
- スマートEX：カード会社の本人認証（3Dセキュア）が必ず入るので、その画面も本人が通す
- 往復のときは、1 本確定してから次の 1 本を同じ流れで進める

### 6. 確かめて報告する
- 予約のメールが届く Gmail で申込完了のメールを探し、1 本ずつ予約番号・列車・号車と席・金額を確かめて報告する
  - えきねっと：「【申込完了】申込内容（JRきっぷ）のご案内」と「【ICカード情報登録・変更完了】」。申込完了メールの「IC番号：未登録」は表示上のもので、IC カード連携完了のメールが届いていればよい
  - スマートEX：スマートEXからの予約完了のメール
- カレンダーの移動の予定に、予約番号・列車・席・金額を書き足す。帰りの移動の予定が無ければ作る（社外の人は招かない）

## 初回の登録（アカウントが無いとき）

- えきねっと：今の新規登録は JRE ID で行う。登録画面は Claude が開き、氏名・ふりがな・電話・生年月日など本人が決めている項目を入れる
- スマートEX：初めて東海道・山陽・九州方面を取るときに登録する。進め方は同じ
- 規約の同意・パスワード・認証コード・クレジットカードと IC カードの登録は本人
- 認証コードやワンタイムパスワードのメールは、つながっている Gmail から探して本人に伝える（入力は本人）。有効期限は 10〜15 分ほどなので、届いたらすぐ伝える
- 登録が済んだら、上の「前提」を本人のメモに残す

## 落とし穴

- **確認画面は時間切れになる**：確定の手前で長く置くと、申込が自動で取り消され、ログインも外れる。「準備できた」を伝えたら、すぐ押してもらう
- **ログインの取り合い**：本人のログインと Claude のやり直しが重なると、サイトに戻る画面がエラーになり、ログインできない状態が続く（えきねっとでは JreidInfomationLink / AuthorizationEndpointResponseAPI の画面）。そうなったら Claude は手を止め、本人に「タブを全部閉じて、1 か所からログインし直す」（だめならそのサイトの Cookie を消す、またはシークレットウィンドウ）を案内する。同じ操作を 3 回以上くり返さない
- **ログイン後はトップに戻る**：選んでいた列車は外れるので、ログインしてから選び直す（だから先にログイン）
- **ユーザー ID を思い出せないとき**：ID の問い合わせをしてもメールが来なければ、アカウント自体が無いことが多い。「初回の登録」へ
- **えきねっとのカード登録にもワンタイムパスワードが要る**：会員情報の変更画面でメールが届く。有効期限は 10 分ほど
- **乗車券の特例が無い**：新幹線eチケットもスマートEXも「東京都区内」などの特例が効かず、新幹線の駅までの在来線は IC カードの残高から引かれる

## やらないこと

- パスワード・認証コード・カード番号・セキュリティコード・本人認証を Claude が入れること
- 本人のOKなしに確定ボタンを押すこと
- カード番号や IC カードの番号をメモやカレンダーに残すこと（カードは呼び名と下 4 桁まで）
