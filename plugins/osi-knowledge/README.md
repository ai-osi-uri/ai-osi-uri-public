# osi-knowledge

知識管理。会話や会議の記録を「考えて答えるための知識」に育てる一式と、Google Calendar の空き時間取得。

## スキル一覧

| スキル | 役割 |
|---|---|
| `knowledge-setup` | 整える。Obsidian を入れる案内から、置き場の形を作り、最初の一件と最初の一問まで |
| `obsidian-knowledge-capture` | 集める。記録 → 事例 → 型 |
| `knowledge-bundle` | 束ねる。型 → 本質。入口の一覧を作る |
| `obsidian-knowledge-consult` | 答える。本質と言葉の二つの入口から入り、必ず具体まで降りて答える |
| `knowledge-compare` | 確かめて直す。読み方や決まりを、伏せて比べて決め直す |
| `calendar-free-time` | Google Calendar の空き時間取得 |

決まり（置き場所・答え方・書き方・比べ方）の正本はノートの側にある。どのスキルも最初に `90_決まり/決まり.md`（無ければ `90_Meta/決まり.md`）を読む。
