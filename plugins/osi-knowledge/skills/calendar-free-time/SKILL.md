# カレンダー空き時間表示スキル

ユーザーのGoogle Calendarから空き時間を取得し、見やすいコンパクトなフォーマットで表示する。

## 手順

### 1. 期間の特定

ユーザーの発言から対象期間を判断する。

- 「来週」→ 次の月曜〜金曜
- 「今週」→ 今日〜今週の金曜
- 「明日」→ 翌日のみ
- 明示的な日付指定があればそれに従う
- 曖昧な場合は確認する

### 2. Google Calendarから空き時間を取得

`gcal_find_my_free_time` ツールを使って空き時間を取得する。

パラメータ:
- `calendarIds`: `["primary"]`
- `timeMin`: 対象期間の開始（RFC3339形式、タイムゾーンなし）
- `timeMax`: 対象期間の終了（RFC3339形式、タイムゾーンなし）
- `timeZone`: `Asia/Tokyo`
- `minDuration`: 60（デフォルト1時間。ユーザーが別の条件を指定した場合はそれに従う）

### 3. 結果のフィルタリング

取得した空きスロットを以下の条件でフィルタリングする:

- **営業時間帯のみ**: 9:00〜18:00の範囲に切り詰める（9:00より前に始まるスロットは9:00開始に、18:00より後に終わるスロットは18:00終了に調整）
- **最小時間**: デフォルト1時間以上。ユーザーが「30分以上」「2時間以上」など指定した場合はそれに従う
- **営業日のみ**: 土日は除外する（ユーザーが明示的に含めるよう指示した場合を除く）

### 4. 出力フォーマット

以下のフォーマットで出力する。チャットUIではプレーンテキストの改行が無視されて1行につながってしまうため、必ずMarkdownのコードブロック（` ``` `）で囲んで出力すること。これにより改行が保持され、ユーザーがそのままコピペできる。

出力例:

````
```
月曜日 4/13（月）
10:00 - 12:30
16:00 - 18:00
水曜日 4/15（水）
11:30 - 16:00
木曜日 4/16（木）
15:00 - 18:00
金曜日 4/17（金）
11:30 - 18:00
```
````

#### フォーマットのルール

このフォーマットは厳密に守ること。ユーザーは出力をそのままコピペして他の人に送ったり、予定調整に使うため、余計な情報が入ると困る。

- **コードブロック必須**: 出力は必ず ` ``` ` で囲む。囲まないとチャットUI上で改行が消えて1行になってしまう
- **日付ヘッダー**: `曜日 M/D（曜日略）` の形式（例: `月曜日 4/13（月）`）
- **時間帯**: `HH:MM - HH:MM` の形式。1行に1スロット。インデントなし
- **空きがない日は表示しない**（スキップする）
- **所要時間は書かない**（「2時間30分」などの記載は不要）
- **箇条書き記号は使わない**（「-」「・」「•」などを時間帯の先頭に付けない）
- **前後の挨拶・補足説明は不要**。コードブロック内にフォーマットされた空き時間リストだけを出力する
- 日付ヘッダーと時間帯の間、および日ごとのブロック間に空行は入れない
