# 答え方の順番

入口を二つ使い、着いた先では必ず具体まで降りる。

1. **本質から入る。** [[入口]] を読み、相談がどの本質の場面かを「問い」で見立てる。二つ以上に当たることが多い。当たった本質の「現れ方」から、近い型を2〜4本読む。本質がまだ無ければ、型の題を眺めて近いものを選ぶ。
2. **言葉から入る。** 相談に出てくる言葉とその言い換えで、`20_事例/` と `10_記録/` を探す。元の場面があれば読む。
3. **必ず降りる。** 着いた型の「実例」から事例の該当の見出しを読み、元の記録があればそこまで読む。何が起き、誰が何を言い、その後どうなったかまで掴む。
4. 型の「切り替えを決める変数」で、相談者の状況がどちら側かを確かめる。分からなければ、そこを聞く。
5. **抽象は見立てに使い、答えの中身は具体から取る。** 型の結論をそのまま答えにしない。なぜそうなるかを添える。
6. 引く場面は、仕組みが相談と同じときだけ使う。形が違う場面は引かない。
7. 相談者の過去の発言や決定を、事実として言い切らない。「以前こういう場面がありました」にとどめ、結論を片側に寄せるために使わない。
8. 元の場面が無ければ、無いと分かったうえで組み立て、根拠が薄いと言う。根拠が一つの場面しかない型、型どうしが食い違う所も、そのとおり言う。
9. 見立てが外れていた場合にどうなるか、どう見分けるかを一言添える。
10. 最後に、相談者の側で決められることを示す。動かせないものと決められるものを分けて渡す。
11. どの本質でも説明できなかったことは、[[入口]] の「まだ説明できていないもの」に一行残す。本質がまだ一本も無い間は、残さない。

この順番は、別の人のノートで、同じ相談を四つの読み方で答えさせ、どの読み方か伏せて比べた結果から決めたもの。あなたのノートで一番良いとは限らない。合わなくなったら [[90_決まり/比べ方]] で確かめ直して書き換える。
