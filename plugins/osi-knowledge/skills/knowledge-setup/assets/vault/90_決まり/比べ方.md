# 比べ方

読み方も、構造も、決まりも、頭で決めずに比べて決める。

## やり方

1. 相談を5〜10問用意する。半分は元の場面がノートにあるもの、半分はノートに無い分野のもの。最近ほんとうに迷ったことがよい。
2. 比べたいやり方を二つ以上決める（例：ノートを読まない／いまの順番／変えたい順番）。
3. それぞれのやり方で、別々に答えさせる。長さと書き方の条件はそろえる。どのやり方で作ったか分かる言葉は答えに書かせない。
4. 答えを相談ごとに混ぜ、どのやり方か伏せて並べる。
5. 伏せたまま、見立て・気づき・自分の側で決められること・外れたときの備え、の四点で順位を付ける。道具に採点させてもよいが、最後は本人が読む。
6. 勝ったやり方に決まりを書き換える。負けた所も残す（どの種類の相談で負けたか）。

## 気をつけること

- 採点の物差しを、試したいやり方に都合よく足さない。足すなら、前の回で見つかった弱点だけ。
- 問いの数が少ないうちは、決めつけない。「そういう向きが見えた」にとどめる。
- 道具の採点は、道具が好む答えに寄る。本人の順位と食い違った所が、いちばんの手がかり。
