# 決まり

このノートの集まりは、人が考えて答えるための知識として持つ。置くのは正解ではなく本質。正解は場面ごとに変わる答えで、本質は多くの場面の下に共通してある「人や物事はこうできている」という性質。答えは、状況と本質を掛け合わせて、その都度作る。

**決まりの正本はこのフォルダのノート。** 道具（スキル）は、まずここを読んでから動く。決まりを変えたいときは、ここを書き換える。

## 置き場所

| 置き場所 | 置くもの |
|---|---|
| `00_受け箱/` | まだ分けていないもの。一週間以上置かない |
| `10_記録/` | 会話や会議の記録そのまま。`日付_題.md`。書き換えない |
| `20_事例/` | 出来事のまとまり（相手・案件・取り組み）ごとに一本。実際に起きた場面を書く。固有の名前・金額・経緯・発言はここに置く |
| `30_型/` | 本質がある場面でどう現れるか。名前を外し、役と変数で書く |
| `40_本質/` | 性質を一文で書いたもの。少数 |
| `50_人/` | 人ごとに一本 |
| `90_決まり/` | このフォルダ |
| `入口.md` | 本質の一覧と、まだ説明できていないもの |

## 名前の付け方

- 記録：`日付_題.md`。日付は出来事のあった日を `2026-01-31` の形で。分からなければ取り込んだ日を使い、ノートの中に「日付は要確認」と書く
- 事例：`（相手や取り組みの呼び名）_事例.md`。名前が分からなければ、役の呼び名で（例：`知り合いの店主_事例.md`）
- 型と本質：題がそのままファイル名。固有の名前や数字を入れない。45字まで、句読点なし
- どのノートも、`updated:` には書いた日を入れる

## 四つの段

具体（記録・事例）→ 型 → 本質 → 入口。型から事例へ、本質から型へ、リンクで降りられるようにする。抽象は「これはどういう場面か」を見立てるのに使い、答えの中身は具体から取る。

## 人が決めること

消す、まとめる、本質を足す・変える、は人が決める。道具は案を出すところまで。各ノートの「自分の言葉で一行」の欄は本人が書く。

## 書いてはいけないもの

人の私生活、健康、家族の事情など、その人が知られたくないだろうこと。暗証や口座の番号。
