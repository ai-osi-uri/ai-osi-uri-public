# 取り戻せる判断は任せ取り戻せない判断だけ一緒に手間をかける

本質：（まだ無い）

## 結論

どの判断に手間をかけるかは、間違えたとき後から取り戻せるかで決まる。取り戻せるものは任せ、取り戻せないものだけ、決める前に一緒に手間をかける。

## 構造

**切り替えを決める変数：間違えたとき、後から取り戻せるか**
- 取り戻せる → 任せる。口を出さない。
- 取り戻せない → 決める前に、後悔する筋書きを先に出してみる。

## なぜ成り立つか

理由はまだ語られていない。

## たとえば
