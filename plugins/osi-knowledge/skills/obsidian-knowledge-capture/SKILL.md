# 集める（obsidian-knowledge-capture）

## §0 定義と不変条件

**取り込んだ** とは、①記録がそのまま置かれ、②使える場面が事例に切り出され、③必要なら型が一本足され（または既存の型に実例が足され）、④何をどこに書いたかの報告が出た状態を指す。

導出の型：**決まりを読む → 記録を置く → 場面を切り出す → 型を探す（足すか、作るか、作らないか）→ 報告する**。

不変条件（破ったら失敗）：

- **最初に決まりを読む。** 決まりの入口は `90_決まり/決まり.md`。無ければ `90_Meta/決まり.md`。そこに、置き場所の名前と、答え方・書き方・比べ方のノートの場所が書いてある。読むのは決まりの入口と、そこが指す「書き方」のノート。どちらの入口も無ければ、下の「ノートの置き場が無いとき」に進む（会社の知識も使えなければ `knowledge-setup` を案内して止まる）。置き場所の名前も書き方も、そこに書いてあるものを正とする。このスキルに書き方を写さない
- **記録は書き換えない。** 要約に置き換えない。読みにくくても、そのまま置く
- **新しく作る前に探す。** 同じ変数の型が既にあれば、そこの「たとえば」と「実例」に足す。型が増えるのは、既存のどれでも説明できないときだけ
- **無理に型にしない。** 具体を抜くと中身が残らないもの（手順、道具の使い方、計画）は、決まりが指す別の置き場へ
- **理由を作らない。** 型の「なぜ成り立つか」には、元の場面で語られた理由だけを書く。無ければ「理由はまだ語られていない」
- **本質は足さない・変えない。** 型の親を書くのは、既にある本質に当たるときだけ
- **人の私生活や、知られたくないだろう事情は書かない。** 迷ったら本人に聞く。人名・社名は記録の表記のままにし、確かめられないものは「要確認」と付ける
- **「自分の言葉で一行」の欄は空ける。** 本人が書く欄
- 消す・まとめる・置き場を動かす、は案を出すまで。決めるのは本人

事故の型：記録を要約で置き換えて元の言い回しが消える／似た型を探さずに作って同じ型が増える／語られていない理由をもっともらしく書く／固有の名前や金額を型の本文に残す／一度に十本の型を作って本人が見切れない（一件の記録から作る型は多くて二、三本）。

## 手順

1. **決まりを読む**（上のとおり）。`見本/` は、形の参考にだけ読んでよい。中身は使わない
2. **入力を受ける。** 貼られた文章、つながったフォルダの中のファイル、受け箱に置かれたもの。どれを取り込むか曖昧なら一つだけ聞く
3. **記録を置く。** 決まりが指す記録の置き場へ、`日付_題.md` で、そのまま
4. **場面を選び、型を探す。** あとで例として使えそうな場面を選ぶ。場面ごとに、型のフォルダを題と変数で探す。①同じ変数の型がある → その型を使う　②無く、別の場面にも持っていける → 新しい型の題を決める　③持っていけない → 型にしない
5. **事例を書き、型に足す（または作る）。** 事例のノートに、型の名前の見出しと、その下に場面の小見出しを立てて書く。何が起き、誰が何を言い、どうなったか。元の記録へのリンクを一行。型にしない場面は「型への紐づけなし」の見出しの下に置く。そのあと、既存の型なら実例（と、必要なら「たとえば」）に足し、新しい型ならひな形で作る
6. **人のノート。** 新しく出てきた人で、今後も出てきそうな人だけ。ひな形（人）で、記録にあることだけ書く
7. **報告する。** 何をどこに書いたか（場所つき）／既存の型に足したものと新しく作ったもの／型にしなかったものとその理由／迷った所・要確認／型の本数（決まりが言う本数を超えたら「束ねますか」と一言）

道具：つながったフォルダを直接読み書きする。Obsidian の接続しか無い環境では、その道具で同じことをする。

## ノートの置き場が無いとき（会社の知識に入れる）

Obsidian のノートの置き場（つないだフォルダか Obsidian の接続）が無く、道具 `secretary_knowledge` が使えるときは、会社の知識（サーバー側。秘書と同じ置き場）に入れる。

- **会社の全員が見る置き場だと、本人に最初に一言伝える。** 個人のメモとして残したいものは入れない（`knowledge-setup` でノートの置き場を作るよう案内する）
- 記録の全文は入れない。記録から、別の場面にも持っていける学び・決まりごと・やり方だけを、一件ずつ `topic`（短い見出し）と `fact`（何が起き、どうしたらうまくいったか。理由は語られたものだけ）にする
- 入れる前に、入れる一覧（見出しと中身）を本人に見せ、OK をもらってから `action=learn` で入れる。一件の記録から入れるのは多くて三件
- 人の私生活・知られたくない事情・お金の数字・相手先の内情は入れない。人名・社名は記録の表記のまま
- 同じ見出しが既にあれば置き換わる。似た見出しを先に `action=recall` で探し、足すか置き換えるかを本人に聞く
- 報告：入れた見出しの一覧／入れなかったものと理由／記録そのものの置き場（会話の中か、ドライブなど）
