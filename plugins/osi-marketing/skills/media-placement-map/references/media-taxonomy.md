# 掲載先メディアの3類型 — 見分け方と探し方

「ランキングサイトに載りたい」という要望は、実務上まったく性格の違う3つの媒体群に分かれる。
混ぜて一覧にすると攻め方を誤るので、必ずこの3列で切る。

---

## A. 一括資料請求ポータル

**実態**：ユーザーが条件を入れると複数社に一括で資料請求・見積依頼が飛ぶ。掲載企業は反響（リード）を買う。

**見分け方**
- ユーザー側の主要CTAが「一括資料請求」「まとめて見積」「無料相談」
- 掲載企業向けの別ドメイン／別サブディレクトリ（`*-business.*`、`/partner/`、`/info/contact/`）を持つ
- 「提携◯◯社」「累計利用者◯万人」を掲げている

**料金体系の3パターン**
| 型 | 内容 | 掲載側のリスク |
|---|---|---|
| 掲載課金 | 月額固定 | 反響ゼロでも払う。最もリスクが高い |
| 反響課金 | 問い合わせ1件ごと | 初期費用ゼロが多く、最も始めやすい |
| 成約課金 | 成約金額の数% | 固定費ゼロだが、率が自社の利益配分と競合する |

**探し方**
1. `<業種> 一括資料請求 比較サイト 掲載費用`
2. `<業種> ポータルサイト 掲載 反響課金`
3. 集客支援メディア（キャククル等）の「◯◯の比較サイトまとめ」記事 → **ただし二次情報。必ず一次で裏を取る**
4. 媒体資料DB（メディアレーダー等）で `<業種>向け` を横断

**注意**
- ロゴ掲載順・課金ティアが「実質の序列」になっていて、ランキングという名前が付いていないことが多い。それも陣取り対象として採る。
- 大手が抜けているポータルがある（例：SUUMO注文住宅に積水ハウス・三井ホーム・ヘーベルハウスは不在）。
  「誰がいないか」も強い情報なので必ず記録する。

## B. 特化型比較メディア

**実態**：テーマを絞った比較サイト。「◯◯特化」「エリア特化」。掲載企業は枠を買う。

**見分け方**
- ドメインがテーマそのもの（`平屋.com`、`ゼロエネ住宅.com` 的）
- `/host/`、`/company/`、運営者情報ページに**制作会社の名前**が入っている
- **同一運営会社が何十本もサイトを持っている**ことが多い。1本問い合わせれば全部の枠が買える

**料金の実態**
「月額掲載型・要問い合わせ」と書かれていても、実態は**専用メディアを1本つくる制作商品**（初年度数百万円規模）であることがある。
「既存メディアの枠買い」なのか「メディア新規制作」なのかを商談で必ず切り分ける。

**探し方**
1. `<テーマ> <業種> 比較 ポータル 掲載`
2. 見つけた1本の `/host/` から運営会社を特定 → その運営会社の**サイト一覧**を辿ると同系列が芋づるで出る
3. エリア特化：`<都道府県> <業種> 比較 掲載`

**このカテゴリが最も狙い目になる理由**
- 掲載社数が少ない（数社〜数十社）ので、入るだけで上位に見える
- テーマが狭い分、そのテーマの定量スペックを持っていれば正面から勝てる
- 運営リソースが薄いサイトが混ざっており（未完成のダミーテキストが残っている等）、**枠の交渉余地が大きい**

**注意**
- サイトのフッター著作権表記が `Copyright (C) 【PR】◯◯` になっている＝**サイト全体がPRメディア**。中立媒体として扱わない。
- 免責に「◯年◯月時点の情報を基に制作」とある場合、コンテンツが数年更新されていない可能性。鮮度を商談で確認する。

## C. 記事型ランキング

**実態**：「◯◯おすすめランキング10選」記事。**多くは直接買えない。**

**収益モデルの見分け方**
| 型 | 見分け方 | 掲載される方法 |
|---|---|---|
| ASP送客型アフィリエイト | 記事の最終CTAが**一括資料請求ポータル**に飛ぶ | **A類型のポータルに加盟する**のが唯一の実質ルート |
| 自社送客型 | 自社の無料相談・診断に誘導し、そこから企業を紹介 | 運営会社に直接、提携可否を照会 |
| 広告枠販売型 | `business.*` など法人向け広告事業ページを持つ | PR表記付きの枠を買う |
| 実調査型 | 大規模な実利用者アンケート（数千〜万人規模・評価項目を開示） | **買えない。**満足度そのものを上げる長期施策 |

**確認すること**
- **PR表記の有無**（「広告」「PR」「本記事は広告を含みます」「送客手数料を受領しています」）
- 評価基準の記載。**記載なしのメディアが実在する**。それ自体を記録する
- 評価項目に「月間検索数」等が入っていないか → 入っていれば**広告出稿量がそのまま順位に効く**構造

**この類型の順位の正体**
棟数・売上・知名度の写像であることがほとんど。1位が媒体間で割れるのは、**何を数えたかの違い**にきれいに対応する。
したがって記事型の順位を追いかけても差別化にならない。**A類型とB類型に資源を寄せるべき**という結論になりやすい。

**絶対にやらないこと**
PR表記なしでの有償上位掲載の打診。`stealth-marketing-guard.md` 参照。

## D. 業界固有の第4類型（該当すれば足す）

| 事業形態 | 追加で見るべき媒体 |
|---|---|
| FC本部・代理店本部 | 加盟店募集メディア（＝施主向けとは別チャネル。料金を公表している媒体がある） |
| BtoB | 業界団体の会員一覧／媒体資料DB／業界紙 |
| 補助金・認証が絡む事業 | 公的機関の登録事業者一覧（無料・掲載ではなく登録。広告ではないが露出になる） |
| 多店舗・FC | **拠点名義での地域枠**。本部名義の全国枠と二重に取れる |

---

## 二重露出（多店舗・FC・代理店型の必須チェック）

本部名義で全国ランキングを狙うのと、**拠点名義でエリアランキングを狙う**のは別の戦い。両方取れる。

- 全国枠は椅子の数が少ない（例：25社の椅子取り）
- エリア枠は母数が小さく、拠点の地域実績（「県内◯年連続No.1」等）をそのまま訴求できる
- 実際に、本部名義では全国枠に不在なのに**加盟店名義でエリア枠の上位を取っている**FCが存在する

陣取り採取のとき、競合FCがどちらの型を選んでいるかを必ず記録する。
