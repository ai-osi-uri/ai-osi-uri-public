# 納品物のスキーマ

## Excel（8シート）

`xlsx` スキルを読んでから作る。フォントは日本語なら Meiryo。全シートでヘッダ行を固定（freeze_panes）、
データ行はオートフィルタを付ける。長文セルは `wrap_text=True` + `vertical="top"`。

### 00_README
構成・読み方の注意・取得できなかったもの・法規制の注意。A列だけ幅130で散文。

### 01_掲載候補サイト
```
優先度 / 分類 / サイト名 / 運営会社 / 料金体系 / 金額の目安 / 審査 /
規模・特徴 / 自社との相性・メモ / 掲載申込／法人向けURL
```
- 分類は3類型（＋第4類型）の値で統一する
- 閉鎖・失効したサイトは削除せず「除外」行として残す（他資料に載っているため、除外した事実に意味がある）

### 02_陣取り一覧 ★本体
```
分類 / サイト / ランキング名 / 順位 / 会社名 / 事業形態区分 /
その枠で売られているもの（訴求軸・原文に近い形） / 価格 / スコア・保証等 /
集計根拠 / PR表記 / 出典URL
```
- **1行1レコードの縦持ち。** サイトごとに表を割らない
- `順位` は数値型（COUNTIFS の条件に使う）。順位付けが存在しないケースは `0`
- 上位5枠の外でも、競合として重要なら記録してよい（例：14位のFC本部）。順位列で後から絞れる
- `順位` 列のヘッダにセルコメントで「順位の意味はサイトごとに異なる。集計根拠列を併読すること」と入れる
- freeze_panes は会社名列まで（例 `E4`）

### 03_占有集計 ★数式
```
会社名 / 上位5枠への登場回数 / うち1位獲得数 / 記事型での登場 / ポータルでの登場 / 特化型での登場
```
値を貼らず COUNTIFS で書く。02を直せば自動追随する。

```
=COUNTIFS('02_陣取り一覧'!$E$4:$E$179,$A4,'02_陣取り一覧'!$D$4:$D$179,"<=5",'02_陣取り一覧'!$D$4:$D$179,">=1")
=COUNTIFS('02_陣取り一覧'!$E$4:$E$179,$A4,'02_陣取り一覧'!$D$4:$D$179,1)
```
分類別は第3条件に `'02_陣取り一覧'!$A$4:$A$179,"記事型"` を足す。

注意：
- シート名にスペースや記号があるとクロスシート参照でクォートが要る。シート名は `NN_名前` 形式で統一する
- `XLOOKUP` / `FILTER` / `UNIQUE` / `SORT` は使わない（LibreOffice で評価できず `#NAME?` になる）
- 表記ゆれ（「パナソニックホームズ」と「パナソニック ホームズ」等）はサイトごとの原文をそのまま残し、
  集計シートの注記で「合算して見ること」と書く。無理に正規化すると原文の証拠性が落ちる

### 04_訴求軸マップ
```
訴求軸 / 占有している企業 / 頻出コピー（原文に近い形） / 占有度 / 自社の勝機
```
行の塗り分け：緑＝空いている／黄＝条件付き／赤＝正面から取りに行っても勝てない。

### 05_競合マトリクス
直接競合（同じ事業形態のプレイヤー）× 各媒体の露出クロス表。最終行に**自社の現在地**を置く。
「差別化ワード」「戦い方の型」の2列を必ず持つ。

### 06_空白ポジション
```
評価(◎○✕) / 軸 / 現状（誰も取っていない／既に埋まっている根拠） / 自社の打ち手
```
◎○だけでなく **✕（取りに行っても勝てない軸）も同じ重さで書く**。

### 07_打ち手
```
優先度 / やること / なぜ効くのか / 費用の目安 / 窓口URL
```
最終行に「やらない」行（＝法規制上やってはいけないこと）を必ず置く。

## HTML アーティファクト

結論と根拠を1枚で読ませる。Excelの代わりではなく併走させる。

構成：
1. ヘッダ（対象製品の前提を1段落）
2. **前回資料からの訂正**（あれば最上部。閉鎖・失効・社名変更）
3. 類型ごとの陣取り表（1〜5位＋訴求軸＋集計根拠）
4. 直接競合マトリクス
5. 空白ポジション（カード形式。空き＝緑ボーダー／埋まっている＝赤ボーダー）
6. 打ち手（番号付きステップ）
7. フッターに取得日・取得不可リスト

自己完結HTML（CSS/JSインライン）。localStorage は使わない。再訪する種類の成果物なので永続アーティファクト化する。

## 品質チェック（納品前）

- [ ] 全レコードに出典URLが付いているか
- [ ] 「集計根拠」列が全レコード埋まっているか（不明なら「記載なし」と明示）
- [ ] 訴求軸が**原文に近い形**か（要約しすぎて元のコピーが消えていないか）
- [ ] 推測で埋めた金額・社数がないか（非公開は「非公開」）
- [ ] 取得できなかったサイトが明示されているか
- [ ] 掲載先の生死をWebFetchで確認したか（二次情報だけで載せていないか）
- [ ] 空白ポジションだけでなく「勝てない軸」も出しているか
- [ ] 単一の差別化ワードの候補を3つ出しているか
- [ ] `recalc.py` が `total_errors: 0` か、かつ **COUNTIFS の結果を data_only で読んで妥当性を目視したか**
      （数式が評価できることと、正しい値を返すことは別）
