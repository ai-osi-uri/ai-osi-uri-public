# Course Outline

逆向き設計を使い、学習成果 → 評価 → 学習活動 → 教材の順で構成する。

## ワークフロー

1. 対象者、前提知識、利用環境、時間制約を確認する。
2. 修了時の行動を、観察・採点できる動詞で3〜7件定義する。
3. 各成果を証明する評価課題と採点基準を作る。
4. 成果に必要な知識・技能を依存順に並べ、モジュール化する。
5. 各レクチャーへ説明、例、練習、フィードバックを配置する。
6. 総学習時間、認知負荷、アクセシビリティ、更新責任を確認する。

## 品質ゲート

- 「理解する」「学ぶ」だけの測定不能な成果を使わない。
- 成果に寄与しないレクチャーを入れない。
- 正解を教える前に、適切な練習機会を置く。
- 字幕、代替テキスト、読み上げ、色依存を考慮する。
- 第三者教材や画像の利用権を確認する。
- 資格・修了証が保証する範囲を誇張しない。
