# line-setup（LINE をつなぐ・確かめる）

道具は 2 か所にある。
- PC の AI OSI URI LINE 拡張：`login_status` / `login_qr` / `login_from_portal` / `list_chats`
- URL のコネクタ：`line_login_handoff`（ポータルで済ませたログインの受け取り URL）・`get_download_link` / `local_tools_status`（拡張を入れる・版を比べる）

**ふつうの流れは「このチャットの中で QR → PIN → 完了」。** 本人にブラウザやツールポータルの画面を開かせない。
QR コードも PIN も、このチャットに出す。本人がやるのは「スマホの LINE で QR を読む」「PIN を入れて承認する」の 2 つだけ。
ログインは「サブ端末」として行うので、スマホ・PC 版 LINE と同時に使える。チャットでログインしたログイン情報はこの PC の中だけに保存する。
拡張の既定は「読むだけ」。セットアップが終わっても、Claude から LINE は送らない。

PC の拡張の道具は、返事を 60 秒しか待てない。`login_status` の `waitSeconds` は **45 以下**にする（長くすると途中で切れる）。
待ちきれなかったら、同じ呼び出しをもう一度すればよい（状態を見るだけなので何度呼んでも害は無い）。

## 1. 拡張があるか・版を確かめる
1. `login_status`（`waitSeconds: 0`）を呼ぶ。
2. 呼べない（道具が無い）→ 拡張が入っていない。Claude が入れる：
   1. `get_download_link`（`product: "line-personal"`）で URL を取る。
   2. 返ってきた `install` の手順で、PC のシェル（Mac は `install.mac`、Windows は `install.windows`）か、ブラウザ（`install.browser`）で落として開く。どちらも使えないときは URL を見せて、本人に開いてもらう。
   3. Claude のデスクトップアプリに出る「インストール」だけ本人に押してもらう。押したら、このチャットで「入れた」と送ってもらう。道具が見えるようになったら、そのまま 2 へ進む（見えなければ、新しいチャットで「LINE のセットアップをして」と送ってもらう）。
   - `get_download_link` が「利用権がありません」「配布されていません」と返す・コネクタがつながっていないときは、ツールポータルの「詳細設定 → ツールインストール（DL）」の AI OSI URI LINE から落としてもらう。そこにも無ければ、その会社にまだ配っていないので、運営に頼むよう伝えて止める。
3. 結果に「拡張の版」が出たら、`local_tools_status`（`installed: {"line-personal": "<版>"}`）と比べる。`needs_update` なら 2 と同じ手順で入れ直してもらう（ログインは引き継がれる）。版が出ない（0.7.0 以前）・`login_from_portal` が無い（0.7.x 以前）ときも入れ直しを勧める。
4. 以前に別の LINE 拡張（自作版など）を入れていたら、Claude の「設定 → 拡張機能」で外してもらう。二重に動くと同じ名前の道具が 2 つ出る。

## 2. つなぐ
`login_status` の結果で分ける。

**「ログイン完了」** → もうつながっている。3 の確かめへ（ヘルスチェックのときもここ）。

**未ログイン** → まず `line_login_handoff` を 1 回だけ呼ぶ（本人がポータルで先にログインを済ませていた場合の受け取り）。
- `status: "ready"` → `claim_url` を拡張の `login_from_portal`（`claimUrl`）にそのまま渡す。URL は本人に見せない・ほかに使わない。「ログイン完了」と出たら 3 へ。
  - 「端末の種類」が違うと言われたら、その文のとおり本人に伝える。
- `status: "none"` / `"expired"` → ポータルには案内しない。そのまま下の「チャットでログインする」へ進む。

### チャットでログインする（ふつうはこれ）
1. 次を短く見せて、OK をもらう（初めてつなぐときだけ。OK が無ければ進めない）。
   > この LINE 拡張は非公式で、LINE ヤフー株式会社とは関係がありません。LINE の利用規約に反するおそれや、アカウントが制限されるおそれがあります。
   > ログイン情報はこのパソコンにだけ保存します。はじめは「読むだけ」で、Claude から LINE を送ることはありません。
   > この内容で進めてよいですか？
   - 本人が「つないで」「セットアップして」とはっきり頼んでいて、前にこの説明を受けて OK している（同じ会話で非公式であることを伝え済み）なら、聞き直さない。
2. `login_qr` を呼ぶ。結果に QR の画像・保存先・期限付き URL が出る。
   - QR 画像を**本人に見える形でチャットに出す**（ファイルを本人に送れる道具があれば画像を送る。無ければ結果の画像をそのまま見せる）。見えないと言われたら、保存先の画像を開いてもらう。
   - 一緒に、次をそのまま伝える：
     > スマホで **LINE アプリのアイコンを長押し** して、出てきたメニューの **「QR コードリーダー」** を開き、この QR コードを読み取ってください。
     > （長押しで出ないときは、LINE を開いて「ホーム」→ 右上の「友だち追加」→「QR コード」でも読み取れます）
     > 読み取ったら、スマホで「ログイン」を押してください。PIN をすぐここに出します。
3. 続けて `login_status`（`waitSeconds: 45`）を呼ぶ。PIN が出るまで、出なければもう一度呼ぶ（2〜3 回まで）。
4. PIN が出たら、**すぐこのチャットに大きく出す**（本人を待たせない。ほかの説明と混ぜない）：
   > **PIN：〇〇〇〇〇〇**
   > スマホの LINE に出ている入力欄にこの数字を入れて、承認してください。
   - 会話の途中で文を送れる道具（SendUserMessage など）があれば、それで PIN だけ先に送ってから次の呼び出しに進む。
5. もう一度 `login_status`（`waitSeconds: 45`）を呼び、「ログイン完了」と出たら 3 へ。出なければもう一度呼ぶ。

## 3. 確かめる（ヘルスチェック）
1. `list_chats`（`limit: 3`）を呼び、トーク名が出ることだけ確かめる。中身は読み上げない。
2. 本人に短く返す：ログインしている名前・端末の種類・拡張の版・最新かどうか（1 の 3）・読むだけかどうか。
   - 「保存済みのログイン情報が使えませんでした」と出たら、スマホ側でこの端末が外されている。2 の「未ログイン」からやり直してもらう。

## 4. 本人に伝えること（初めてつないだときだけ・短く）
- 「PC 版 LINE やスマホは、そのまま使えます。」
- 「いまは読むだけです。Claude は、未読のまとめ・返事をしていないトークの確認・返信の文の下書きができます。送るのはご自身で LINE から行ってください。」
- 「Claude から返信も送りたくなったら、Claude の『設定 → 拡張機能 → AI OSI URI LINE』で『読むだけ』を外し、新しいチャットで始めてください。送る前には必ず文と宛先をお見せして、OK をもらってから 1 通ずつ送ります。」
- 「画像やファイルを Claude が読んだときは、『ダウンロード/LINE（Claude）』に保存されます。」
- 始め方の例：「LINE の未読を見せて」「返事してない LINE ある？」「〇〇さんとの LINE を見せて」「〇〇さんへの返信を考えて」

## 困ったとき
| 様子 | すること |
|---|---|
| チャットの QR が切れた・読み取れない・「ログイン処理が途中で終了しました」 | `login_qr` を `restart: true` で呼び直し、新しい QR をチャットに出す |
| `login_status` が「60 秒以内に返事が無い」で切れた | `waitSeconds` を 45 以下にして、もう一度呼ぶ（状態を見るだけなので害は無い） |
| LINE アイコンの長押しで「QR コードリーダー」が出ない | LINE を開いて「ホーム」→ 右上の「友だち追加」→「QR コード」で読み取ってもらう |
| PIN を入れる画面がスマホに出ない | スマホの LINE を開き直す。出なければ `login_qr` を `restart: true` でやり直す |
| `line_login_handoff` が `expired` | ポータルの受け取りは 10 分で切れる。ポータルに戻さず、チャットでログインする |
| `login_from_portal` が「切れているか、もう使われています」 | ポータルに戻さず、チャットでログインする |
| PC 版 LINE がログアウトされる | 拡張の設定「接続する端末の種類」が DESKTOPWIN / DESKTOPMAC になっている。ANDROIDSECONDARY に戻してログインし直す |
| Android タブレットの LINE がログアウトされる | 拡張の設定を IOSIPAD にしてログインし直す |

メールアドレスとパスワードは、チャットに貼ってもらわない（拡張の設定欄に入れてもらう）。
やめたい・連携を解除したいときは line-basics の「連携を解除する」。
