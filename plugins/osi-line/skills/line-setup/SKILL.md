# line-setup（LINE をつなぐ・確かめる）

道具は 2 か所にある。
- PC の AI OSI URI LINE 拡張：`login_status` / `login_from_portal` / `login_qr` / `list_chats`
- URL のコネクタ：`line_login_handoff`（ポータルで済ませたログインの受け取り URL）・`get_download_link` / `local_tools_status`（拡張を入れる・版を比べる）

ふつうの流れは「本人がツールポータルの AI OSI URI LINE のページで QR（またはメール）→ PIN を済ませる → Claude に『LINE のセットアップをして』」。
ログイン情報はサーバーに 10 分だけ・一度きりで預けられ、拡張が受け取った時点でサーバーから消える。以降は PC の中だけ。
ログインは「サブ端末」として行うので、スマホ・PC 版 LINE と同時に使える。拡張の既定は「読むだけ」。セットアップが終わっても、Claude から LINE は送らない。

## 1. 拡張があるか・版を確かめる
1. `login_status`（`waitSeconds: 0`）を呼ぶ。
2. 呼べない（道具が無い）→ 拡張が入っていない。Claude が入れる：
   1. `get_download_link`（`product: "line-personal"`）で URL を取る。
   2. 返ってきた `install` の手順で、PC のシェル（Mac は `install.mac`、Windows は `install.windows`）か、ブラウザ（`install.browser`）で落として開く。どちらも使えないときは URL を見せて、本人に開いてもらう。
   3. Claude のデスクトップアプリに出る「インストール」だけ本人に押してもらう。押したら**新しいチャット**で「LINE のセットアップをして」と送ってもらう（道具が出るまで少しかかることがある）。
      ポータルのログインは 10 分で切れるので、間に合わなければポータルでもう一度ログインしてもらってから送ってもらう。
   - `get_download_link` が「利用権がありません」「配布されていません」と返す・コネクタがつながっていないときは、ツールポータルの「詳細設定 → ツールインストール（DL）」の AI OSI URI LINE から落としてもらう。そこにも無ければ、その会社にまだ配っていないので、運営に頼むよう伝えて止める。
3. 結果に「拡張の版」が出たら、`local_tools_status`（`installed: {"line-personal": "<版>"}`）と比べる。`needs_update` なら 2 と同じ手順で入れ直してもらう（ログインは引き継がれる）。版が出ない（0.7.0 以前）・`login_from_portal` が無い（0.7.x 以前）ときも入れ直しを勧める。
4. 以前に別の LINE 拡張（自作版など）を入れていたら、Claude の「設定 → 拡張機能」で外してもらう。二重に動くと同じ名前の道具が 2 つ出る。

## 2. つなぐ
`login_status` の結果で分ける。

**「ログイン完了」** → もうつながっている。3 の確かめへ（ヘルスチェックのときもここ）。

**未ログイン** → ポータルで済ませたログインを受け取る：
1. `line_login_handoff` を呼ぶ。
2. `status: "ready"` → `claim_url` を拡張の `login_from_portal`（`claimUrl`）にそのまま渡す。URL は本人に見せない・ほかに使わない。
   - 「ログイン完了」と出たら 3 へ。
   - 「端末の種類」が違うと言われたら、その文のとおり本人に伝える（ポータルで端末の種類を合わせてログインし直すか、拡張の設定を合わせる）。
3. `status: "none"` / `"expired"` → ポータルでのログインがまだか、10 分が過ぎた。本人に伝えて待つ：
   「ツールポータルの AI OSI URI LINE のページ（`portal_url`）で、同意にチェックして『QR コードを出す』を押し、スマホの LINE で読み取って PIN を承認してください。終わったら、ここで『LINE のセットアップをして』と送ってください。」
4. ポータルが使えない（開けない・ログインできない）と言われたときだけ、チャットでログインする（下の「チャットでログインする」）。

## 3. 確かめる（ヘルスチェック）
1. `list_chats`（`limit: 5`）を呼び、トーク名が出ることだけ確かめる。中身は読み上げない。
2. 本人に短く返す：ログインしている名前・端末の種類・拡張の版・最新かどうか（1 の 3）・読むだけかどうか。
   - 「保存済みのログイン情報が使えませんでした」と出たら、スマホ側でこの端末が外されている。2 の「未ログイン」からやり直してもらう。

## 4. 本人に伝えること（初めてつないだときだけ・短く）
- 「PC 版 LINE やスマホは、そのまま使えます。」
- 「いまは読むだけです。Claude は、未読のまとめ・返事をしていないトークの確認・返信の文の下書きができます。送るのはご自身で LINE から行ってください。」
- 「Claude から返信も送りたくなったら、Claude の『設定 → 拡張機能 → AI OSI URI LINE』で『読むだけ』を外し、新しいチャットで始めてください。送る前には必ず文と宛先をお見せして、OK をもらってから 1 通ずつ送ります。」
- 「画像やファイルを Claude が読んだときは、『ダウンロード/LINE（Claude）』に保存されます。」
- 始め方の例：「LINE の未読を見せて」「返事してない LINE ある？」「〇〇さんとの LINE を見せて」「〇〇さんへの返信を考えて」

## チャットでログインする（ポータルが使えないときだけ）
1. 次をそのまま見せて、はっきり OK をもらう。OK が無ければ進めない（ポータルでは画面で同意をもらっているので要らない）。
   > この LINE 拡張は非公式です。LINE ヤフー株式会社とは関係がなく、LINE の利用規約に反するおそれや、アカウントが制限されるおそれがあります。
   > チャットでログインしたときのログイン情報は、このパソコンにだけ保存し、提供元のサーバーには送りません。
   > はじめは「読むだけ」で、Claude から LINE を送ることはありません。送るようにするのは、あなたが設定を変えたときだけです。
   > この内容で進めてよいですか？
2. `login_qr` を呼ぶ。結果に QR の画像と保存先が出る。本人に「スマホの LINE の『ホーム』→ 右上の『友だち追加』→『QR コード』で読み取り、『ログイン』を押してください」と伝える。QR が見えないときは保存先の画像を開いてもらう。
3. `login_status`（`waitSeconds: 90`）で PIN が出たら、そのまま見せる：「スマホの LINE に入力欄が出ています。PIN 〇〇〇〇〇〇 を入れて承認してください。」
4. もう一度 `login_status`（`waitSeconds: 120`）を呼び、「ログイン完了」と出たら 3 へ。

## 困ったとき
| 様子 | すること |
|---|---|
| ポータルで QR の期限が切れた・読み取れない | ポータルの「やり直す」を押してもらう |
| ポータルで「メールアドレスかパスワードが違う」 | QR コードでログインしてもらう（LINE ID・電話番号ではログインできない） |
| `line_login_handoff` が `expired` | 10 分を過ぎた。ポータルでもう一度ログインしてもらう |
| `login_from_portal` が「切れているか、もう使われています」 | `line_login_handoff` をもう一度呼ぶ。それでも `none` なら、ポータルでログインし直してもらう |
| チャットの QR が切れた・「ログイン処理が途中で終了しました」 | `login_qr` を `restart: true` で呼び直す |
| PIN を入れる画面がスマホに出ない | スマホの LINE を開き直す。出なければ最初からやり直す |
| PC 版 LINE がログアウトされる | 拡張の設定「接続する端末の種類」が DESKTOPWIN / DESKTOPMAC になっている。ANDROIDSECONDARY に戻してログインし直す |
| Android タブレットの LINE がログアウトされる | ポータルの「端末の種類」と拡張の設定を、どちらも IOSIPAD にしてログインし直す |

メールアドレスとパスワードは、チャットに貼ってもらわない（ポータルの画面か、拡張の設定欄に入れてもらう）。
やめたい・連携を解除したいときは line-basics の「連携を解除する」。
