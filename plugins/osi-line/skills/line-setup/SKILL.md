# line-setup（LINE をつなぐ）

道具は AI OSI URI LINE 拡張（`login_status` / `login_qr` / `list_chats`）。
ログインは「サブ端末」として行うので、スマホ・PC 版 LINE と同時に使える（PC 版 LINE は落ちない）。
拡張の既定は「読むだけ」。セットアップが終わっても、Claude から LINE は送らない。

## 0. 手元の準備
1. `login_status`（`waitSeconds: 0`）を呼ぶ。
   - 呼べない（道具が無い）→ 拡張が入っていない。「1. 同意をもらう」を先に済ませてから、Claude が入れる：
     1. URL のコネクタの道具 `get_download_link`（`product: "line-personal"`）で URL を取る。
     2. 返ってきた `install` の手順で、PC のシェル（Mac は `install.mac`、Windows は `install.windows`）か、ブラウザ（`install.browser`）で落として開く。シェルもブラウザも使えないときは URL を見せて、本人に開いてもらう。
     3. Claude のデスクトップアプリに出る「インストール」だけ本人に押してもらう。押したら新しいチャットで「LINE をつないで」と送ってもらい、「2. QR コードでログイン」から続ける（道具が出るまで少しかかることがある）。
     - `get_download_link` が「利用権がありません」「配布されていません」と返す・コネクタがつながっていないときは、ツールポータルの「詳細設定 → ツールインストール（DL）」の AI OSI URI LINE から落としてもらう。そこにも無ければ、その会社にまだ配っていないので、運営に頼むよう伝えて止める。
   - 「ログイン完了」→ 結果の「拡張の版」を、コネクタの `local_tools_status`（`installed: {"line-personal": "<版>"}`）と比べる。`needs_update` なら上と同じ手順で入れ直してもらう（ログインはそのまま引き継がれる）。そのあと 3 の確認と 4 の案内だけして終わる。版が出ない（0.7.0 以前）ときも入れ直しを勧める。
2. 以前に別の LINE 拡張（自作版など）を入れていたら、Claude の「設定 → 拡張機能」で外してもらう。二重に動くと同じ名前の道具が 2 つ出る。

## 1. 同意をもらう（最初の 1 回）
次をそのまま見せて、はっきり OK をもらう。OK が無ければ進めない。

> この LINE 拡張は非公式です。LINE ヤフー株式会社とは関係がなく、LINE の利用規約に反するおそれや、アカウントが制限されるおそれがあります。
> ログイン情報はこのパソコンにだけ保存し、提供元のサーバーには送りません。
> はじめは「読むだけ」で、Claude から LINE を送ることはありません。送るようにするのは、あなたが設定を変えたときだけです。
> この内容で進めてよいですか？

## 2. QR コードでログイン
1. `login_qr` を呼ぶ。道具の結果に QR の画像と、画像の保存先が出る。
2. 本人に伝える：
   - 「QR コードを、スマホの LINE で読み取ってください。」
   - 読み取り方：LINE の「ホーム」→ 右上の「友だち追加」→「QR コード」→ 読み取る →「ログイン」。
   - QR が見えないときは、結果に出た保存先の画像ファイルを開いてもらう。
3. `login_status`（`waitSeconds: 90`）を呼ぶ。PIN が出たら、そのまま本人に見せる：
   「スマホの LINE に入力欄が出ています。PIN 〇〇〇〇〇〇 を入れて承認してください。」
4. もう一度 `login_status`（`waitSeconds: 120`）を呼び、「ログイン完了」と出たら次へ。

## 3. 終わりの確認
`list_chats`（`limit: 5`）を呼び、トーク名が出ることだけ確かめる。中身は読み上げない。

## 4. 本人に伝えること（短く）
- 「PC 版 LINE やスマホは、そのまま使えます。」
- 「いまは読むだけです。Claude は、未読のまとめ・返事をしていないトークの確認・返信の文の下書きができます。送るのはご自身で LINE から行ってください。」
- 「Claude から返信も送りたくなったら、Claude の『設定 → 拡張機能 → AI OSI URI LINE』で『読むだけ』を外し、新しいチャットで始めてください。送る前には必ず文と宛先をお見せして、OK をもらってから 1 通ずつ送ります。」
- 「画像やファイルを Claude が読んだときは、『ダウンロード/LINE（Claude）』に保存されます。」
- 始め方の例：「LINE の未読を見せて」「返事してない LINE ある？」「〇〇さんとの LINE を見せて」「〇〇さんへの返信を考えて」

## 困ったとき
| 様子 | すること |
|---|---|
| QR の期限が切れた・読み取れない | `login_qr` を `restart: true` で呼び直す |
| 「ログイン処理が途中で終了しました」 | `login_qr` を `restart: true` で呼び直す |
| PIN を入れる画面がスマホに出ない | スマホの LINE を開き直す。出なければ `login_qr` を `restart: true` でやり直す |
| 「保存済みのログイン情報が使えませんでした」 | スマホ側でこの端末がログアウトされている。`login_qr` からやり直す |
| PC 版 LINE がログアウトされる | 拡張の設定「接続する端末の種類」が DESKTOPWIN / DESKTOPMAC になっている。ANDROIDSECONDARY に戻して QR でログインし直す |
| Android タブレットの LINE がログアウトされる | 設定「接続する端末の種類」を IOSIPAD にして、QR でログインし直す |

メールアドレスとパスワードでのログイン（`login_email`）は、QR が使えないときだけ。パスワードはチャットに貼ってもらわず、拡張の設定欄に入れてもらう。
やめたい・連携を解除したいときは line-basics の「連携を解除する」。
