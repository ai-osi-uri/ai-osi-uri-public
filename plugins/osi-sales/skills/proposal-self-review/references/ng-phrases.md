## 提示直前のスキャン

pptx の例。LP / HTML / md でも同様に grep する。

```bash
# 社内ジャーゴン・上から目線・比喩（E15/16/18/19/20）
python -m markitdown deck.pptx | grep -nE "地雷|金脈|握(る|っ)|営業赤字|延命|衰退|性的|被害|餅|刺さ|打ち上げ花火|出すだけ|お金になる|構いません|もらってい|座組|お出しし|若手|裸で"

# 範囲を限定しない断定（E21）
python -m markitdown deck.pptx | grep -nE "(ご)?負担[はもがを]?(一切)?(ありませ|ございませ|生じませ|不要)|追加費用は?不要|費用は?(かかり|発生し)ませ|リスクは(ありませ|ございませ)|いつでも(解約|中止|やめ)|差し支えありません|問題ございません|そのままで結構です"

# 数量の断定（E22）。ヒット箇所ごとに、対応する図表の行数を数えて突き合わせる
python -m markitdown deck.pptx | grep -nE "[0-9０-９一二三四五六七八九]+ *(点|つ|項目|名|段階|ステップ|社|週間|ヶ月)(です|になります|あります|で進め)"
```

**誤検出は除外してよい**（「把握」「混入率」等の技術語の部分一致）。
ゼロ件にするのは目的ではなく、**1件ずつ見て判断する**ためのスキャン。
