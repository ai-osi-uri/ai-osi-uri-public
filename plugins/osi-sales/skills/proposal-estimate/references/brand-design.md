# ブランドデザイン規約（proposal-estimate 用）

CAIO_サービス紹介資料.pptx から抽出したブランドカラー。実際の描画は pptx / pptx-custom スキルに従い、配色はここを正本にする。

## カラーパレット

| 用途 | Hex | 説明 |
|------|-----|------|
| Primary Dark | `111827` | タイトル・クロージング背景、本文テキスト色 |
| Accent Red | `B91C1C` | アクセントバー、ボタン、バッジ、強調、見出しバー |
| Secondary Red | `C0392B` | セクションヘッダー、カード見出し背景 |
| Card Dark | `1F2937` | カード背景（暗め）、テーブルヘッダー |
| Card Dark 2 | `3D3D4F` | Phase/Step カード差別化用 |
| Light BG | `F7F7F7` | カード背景、テーブル偶数行 |
| Light Red | `FEF2F2` | 注釈・補足エリアの背景 |
| Text Medium | `4B5563` | 本文・説明テキスト |
| Text Light | `9CA3AF` | キャプション・補足テキスト |
| White | `FFFFFF` | 明るい背景、暗い背景上のテキスト |
| Green (sub) | `27AE60` | 成功・達成表示、フェーズ3 |
| Orange (sub) | `E67E22` | 警告・注意表示、フェーズ2 |

## フォント

- ヘッダー: `Noto Sans JP`
- ボディ: `Calibri`

## レイアウト（ダーク/ライト交互のサンドイッチ構造）

- タイトル＆クロージング: `111827` 背景 + 上部 `B91C1C` アクセントバー
- コンテンツ: `FFFFFF` 背景 + 上部 `B91C1C` アクセントバー
- カード: `F7F7F7` 背景 + `B91C1C` or `1F2937` ヘッダーバー
- 注釈ボックス: `FEF2F2` 背景 + `7F1D1D` テキスト
- 3フェーズの色: Phase1=`B91C1C`（赤）/ Phase2=`1F2937`（ダーク）/ Phase3=`3D3D4F`（チャコール）

> 週次ロードマップのヘッダ行は単色のダーク（`111827`）でニュートラルに。タスクのバーはワークストリーム別に色分けし凡例で示す（フェーズ色と兼用しない）。
