# 配色・フォント・レイアウト規約（proposal-estimate 用）

実際の描画は pptx / pptx-custom スキルに従う。**色とフォントはこのファイルに固定値を持たない。**

## 配色の決め方（優先順）

1. **自社の見積提案（自社が出す資料）** → `osi-profile.md` の `brand.*` を使う
   - `{{brand.primary_hex}}` = 主色 / `{{brand.accent_hex}}` = 強調色 / `{{brand.font_ja}}` = 日本語フォント / `{{brand.logo_path}}` = ロゴ
2. `brand.*` が空 → 下の**中立の既定パレット**（濃紺・グレー）で作り、報告の最後に
   「`osi-profile.md` の `brand:` に主色・強調色・フォント・ロゴを入れると自社の色で作れます」と1行案内する
3. 相手企業の社内向けに作る資料（相手の社内会議で使われる前提のもの）→ 相手企業の色（ロゴ・サイト）から取る

## カラーパレット（中立の既定。`brand.*` があれば Accent/Secondary をそれで置き換える）

| 用途 | Hex | 説明 |
|------|-----|------|
| Primary Dark | `111827` | タイトル・クロージング背景、本文テキスト色 |
| Accent | `{{brand.accent_hex}}`（未設定: `1E3A8A`） | アクセントバー、ボタン、バッジ、強調、見出しバー |
| Secondary | `{{brand.primary_hex}}`（未設定: `334155`） | セクションヘッダー、カード見出し背景 |
| Card Dark | `1F2937` | カード背景（暗め）、テーブルヘッダー |
| Card Dark 2 | `3D3D4F` | Phase/Step カード差別化用 |
| Light BG | `F7F7F7` | カード背景、テーブル偶数行 |
| Light Accent | `EFF6FF`（Accent を白で薄めた色） | 注釈・補足エリアの背景 |
| Text Medium | `4B5563` | 本文・説明テキスト |
| Text Light | `9CA3AF` | キャプション・補足テキスト |
| White | `FFFFFF` | 明るい背景、暗い背景上のテキスト |
| Green (sub) | `27AE60` | 成功・達成表示、フェーズ3 |
| Orange (sub) | `E67E22` | 警告・注意表示、フェーズ2 |

## フォント

- ヘッダー・ボディとも `{{brand.font_ja}}`（未設定: `Noto Sans JP`）
- 英字だけの欧文フォント（Calibri・Montserrat 等）を日本語本文に使わない（日本語が代替フォントに落ちて崩れる）

## レイアウト（ダーク/ライト交互のサンドイッチ構造）

- タイトル＆クロージング: `111827` 背景 + 上部 Accent バー
- コンテンツ: `FFFFFF` 背景 + 上部 Accent バー
- カード: `F7F7F7` 背景 + Accent or `1F2937` ヘッダーバー
- 注釈ボックス: Light Accent 背景 + Accent を暗くした色のテキスト
- 3フェーズの色: Phase1=Accent / Phase2=`1F2937`（ダーク）/ Phase3=`3D3D4F`（チャコール）
- ロゴ: `{{brand.logo_path}}` があれば表紙とクロージングに置く。無ければ社名テキストだけ

> 週次ロードマップのヘッダ行は単色のダーク（`111827`）でニュートラルに。タスクのバーはワークストリーム別に色分けし凡例で示す（フェーズ色と兼用しない）。
