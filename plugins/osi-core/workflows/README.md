# 型（ワークフロー）— スキルをどの順に、何を渡して、どこで止めるか

スキルは動詞、型は文法。**112 本のスキルを「どの場面で、どの順に、何を渡して、どこで人が決めるか」の 5 本の型に畳んだもの。**
新しい人が「同じ使い方」になるのは、スキルを入れたときではなく、この型をなぞったとき。

|---|---|---|---|---|
| 1 | [商談録音 → 提案書](01-shodan-to-proposal.md) | 「○○社の録音、提案まで持っていって」 | 1（議事録に Plaud/Drive）→ 0 | 60〜90 分 |
| 2 | [契約 → 請求 → 月次](02-contract-to-monthly.md) | 「契約が来た」「今月の請求」「月次を締めて」 | 1〜2（Gmail・MoneyForward・Finance） | 契約 10 分／請求 20 分／月次 60 分 |

## 1 枚の書式（全部この形）

- **いつ**：この型に入るきっかけ（人の一言・届くもの）
- **入力**：手元にあるもの（ファイル・URL・文字起こし）
- **連鎖**：スキルの順番。各行に「渡すもの → 受け取るもの」
- **止まる場所**：人が決める箇所。ここ以外で人に聞かない
- **出口**：成果物と置き場（案件フォルダの `03_制作・成果物/` など）
- **完了条件**：これが満たされていなければ「できた」と言わない（不変条件）
- **よくある事故**：この型で過去に起きたこと

## 使い方

型の番号か名前を言えば、Claude はその順で回す（「型 1 で」「契約→請求の型で」）。
途中から入るときは、入力を渡して「型 3 の Step 4 から」と言えばよい。型に無い場面は `osi-core:transcript-router`（貼って一言）に任せる。

会社固有の値（案件フォルダ・台帳・社名）は本文に無く、連結フォルダ直下の `osi-profile.md` から読む。
