# 型 5：議事 → ナレッジ → 次の一手

## いつ
会議・伴走セッション・商談が終わった直後（記憶が新しいうち）。次に同じ相手／同じ論点に当たる前。

## 入力
- 文字起こし・議事録・自分のメモ（長文で可）
- 相手（会社・人）と論点の名前

## 連鎖
| # | スキル | 渡すもの → 受け取るもの |
|---|---|---|
| 1 | `osi-core:transcript-router` | 長文＋一言（「まとめて」「本質と TODO」「知識化して」）→ 後続への振り分け |
| 2 | `osi-sales:session-review`（伴走セッションのとき） | 文字起こし → 前回宿題の進捗・論点・採用案と理由・決定・宿題・次回アジェンダの 1 枚＋横展開できる「伴走メソッド」「技術ナレッジ」 |
| 3 | `osi-knowledge:obsidian-knowledge-capture` | レビュー・気づき → vault に Concept／Resource／Inbox として保存（命名・frontmatter は vault の規約）。**vault が無い組織は案件フォルダの `05_受領資料/ナレッジ/` に md で置く** |
| 4 | `osi-knowledge:obsidian-knowledge-consult`（次に当たる前） | 相手・論点 → 過去のノートから「自分は前に何を考えたか」を `[[ノート名]]` 付きで引く |
| 5 | `osi-sales:discussion-prep` | 相手の会社 → vault の類似案件＋Web 調査 → 壁打ちの論点 3 点＋証拠レベル |
| 6 | `osi-sales:shodan-prep`（準備面） | 論点 → 期待値質問リスト・初回チェックリスト |

## 止まる場所
- 機微情報の線引き（顧客の個人情報・金額をノートに残すか）。迷ったら案件フォルダ側に置き、vault には論点だけ
- 「知識化」の粒度（会話全部ではなく、次に効く判断だけ）

## 出口
- vault（または案件フォルダ）に、次に引けるノート（出典＝どの会議の何分か）
- 次回の論点 3 点と質問リスト

## 完了条件
- 決定事項と宿題に担当・期限・完了条件がある
- ノートは「ゼロから生成した一般論」ではなく、この会社・この人の判断が書いてある（出典付き）
- 次に同じ論点に当たったとき、consult で引けた（引けなければ命名か置き場が悪い）
- 機微情報の線引きに従っている

## よくある事故
- 議事キャッシュを全部 vault に流し込んで、引けなくなる
- 一般論の要約で終わり「自分の判断」が残らない → 「なぜそれを選び、何を選ばなかったか」を必ず書く
