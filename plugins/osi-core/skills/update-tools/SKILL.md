# 道具を最新にする（update-tools）

本人が「最新にして」と言ったら、本人に手順を覚えさせずに、Claude がここまでやる。
本人にお願いするのは、Claude の手が届かない操作（画面の再読み込み・再起動など）だけ。

## 0. 不変条件

- サーバーの道具とスキル本文（get_skill）は、サーバーが新しくなった時点で全員に届いている。古いのは **Claude 側の控え**（道具の一覧・手元のプラグイン・設定に書いた決まり）だけ。直すのはそこ。
- 設定・プラグイン・コネクタの画面を変える操作は、何をどこで変えるかを一言見せて OK をもらってから行う。
- パスワードは入れない。サインインを求められたら本人にしてもらう。
- 消す操作（プラグインやコネクタを外す）はしない。外して入れ直すのは最後の手段で、本人に聞いてから。

## 1. いまの版を確かめる

1. 道具 getting_started を呼ぶ。返事の次の 3 つを控える。
   - 「道具の版」と「決まりの版」
   - 「この版の道具」の名前の一覧
   - 「手元のプラグインの入れ先」（マーケットプレイスの名前とリポジトリ）
2. いま自分に見えている道具の名前と、「この版の道具」を比べる（道具の名前は、前に付く接続名を外して比べる）。
   - 見えない道具がある → 2 へ（道具の一覧が古い）
   - 全部見える → 2 は飛ばす
3. 自分が読んでいる設定（Claude Code はユーザーの CLAUDE.md、Claude のアプリは覚え書きかプロジェクトの指示）にある、道具と働く決まりの節（getting_started が返す決まりと同じ見出しの節）の見出しのすぐ下にある版の目印（日付入りのコメント）を見る。
   - 目印の日付が「決まりの版」より古い、または節が無い → 4 で書き直す

## 2. 道具の一覧を読み直す

使っている場所で分ける。

- **Claude のアプリ（ブラウザ・デスクトップ）**
  1. ブラウザの道具（Claude in Chrome か、アプリ内のブラウザ）が使えるなら、本人の OK をもらって `https://claude.ai/customize/connectors` を開く。
  2. 道具を提供しているコネクタ（getting_started を返したもの）を選び、右上の「⋮」→「ツールリストを更新」を押す。
  3. 押したあと、本人に「新しい会話を開くと新しい道具が見えます」と伝える（いまの会話の道具の一覧は、会話の途中では増えないことがある）。
  4. ブラウザの道具が無いときは、上の 1〜2 を本人にやってもらうよう、画面の名前どおりに 1 行ずつ案内する。
- **Claude Code**：本人に `/mcp` を開いてこの道具のサーバーを選び「Reconnect」してもらう。うまくいかなければ Claude Code を再起動してもらう。
- **ほかの AI（Codex・Copilot など）**：その AI を再起動してもらう。

## 3. 手元のプラグインを最新にする

手元にプラグインを入れていない人は飛ばしてよい（スキルの本文は get_skill でいつも最新が読める）。

- **Claude Code**（シェルが使える）
  1. `claude plugin list` で、入れ先のマーケットプレイスから入っているプラグインを見る。
  2. `claude plugin marketplace update <マーケットプレイス>` を実行する。
  3. 入っているプラグインごとに `claude plugin update <名前>@<マーケットプレイス>` を実行する。
  4. 終わったら「Claude Code を再起動すると新しい版になります」と伝える。
- **Claude のアプリ**
  1. ブラウザの道具が使えるなら、本人の OK をもらって `https://claude.ai/customize/plugins` を開き、入れ先のマーケットプレイスの「自動的に同期」がオンかを見る。オフなら本人に聞いてオンにする。
  2. 「同期」や「更新」のボタンがあれば押す。
  3. ブラウザの道具が無ければ、同じことを本人に 1 行ずつ案内する。

## 4. 設定の決まりを書き直す

1 で古かったときだけ。

1. getting_started の「Claude の設定に書く決まり」の中身を、本人にそのまま見せる。
2. OK をもらったら、設定の、同じ見出しの決まりの節を丸ごと置き換える（節が無ければ足す）。ほかの節には触らない。
3. 書けない場所（Claude のアプリの覚え書きなど、Claude から書けないとき）は、貼る場所と貼る文を本人に渡す。

## 5. 報告する

短く、次の形で返す。

```
最新にしました。
- 道具：版 <道具の版>。新しく見えるようになった道具：<名前>（無ければ「変わりなし」）
- プラグイン：<更新したもの／自動で同期されています／入れていません>
- 決まり：<書き直しました（版 <決まりの版>）／最新です>
- 本人にお願い：<新しい会話を開く・再起動する、など。無ければ書かない>
```

## 事故リスト

- 道具の一覧を読み直しても、いまの会話には新しい道具が出てこないことがある。「失敗した」と言わず、新しい会話で確かめてもらう。
- 設定の節を置き換えるとき、本人が自分で書いた別の節まで消さない。置き換えるのは見出しから目印までの決まりの節だけ。
