# 手元の拡張を入れる・上げる（Deploy・Finance・Creative・Core・Ops host・LINE 共通・2026-10-16〜）

手元の拡張は、手元の PC が要る仕事のためだけに入れる。手元が要らない仕事は URL のコネクタの道具で進める。
**Claude が「落として開く」ところまで進め、本人には Claude のデスクトップアプリの「インストール」を1回だけ押してもらう**
（ここは安全のため本人が押す決まりで、Claude からは押せない）。

**入れる・上げるときは、どの道で進めても、必ず本人にダウンロードのリンクを見せる（2026-10-27〜）。**
Claude が自動で落とせる場面でも見せる。本人が自分で押せる道を残すためと、Claude の道具では落とせなかった・
開けなかったときに、本人がその場で続けられるようにするため。

## 1. 要るか・古いかを確かめる
1. 手元の拡張がつながっていれば、その拡張の `health_check` を呼んで版を見る（Deploy は `server`・Finance は `version` の行）。
2. `local_tools_status` に `installed`（例 `{"ai-osi-uri-deploy":"1.39.0"}`）を渡す。
   `needs_install` / `needs_update` が付いたものだけ進める。`only_local` を見せて、何のために入れるのかを一言で伝える。

## 2. リンクを見せて、落として開く
`get_download_link(product)` を呼ぶ。URL は 30 分で切れるので、取ったらすぐ使う。返ってくる `install` に手順がある。

**まず、本人にリンクを見せる。** 次の形で、押せるリンクにして出す（返答の最後ではなく、取った直後に出す。
長い作業の途中なら、途中経過として先に届く方法で送る）。

```
<拡張の名前> <版> のダウンロードリンクです。30分で切れるので、早めに押してください。

[<filename> をダウンロード](<url>)

1. リンクを押してダウンロードする
2. ダウンロードした「<filename>」をダブルクリックする
3. Claude のデスクトップアプリに出る「インストール」を押す

リンクが切れていたら「リンクをもう一度」と言ってください。
```

- `url` は本人だけのための一時的なリンク。返答に出してよいが、資料・メール・台帳・記録には書かない。
- 本人が「リンクをもう一度」と言ったら、`get_download_link` を呼び直して新しいリンクを出す（古いリンクは使わない）。

そのうえで、Claude の手が届く道があれば、上から使って落として開く。

1. **Claude Code（本人の Mac のシェル）**：`install.mac` をそのまま実行する（Windows は `install.windows`）。
   ダウンロードしたファイルが開き、デスクトップアプリの「インストール」の画面が出る。
2. **Claude のアプリで、パソコンを動かす道具（computer use）が使える**：
   Claude in Chrome で `url` を開いてダウンロードし、computer use でダウンロードフォルダのファイルを開く。
3. **どちらも無い**：見せたリンクを本人に押してもらい、ダウンロードしたファイルをダブルクリックしてもらう。

## 3. 本人が「インストール」を押す
- 「デスクトップアプリに『インストール』の画面が出ていると思います。押してください」と伝える。
- 上げる（更新）ときも同じ。設定欄（鍵・台帳フォルダ）は前の版のものが残る。
- 押したら、新しい会話を開いてもらう（新しい道具はその会話から見える）。`health_check` で版を確かめる。

## 事故の型
- URL が切れた（30 分）→ `get_download_link` からやり直し、新しいリンクを見せ直す
- リンクを見せずに「落として開きました」だけで済ませる → 開けていなかったとき本人が詰まる。必ずリンクも見せる
- Cowork のシェル（パソコンの中の作業用の箱）で `open` しても画面は出ない → 上の 1 か 2 の道で開く
- 本人が押す前に「入れました」と言わない。押したかどうかは本人に聞いて確かめる
