# 手元の拡張を入れる・上げる（Deploy・Finance・Creative・Core 共通・2026-10-16〜）

手元の拡張は、手元の PC が要る仕事のためだけに入れる。手元が要らない仕事は URL のコネクタの道具で進める。
**Claude が「落として開く」ところまで進め、本人には Claude のデスクトップアプリの「インストール」を1回だけ押してもらう**
（ここは安全のため本人が押す決まりで、Claude からは押せない）。

## 1. 要るか・古いかを確かめる
1. 手元の拡張がつながっていれば、その拡張の `health_check` を呼んで版を見る（Deploy は `server`・Finance は `version` の行）。
2. `local_tools_status` に `installed`（例 `{"ai-osi-uri-deploy":"1.39.0"}`）を渡す。
   `needs_install` / `needs_update` が付いたものだけ進める。`only_local` を見せて、何のために入れるのかを一言で伝える。

## 2. 落として開く（できる道を上から使う）
`get_download_link(product)` を呼ぶ。URL は 5 分で切れるので、取ったらすぐ使う。返ってくる `install` に手順がある。

1. **Claude Code（本人の Mac のシェル）**：`install.mac` をそのまま実行する（Windows は `install.windows`）。
   ダウンロードしたファイルが開き、デスクトップアプリの「インストール」の画面が出る。
2. **Claude のアプリで、パソコンを動かす道具（computer use）が使える**：
   Claude in Chrome で `url` を開いてダウンロードし、computer use でダウンロードフォルダのファイルを開く。
3. **どちらも無い**：`url` を本人に渡し、開いてダウンロードしたファイルをダブルクリックしてもらう。

## 3. 本人が「インストール」を押す
- 「デスクトップアプリに『インストール』の画面が出ていると思います。押してください」と伝える。
- 上げる（更新）ときも同じ。設定欄（鍵・台帳フォルダ）は前の版のものが残る。
- 押したら、新しい会話を開いてもらう（新しい道具はその会話から見える）。`health_check` で版を確かめる。

## 事故の型
- URL が切れた（5 分）→ `get_download_link` からやり直す
- Cowork のシェル（パソコンの中の作業用の箱）で `open` しても画面は出ない → 上の 1 か 2 の道で開く
- 本人が押す前に「入れました」と言わない。押したかどうかは本人に聞いて確かめる
