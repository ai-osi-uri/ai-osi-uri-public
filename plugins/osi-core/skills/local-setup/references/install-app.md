# アプリを入れる（議事録パートナー・Form Sender・SNS Sender・App Builder・2026-11-04〜）

アプリは、手元の PC で動かす配布物（dmg / exe / zip）。拡張（.mcpb）と違い、Claude のデスクトップアプリは関係なく、
入れたらそのアプリの中でツールポータルにログインして使う（鍵は要らない。共用の鍵で動き、会社のクレジットから引かれる）。
**本人をポータルの「ツールインストール（DL）」へ行かせない。** リンクはこの会話で出す（2026-11-04〜 `get_download_link` がアプリも返す）。

## 1. 何を・どの OS 用かを決める
1. `get_download_link()`（product を空）で、配布中のアプリと OS 別のファイルの一覧を取る。`can_use` が false なら、
   会社に所属していないか会社の「アプリ」が無効。運営（管理コンソールの会社詳細）に有効にしてもらう案内をして止める。
2. 本人の OS を確かめる。**Windows か Mac か。Mac なら Apple Silicon（M1 以降）か Intel か**。
   分からなければ「左上のリンゴ →『この Mac について』の『チップ』に Apple と書いてあれば Apple Silicon」と伝えて聞く。
   手元のパソコンの道具が見えていれば、`uname -m`（arm64 = Apple Silicon）や Windows の `$env:PROCESSOR_ARCHITECTURE` で Claude が見てよい。
3. platform は `mac-arm64`（Apple Silicon）／`mac-x64`（Intel）／`win-x64`（Windows）。ソース版（`source`）は、中身を直して動かしたい人だけ。

## 2. リンクを見せて、落として開く
`get_download_link(product, platform)` を呼ぶ。URL は 30 分で切れるので、取ったらすぐ使う。返ってくる `install` に手順がある。

**まず、本人にリンクを見せる**（取った直後に。拡張と同じく、Claude が自動で落とせる場面でも見せる）。

```
<アプリの名前> <版>（<OS の表示>）のダウンロードリンクです。30分で切れるので、早めに押してください。

[<filename> をダウンロード](<url>)

1. リンクを押してダウンロードする（<サイズ> MB）
2. ダウンロードした「<filename>」を開く
3. <install.last_step の入れ方>
4. 起きたアプリでツールポータルにログインする（鍵は要りません）

リンクが切れていたら「リンクをもう一度」と言ってください。
```

- `url` は本人だけのための一時的なリンク。返答に出してよいが、資料・メール・台帳・記録には書かない。
- 本人が「リンクをもう一度」と言ったら、`get_download_link` を呼び直して新しいリンクを出す（古いリンクは使わない）。

そのうえで、Claude の手が届く道があれば、上から使って落として開く。

1. **Claude Code（本人のパソコンのシェル）**：`install.mac`（Mac）または `install.windows`（Windows）をそのまま実行する。
   OS に合わない方は null で返るので、その道は使わない。
2. **Claude のアプリで、パソコンを動かす道具（computer use）と Claude in Chrome の両方が使える**：
   Claude in Chrome で `url` を開いてダウンロードし、computer use でダウンロードフォルダのファイルを開く。
3. **それ以外**：見せたリンクを本人のいつものブラウザで押してもらい、ダウンロードしたファイルを開いてもらう。

## 3. 入れたあと
- dmg：窓の中のアプリを「アプリケーション」へドラッグし、アプリケーションから起動。Mac 版は Apple の公証済みなので、「開発元を確認できない」は出ない（出たら古いファイル。リンクを取り直す）。
- exe：開くとインストールが走り、終わると起動する。「変更を許可しますか」は「はい」。Windows 版はまだ署名していないので、青い「Windows によって PC が保護されました」が出たら「詳細情報」→「実行」。
- zip（App Builder）：展開して、中の README の手順で起動する。
- 初回はアプリの中でツールポータルにログインする（会社に所属している本人のメールアドレス）。ログインできたら使える。
- 入ったかを確かめる。議事録パートナーは `gijiroku_status` で Claude が確かめられる（「待機中」ならつながった）。それ以外のアプリは本人に聞く。「入れました」とこちらから言わない。
- 「議事録起動して」から入れる流れに来たとき（`gijiroku_start` が「入っていない」を返した）は、つながったらそのまま `gijiroku_start` を呼び、最初の頼みごとを終わらせる。

## 目の見えない方・画面読み上げを使う方へ（2026-11-06）
- 1 回に 1 つだけ、押す場所を「画面の左上」「窓の中央の大きなアイコン」のように言葉で伝える。色や絵で伝えない。
- Claude の手が届く道（Claude Code・computer use と Claude in Chrome）があれば、落として開くところまで Claude がやる。本人にお願いするのは確認の「はい」「インストール」だけにする。
- 入ったあとは、画面のボタンを覚えてもらわなくてよい。「議事録起動して」「議事録止めて」「今録音してる？」「今までの話をまとめて」「さっきの会議まとめて」を Claude に言えば動く（gijiroku_start / gijiroku_stop / gijiroku_status / gijiroku_live / gijiroku_meeting）。文字起こしをコピーして Claude に貼る必要はない。アプリは Claude から始めた録音の始まり・終わり・声が入っていないことを声で知らせる。

## 事故の型
- 本人をポータルへ行かせてしまう → この会話でリンクを出す（ポータルは、本人が自分で見たいときのための場所）
- OS を確かめずに落とす → Intel Mac に arm64 を渡すと開かない。必ず先に聞くか、手元の道具で見る
- URL が切れた（30 分）→ `get_download_link` からやり直し、新しいリンクを見せ直す
- 「鍵が要りますか」と聞かれる → 要らない。アプリの中のログインだけ。クレジットが足りないときはアプリ側に「クレジットが足りません」と出る（ポータルの「クレジット利用状況」で買い足すか、運営に相談）
