# computer：本人のパソコンとつなぐ

## 揃っているか
- Claude Code で動いている → 揃っている。
- Claude のアプリで、本人のパソコンのフォルダを読み書きする道具（フォルダの一覧・シェルなど）が見えている → 揃っている。使うフォルダがつながっているかも見る。
- どちらでもない → 下の手順。

## 手順（Claude のアプリ）
1. **デスクトップアプリを入れる**：ブラウザで使っているなら、https://claude.ai/download から Claude のデスクトップアプリを入れて、同じアカウントでログインしてもらう。
2. **この会話をデスクトップアプリで開く**：左の一覧から同じ会話を開く。
3. **フォルダをつなぐ**：入力欄の近くの「フォルダを追加」（または ＋ のメニュー）から、仕事で使うフォルダを選んでもらう。
   - 何のフォルダが要るかは元のスキルに合わせて言う（例：案件フォルダ、台帳のあるフォルダ、アプリのソースを置くフォルダ）。
   - Google ドライブのファイルを使うなら、Google ドライブのデスクトップアプリで同期しているフォルダを選ぶ。
4. **確かめる**：つないだフォルダの中身を一覧して、本人に「このフォルダで合っていますか」と聞く。

## 手順（パソコンでプログラムを動かす仕事）
元のスキルが Docker・AWS CLI・Node などをパソコンで動かすとき：
1. パソコンのシェルが使えるなら、`which <道具名>` で入っているかを確かめる。
2. 入っていなければ、入れ方の公式ページを 1 つだけ示し、入れてもらう（本人の OK のもとで、Claude がシェルから入れてもよい）。
3. 入ったら、バージョンを表示するコマンドで確かめる。

## Claude Code を使う道もある
パソコンでの作業が多い仕事（アプリのソースを直す・何度もビルドする）は、Claude Code の方が速い。
本人が望めば https://claude.com/claude-code の入れ方を案内する。
