# ext-deploy：デスクトップ拡張「Deploy」を入れる

手元の git 操作（取り込み・push）・CI のログの読み取り・GCP/AWS の操作は、Claude のデスクトップアプリに入れる拡張でだけ動く。

## 揃っているか
- `github_push` や `github_fetch` の道具が見えている → 揃っている。

## 手順
1. まず computer（デスクトップアプリ）を済ませる。
2. 道具 `get_download_link` を、拡張の製品キー（Deploy の拡張）で呼び、ダウンロードの URL を本人に渡す（5 分で切れるので、渡したらすぐ開いてもらう）。製品キーが分からなければ、ポータルの「製品」の画面から落としてもらう。
3. ダウンロードした `.mcpb` をダブルクリックし、デスクトップアプリの「インストール」を押してもらう。
4. 拡張の設定欄に入れる鍵は、スキル setup-deploy-environment の手順で 1 つずつ案内する（鍵の値は会話に貼らせない）。
5. 新しい会話を開いてもらい、`health_check` が返るかで確かめる。
