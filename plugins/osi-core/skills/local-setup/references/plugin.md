# plugin：手元にプラグインを入れる

**プラグインは入れておく（2026-10-19 決定）。** 手元にプラグインがあると、頼まれた言葉から Claude がスキルを自動で選べる。
プラグインが無いと、Claude のチャットはスキルを探しにいかない（コネクタの一覧や find_skill だけでは選ばれないと 10/17 に確かめた）。

- **会社の組織（Team / Enterprise）のメンバー**：組織の設定から自動で入り、自動で最新になる。本人は何もしなくてよい。
  個人の組織ではなく会社の組織を選んでいるかだけ確かめる。
- **個人のアカウント**：下の手順で 1 回だけ入れる。「自動的に同期」をオンにすれば、以後の更新は自動で届く。
- **入っていない・入れられないとき**：止めない。スキルの本文は `get_skill`、雛形ファイル（フォント・PDF・pptx・画像）は
  `get_skill` に `download: true` を渡して一式を落とせば動く。

入れ先（マーケットプレイスの名前とリポジトリ）は、道具 getting_started の「手元のプラグインの入れ先」に書いてある。

## 揃っているか
- 元のスキルが、手元のスキル一覧に同じ名前で入っている → 揃っている。
- Claude Code なら `claude plugin list` に、そのプラグインがある → 揃っている。

## 手順（Claude のアプリ）
1. 「カスタマイズ」→「プラグイン」を開いてもらう（ブラウザの道具があれば、本人の OK のもとで Claude が開く）。
2. 入れ先のマーケットプレイスが無ければ、右上の「追加」→「マーケットプレイスを追加」→「リポジトリから追加」に、入れ先のリポジトリの URL を入れて追加する。「自動的に同期」をオンにする。
3. 元のスキルのプラグイン（例：osi-docs）を ＋ で入れる。
4. 新しい会話を開いてもらう（入れたプラグインは新しい会話から使える）。
5. コードを動かすスキルなら、「設定」→「機能」→「コードの実行とファイルの作成」の「クラウドでのコード実行とファイル作成」がオンになっているかも見てもらう（スキルを使うのにも要る）。

## 手順（Claude Code）
1. `claude plugin marketplace add <入れ先のリポジトリ>`（まだなら）
2. `claude plugin install <プラグイン名>@<マーケットプレイス>`
3. Claude Code を再起動してもらう。
