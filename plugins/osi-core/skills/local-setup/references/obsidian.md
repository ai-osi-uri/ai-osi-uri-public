# obsidian：ノートの置き場を作る

## 揃っているか
- Obsidian の道具（ノートの検索・読み書き）が見えている → 揃っている。

## 先に考えること
ノートの置き場が無くても、会社の知識（secretary_knowledge）に覚えさせて使える。
「自分だけのノートを貯めたい」「会社に共有しない知識を持ちたい」ときだけ Obsidian を入れる。どちらにするか本人に聞く。

## 手順
1. まず computer（本人のパソコンとつなぐ）を済ませる。
2. スキル knowledge-setup を `get_skill` で読み、その手順で進める（Obsidian を入れる → ノートのフォルダを作ってつなぐ → 形を作る → 最初の一件）。
