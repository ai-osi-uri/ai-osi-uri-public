# chrome：本人の Chrome を操作する

鍵の発行画面や管理画面を開いて押す場所まで進めるために、本人の Chrome を Claude が操作する。

## 揃っているか
- Chrome を操作する道具（タブを開く・画面を読む・クリックする）が見えている → 揃っている。
- Claude のデスクトップアプリのブラウザ（アプリの中のブラウザ）が使える場合は、それでもよい。

## 手順
1. Chrome に「Claude」の拡張機能（Claude in Chrome）を Chrome ウェブストアから入れ、同じアカウントでログインしてもらう。
2. Claude のアプリで、Chrome を使う設定がオンになっているかを見てもらう。
3. 新しい会話を開いてもらい、Chrome の道具が見えるかを確かめる。

## Chrome が使えないとき
押す場所を 1 行ずつ案内する（「どの画面の・どのボタン」）。ログイン・同意・鍵のコピーは、いつも本人にしてもらう。
