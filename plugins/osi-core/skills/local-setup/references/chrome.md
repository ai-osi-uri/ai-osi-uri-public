# chrome：本人の Chrome を操作する

鍵の発行画面や管理画面を開いて押す場所まで進めるために、本人の Chrome を Claude が操作する。
**標準は Claude in Chrome**（2026-10-28〜）。普段の Chrome のログイン（Google・GitHub・Vercel など）のまま動けるので、
パスワードの手入力や二段階認証のやり直しが起きない。初回セットアップ（getting-started の Step 4b）でも入れてもらっている。

## 揃っているか
- Chrome を操作する道具（`mcp__claude-in-chrome__*`。最初は、それをオンにする道具だけが見えていることもある）が見えていて、
  1 回軽く叩いて返る（開いているタブの一覧など）→ 揃っている。オンにする道具だけ見えているときは、呼んでから確かめる。
- Claude のデスクトップアプリの中のブラウザが使えても、**それだけでは揃っているとしない**（下の「代わりの順番」の 3 番目）。

## 手順（入っていないとき）
得を先に 1 行で言ってから勧める：「Claude が画面を押すときに、いつもの Chrome のログインのまま動けるようにします。入れないと、サービスごとにパスワードの入力や二段階認証をやり直すことになります」。

1. Chrome で Chrome ウェブストアを開き、「Claude」の拡張機能（Claude in Chrome）を追加する
2. 拡張機能を開き、いま使っている Claude と同じアカウントでログインする
3. Claude の設定で Chrome を使う設定をオンにし、使うブラウザを Chrome にしておく（アプリの中のブラウザが選ばれていると、Chrome のログインが使えない）
4. 新しい会話を開いてもらい、Chrome の道具が見えるかを確かめる

任せる範囲も一緒に伝える：「ログイン・同意・鍵のコピーは、いつもあなたがします。Claude は押す場所まで進めます」。

## 代わりの順番（Chrome を入れられない・入れないとき）
Chrome を使っていない人、会社の決まりで拡張を入れられない人もいる。止めずに、次の順で進める。

1. **本人のいつものブラウザで、押す場所を 1 行ずつ案内する**（「どの画面の・どのボタン」）。本人のブラウザはログイン済みなので、手入力も二段階認証も起きない。**まずこれ。**
2. 画面を見ないと案内できないときは、本人にスクリーンショットを貼ってもらい、それを見て次の 1 行を出す。
3. **アプリの中のブラウザは最後の手段。** 使う前に「ここはいつものブラウザとは別なので、<サービス名> へのログイン（パスワードと二段階認証）がもう一度要ります」と伝え、本人が良いと言ったときだけ使う。

ログイン・同意・鍵のコピーは、どの道でもいつも本人にしてもらう。

## 事故の型
- アプリの中のブラウザを黙って使い、サービスごとにログインと二段階認証が続いて離脱する（2026-10-28 に指摘。上の順番で防ぐ）
- 入っているのに入れ直させる。必ず先に確かめる
- 「Chrome が無いのでできません」で止める。代わりの順番の 1 で必ず進める
