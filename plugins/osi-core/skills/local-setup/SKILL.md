# 手元の準備（local-setup）

チャットだけでは終わらない仕事を、**止めずに、会話の中で導入して使えるようにする**ためのスキル。
本人にお願いするのは「ダウンロードしたファイルを開く」「ログイン・許可のボタンを押す」「アプリを入れる」のような、
Claude の手が届かない操作だけ。それ以外（何が要るかを確かめる・どこを押すかを示す・入ったかを確かめる）は Claude がやる。

## 0. 不変条件

- 先に**いま揃っているか**を確かめる。揃っていれば何も案内せず、元のスキルへ戻る。
- 準備を始める前に、何が要るか・どのくらいかかるかを 1〜3 行で見せ、本人の OK をもらう。断られたら、チャットだけでできる範囲（下書き・ファイルで渡す等）で元の仕事を進める。
- 手順は 1 回に 1 つだけ出す。本人が「できた」と言ったら、Claude が確かめてから次へ進む。
- パスワード・鍵の値を会話に貼ってもらわない。鍵はポータルの「鍵設定」か、拡張の設定欄に本人が入れる。
- 画面の名前は、いま見えている画面に合わせて言い換えてよい（アプリの更新で名前が変わることがある）。見当たらなければ本人に画面の様子を聞く。

## 1. 何が要るかを決める

元のスキルを get_skill で読んだときの「手元の準備」の節に、要るものの種類が書いてある。
種類と、読む手順書の対応：

| 種類 | 何のため | 手順書 |
| --- | --- | --- |
| computer | 本人のパソコンのファイル・フォルダを読み書きする、パソコンでプログラムを動かす | `references/computer.md` |
| plugin | 手元にプラグインを入れる（言葉で自動でスキルが選ばれる。会社の組織なら自動で入る。無くても get_skill と download で動く） | `references/plugin.md` |
| chrome | 本人の Chrome で画面を操作する（鍵の発行画面・管理画面など） | `references/chrome.md` |
| mac | iPhone アプリの手元での確認（Xcode・シミュレーター・キーチェーン） | `references/mac.md` |
| android | Android アプリの手元での確認（Android Studio・エミュレーター・keytool） | `references/android.md` |
| ext-deploy | デスクトップ拡張「Deploy」（Git の push・取り込み、手元から Vercel に直接上げる・Terraform・署名鍵・Cloudflare Worker） | `references/extension.md` |
| finance | 経理の台帳（デスクトップ拡張「Finance」＋台帳フォルダ） | `references/finance.md` |
| obsidian | Obsidian のノートの置き場 | `references/obsidian.md` |

手順書は `get_skill`（name=`osi-core:local-setup`, file=`references/<名前>.md`）で読む。
手元の拡張（Deploy・Finance・Creative・Core）を入れる・上げるのは、どれも `references/install-extension.md` の共通の手順（`local_tools_status` で版を比べ、Claude が落として開き、本人は「インストール」を1回押す）。
手元にこのスキルが入っていれば、そのファイルを直接読んでもよい。

## 2. いま揃っているかを確かめる

種類ごとの確かめ方は各手順書の冒頭にある。共通の見分け方：

- **Claude Code**（本人のパソコンのターミナルで動いている）なら、computer はもう揃っている。plugin・mac・android はコマンドで確かめられる。
- **Claude のアプリ**なら、本人のパソコンの道具（フォルダの読み書き・シェル）が見えていれば computer は揃っている。見えていなければ揃っていない。
- 拡張・Obsidian・Chrome は、その道具の名前が見えているかで分かる。

## 3. 整える

足りないものだけ、手順書の順に進める。複数足りないときは computer → chrome → plugin → 拡張・Obsidian → mac/android の順（chrome を先にするのは、拡張のダウンロードや鍵の発行画面で、いつものログインのまま Claude が進められるようにするため。2026-10-28）。

## 4. 戻る

整ったら「準備ができました。<元の仕事> に戻ります」と 1 行伝えて、元のスキルの手順に戻る。
途中で止めたときは、どこまで整ったかと、次にやることを 1〜2 行で残す。

## 事故リスト

- 準備の話を長く続けて、元の仕事を忘れる。準備は最小限、終わったらすぐ戻る。
- 揃っているのに入れ直させる。必ず先に確かめる。
- 「この環境ではできません」とだけ言って止める。手順を案内するか、チャットだけでできる範囲で進めるかのどちらかを必ず出す。
