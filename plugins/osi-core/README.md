# osi-core

自社の**横断オーケストレーション層**プラグイン。

ドメインプラグイン（osi-sales / osi-knowledge / osi-docs / osi-deploy など）が「実作業」を担うのに対し、
osi-core は**入力の振り分けと横断品質ゲート**を集約する。

## 含まれるスキル
- **transcript-router** … 会議/商談/伴走の文字起こしや長文＋一言の指示を受け、議事録化・論点出し・商談準備・
  見積もりなどへ自動で振り分ける入口スキル。宛先スキルが無い環境でも単体で最低限の成果を返すフォールバック付き。
- **research-verifier** … 調査・提案・記事の事実主張を独立検証し、確認済み・反証・未検証・競合・期限切れで返す品質ゲート。
- **jev-judge** … 大量の文章に「はい／いいえ・選択肢・点数」の判定をまとめてかける（TypeSafe の Jev をリモートMCP の `jev_judge` で呼ぶ）。自信の低いものだけ Claude か人に回す。営業お断り判定・議事録の案件特定・裏取りの一次仕分け・経理の分類で使う。

## 設計方針
- 横断レイヤーなので、宛先スキルへの依存は**ソフト**（無ければ自前で処理）。
- ルーター、検証、横断ゲートなど、特定ドメインに閉じない機能をここに集約する。
