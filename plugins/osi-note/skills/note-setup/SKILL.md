# note-setup（note をつなぐ・確かめる）

道具は 2 か所にある。
- PC の AI OSI URI note 拡張：`search-notes` / `get-note` / `get-my-notes` / `post-draft-note` など（名前に「-」が入る）
- URL のコネクタ：`get_download_link`（拡張を落とすリンク）

この拡張は、オープンソースの note MCP（shimayuz/note-com-mcp・MIT）を包んだ**非公式**のもの。note の公式 API ではない。
既定は「読むだけ」で、下書きの保存などは拡張の設定で「書き込みを許可」をオンにしたときだけ。**記事を公開する道具は無い**（公開は本人が note の画面で行う）。

## 1. 拡張があるか確かめる
1. `search-notes`（`query: "AI"`, `size: 3`）を呼ぶ。
2. 呼べない（道具が無い）→ 拡張が入っていない。Claude が入れる：
   1. `get_download_link`（`product: "note-com"`）で URL を取る。
   2. 返ってきた `install` の手順で、PC のシェル（Mac は `install.mac`、Windows は `install.windows`）か、ブラウザ（`install.browser`）で落として開く。どちらも使えないときは、リンク（押せる形・ファイル名・30 分で切れること）を見せて本人に開いてもらう。
   3. Claude のデスクトップアプリに出る「インストール」だけ本人に押してもらう。押したら「入れた」と送ってもらい、道具が見えたら 1 からやり直す（見えなければ新しいチャットで「note のセットアップをして」と送ってもらう）。
   - `get_download_link` が「利用権がありません」「配布されていません」と返すときは、その会社にまだ配っていない。運営に頼むよう伝えて止める。
3. Node.js が無いと拡張が起動しない（「起動できない」「server disconnected」）。そのときは Claude のデスクトップアプリを最新にしてもらう（アプリ内蔵の Node で動く）。直らなければ Node.js（LTS）を入れてもらう。

## 2. 初めてのときに伝える（短く・OK をもらう）
> この note の拡張は非公式で、note 株式会社とは関係がありません。note の画面の仕様が変わると、急に動かなくなることがあります。
> 記事を探す・読む・分析するのはログインなしでできます。自分の記事一覧・PV・下書きの保存を使うときだけ、note のメールアドレスとパスワードを拡張の設定に入れます（このパソコンの安全な場所に保存され、note 以外には送られません）。
> この内容で進めてよいですか？

本人が前にこの説明を受けて OK していれば聞き直さない。

## 3. 自分の記事も使いたいとき（任意）
1. Claude の「設定 → 拡張機能 → AI OSI URI note」を開いてもらう。
2. 「note のメールアドレス」「note のパスワード」「note のユーザー ID」（プロフィール URL の note.com/〇〇 の〇〇）を入れてもらう。**チャットには貼ってもらわない。**
3. 下書きを Claude から保存したいなら「書き込みを許可」をオンにしてもらう。
4. 設定を変えたら、拡張は自動で読み直される。新しいチャットで「note のヘルスチェック」と送ってもらうと確実。
- Google・Apple・X のアカウントで note にログインしている人は、note の「アカウント設定」でメールアドレスとパスワードを先に作ってもらう（この拡張はメールとパスワードでしかログインできない）。

## 4. 確かめる（ヘルスチェック）
1. `search-notes`（`size: 3`）で記事のタイトルが出ることを確かめる。
2. ログイン情報を入れている人は `get-my-notes`（`page: 1`）を呼ぶ。自分の記事が出ればログインできている。「認証」「ログイン」の失敗が出たら、3 の入力を見直してもらう。
3. 本人に短く返す：検索できるか・ログインできているか・書き込みが許可されているか（`post-draft-note` が見えるか）。

## 5. 伝えること（短く）
- 始め方の例：「note で『生成AI 業務効率化』の人気記事を調べて」「〇〇さんの note の最近の記事を分析して」「自分の note の PV を見せて」「この原稿を note の下書きに入れて」
- 「下書きまでは Claude が入れます。公開は、note の画面で中身を確かめてから本人が押してください。」

## 困ったとき
| 様子 | すること |
|---|---|
| 検索が空・エラーが続く | note の仕様変更のおそれ。しばらくして試す。続くなら運営に伝える（上流の修正待ちになることがある） |
| ログインに失敗する | メール・パスワードの打ち間違い、または SNS ログインだけのアカウント。3 を見直す |
| `post-draft-note` が見えない | 「書き込みを許可」がオフ。3 の 3 |
| 同じ名前の道具が 2 つ出る | 前に別の note MCP を入れている。Claude の「設定 → 拡張機能」で古い方を外してもらう |
