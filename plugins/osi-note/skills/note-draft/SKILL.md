# note-draft（note の下書きを作る）

道具は PC の AI OSI URI note 拡張。下書きの保存には、拡張の設定で note のログイン情報と「書き込みを許可」が要る。
`post-draft-note` が見えなければ note-setup の 3 へ案内する（原稿づくりは先に進めてよい）。
**記事を公開する道具は無い。** 「公開して」と言われても、下書きに保存して「note の画面で公開を押してください」と返す。

## 1. 中身を決める
- テーマ・読者・読後にしてほしいこと・文字数のめやす・有料にするか、を本人の言葉から取る。足りなければ 1 回だけ聞く。
- 本人の原稿・メモ・ほかのブログがあれば、それを元にする（言い回しは本人のものを残す）。
- 下調べが要るときは note-research で上位の型を見てから組む。**他の人の記事の文を写さない。**

## 2. 構成案 → 本文
1. 構成案（タイトル案 3 つ・見出し・各見出しで言うこと）を見せて、OK か直しをもらう。
2. 本文を Markdown で書く。拡張が note 用に変換するので、次の書き方にそろえる：
   - 見出しは `##`（大見出し）と `###`（小見出し）。`####` 以下は太字になる。
   - 箇条書きは `- `。表は note で崩れるので使わず、箇条書きにする。
   - 画像は後で入れる場所に `（画像：〇〇）` と書いておく。
3. タグ（10 個まで）を提案する。
4. 本文全体を本人に見せる。

## 3. 下書きに保存する（本人の OK のあとで 1 回）
1. 保存する前に、タイトル・タグ・本文の先頭 3 行と「下書きに保存します（公開はしません）」を見せて、はっきり OK をもらう。
2. `post-draft-note`（`title` / `body` / `tags`）を 1 回だけ呼ぶ。既存の下書きを直すときは `id` に下書きの ID を渡す（`get-my-notes` で探す）。
   - 画像を入れるときは `post-draft-note-with-images`。画像は `images` に `fileName`・`mimeType`・`base64`（画像ファイルを Base64 にしたもの）で渡し、見出し画像は `eyecatch` にその `fileName` を指定する。画像は本人に添付してもらうか、つないだフォルダから読む。PNG・JPEG・GIF、10MB まで。
3. 返ってきた下書きの ID と編集画面の URL を本人に渡す：
   > 下書きに保存しました。公開する前に、note の画面で見た目（見出し・画像・改行）を確かめてから「公開に進む」を押してください。
4. 失敗したら同じ呼び出しを繰り返さない。エラーをそのまま伝え、ログインの見直し（note-setup）か、本文を本人に渡して note に貼ってもらう。
5. マガジンに入れたいと言われたら、公開後に `add-magazine-note`（本人の OK のあとで 1 回）。

## 守ること
- 1 回の OK で保存は 1 回。直しを足すときも、もう一度見せてから。
- コメント・スキは、このスキルではしない（頼まれたら内容を見せて OK をもらってから 1 回だけ）。
- 有料部分の線引きや価格は本人が決める（Claude は案を出すだけ）。下書きでは、有料にする位置を本文に `（ここから有料）` と書いておき、設定は note の画面で本人が行う。
