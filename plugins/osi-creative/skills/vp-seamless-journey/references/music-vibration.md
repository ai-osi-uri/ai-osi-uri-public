# 音楽の振動（バイブレーション）で疾走感を出す（正本）

**考え方**：疾走感は“速く動かす”だけでは出ない。**音楽のうねり（ビート・エネルギー・緩急）を先に読み取り、映像のカメラ加速・カットの切れ目・繋ぎの瞬間をそこに同期させる**と、観る人が音と一緒に「速さ＝振動」を体感する。ファイル名の「緩急」はこの同期の産物。

> ※この節は「地図の物語」制作時の口頭方針（制作陣の“音楽から振動を感じて疾走感を”）を手法化したもの。運用しながら言い回し・数値を更新する。

## 手順

### STEP 1. 音楽を先に決める・解析する
BGMを先に確定（無ければ `generate_music` で作る）。ビート・エネルギー包絡・区切りを解析する：

```python
import librosa, numpy as np
y, sr = librosa.load("bgm.mp3")
tempo, beats = librosa.beat.beat_track(y=y, sr=sr)      # BPMと拍の時刻
beat_t = librosa.frames_to_time(beats, sr=sr)           # 拍の秒
rms = librosa.feature.rms(y=y)[0]                        # エネルギー包絡（緩急の元）
onset = librosa.onset.onset_detect(y=y, sr=sr, units='time')  # アタック（切れ目候補）
```
（librosa が無ければ `pip install librosa --break-system-packages`。簡易版は ffmpeg `astats`/`silencedetect` でエネルギーの山谷だけでも可。）

### STEP 2. ビートに“出来事”を置く
- **カットの切れ目・繋ぎの瞬間**は、恣意的な秒でなく**拍（beat_t）に合わせる**。特にサビ/落ちサビ等の大きな区切りは強拍に。
- **カメラの加速**は**エネルギー包絡（rms）に比例**させる：静かな箇所は滑空（低速）、盛り上がりで加速、ピークで最高速、解決で減速して着地。
- 固定ナレ同期の制約（#20）がある場合は、拍に完全一致できないので**「最も近い拍」に寄せる**（±0.1〜0.15s）。ナレ優先、その中でビートに寄せる。

### STEP 3. 映像側パラメータへ落とす
| 音楽 | 映像の操作 |
|---|---|
| BPM / 拍 | カット境界・繋ぎ（最終フレーム連鎖の切替点）・フラッシュの位置 |
| エネルギー包絡（rms）↑ | カメラ前進速度↑（i2vプロンプトの "accelerate/rush" 強度、`setpts`の詰め、moveboardのPUSH強度） |
| 静→動→静（緩急） | 滑空 → 加速疾走 → 減速して人物に着地（＝物語のリリース） |
| ピーク（サビ） | 最高速 or 最インパクトのカット（今回は疾走路のライトトレイル） |
| 終止 | 着地・ロゴ・余韻（afade out 2s） |

### STEP 4. 音の仕上げ
- ナレ主役でBGMを引く（サイドチェイン・ダッキング）：
  `[music][voice]sidechaincompress=threshold=0.025:ratio=7:attack=5:release=400`
- 全体 `afade=in:1.2` / `afade=out:2`。BGMはループの継ぎ目が“途切れ”に聞こえるので曲尺≥動画尺を選ぶ（`../../ai-video-production/references/bgm-selection.md`）。

## 鉄則
- ✅ **音楽を先に置き、映像を後から音に同期**（逆にしない）。
- ✅ 疾走感＝速さ×**音の緩急との一致**。ピークで最高速、解決で着地。
- ✅ 固定ナレがある時はナレ優先で“最寄りの拍”に寄せる。
- ❌ 拍を無視した等間隔カット／一定速度の疾走（振動が感じられず単調）。
