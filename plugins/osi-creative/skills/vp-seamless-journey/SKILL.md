# vp-seamless-journey — 継ぎ目のない1本のカメラ移動 × 音楽同期の疾走感

このメソッドの仕事は **「複数の生成クリップを“1台のカメラが動き続けている1本の映像”として繋ぎ、音楽のうねりに疾走感を同期させる」** こと。
生成・承認・連結ループそのものは `vp-core` に委譲する。元ネタは「地図の物語」実写CM（車→空撮→疾走→水辺の人物）で確立。

**詳細は必ず参照：**
- `references/seamless-continuation.md` … 最終フレーム連鎖・尺同期・frame-diff検証（正本）
- `references/music-vibration.md` … 音楽の振動＝緩急/ビートに映像を同期して疾走感を出す（正本）
- 共通の落とし穴は `../ai-video-production/references/pitfalls.md`（#17 reference-to-video / #19 カメラ反転 / #20 固定タイムライン尺 / #21 人物は動かす）

## 5つの確定原則（これを外すと“繋がって見えない/気持ち悪い”）

1. **繋ぎはフラッシュで誤魔化さない。最終フレーム連鎖で繋ぐ。**
   前カットの最終フレームを `ffmpeg -sseof -0.05 -i A.mp4 -update 1 -frames:v 1 last.png` で抜き、その `last.png` を次カットの `image_url`（i2v 起点）にする。B の1フレーム目＝A の最終フレームになるので、連結すると継ぎ目が消える。白フラッシュ/クロスフェードは最後の手段。
2. **カメラの向きを反転させない（#19）。** 「引く→寄せる」は気持ち悪い。1本のジャーニーは方向を一貫させる（前進なら最後まで前進。“引きながら前へ進む”＝前進ドリー＋クレーンで視界を開く、で表現）。
3. **音楽の振動に映像を乗せる（疾走感の芯）。** BGMのビート/エネルギー/緩急を先に解析し、**カメラの加速・カットの切れ目・繋ぎの瞬間をビート（拍）に合わせる**。静かな箇所は滑空、盛り上がりで加速、サビ手前で最高速→着地でリリース。`references/music-vibration.md`。
4. **固定タイムラインの尺は1フレームも動かさない（#20）。** 単一ナレ音声＋adelayで組んだ動画では、差し替えるカットの尺を**元と一致**させる。全カメラアークを残したいときは `setpts` で全体を圧縮/伸長（`trim` は山場＝グランドリビールを落とすので注意）。尺を変えると以降のナレが全部ズレる。
5. **人物は“動かす”、静止画＋ズームで誤魔化さない（#21）。** 被写体が人ならi2vで実際に動かす。人物が別カットで別人化したら、正しいカットの1枚を key visual に `edit_image` で「同一人物のまま別の感情/ポーズ」に編集してから i2v（同じ場面の2回目も、クリップ再利用ではなく edit_image で別アングルを作る）。

## フロー

1. **ジャーニー設計（無料）**：一本の移動を「起点画像 → ビート列（各ビートの被写体・カメラ・尺）→ 終点（誰/何で終わるか）」に分解。音楽があれば先に解析（`music-vibration.md`）。無ければ `generate_music` で先に作ってから解析。
2. **起点画像**：既存カット（例：前シーンの車の最終フレーム）を使うか、無ければ `generate_image`（nano-banana-pro, 4K, テキスト/線なし）。
3. **連鎖生成（vp-core 承認ゲート）**：各ビートを「前カットの最終フレーム起点 + 短い連続モーションプロンプト（"seamless continuous motion, no cuts, never move backward"）」で i2v 生成。**途中のカットを差し替えたら、そのカット以降は最終フレームが変わるので全部作り直す（カスケード）**。カメラムーブ主体のビートは `vp-moveboard` のムーブボードを併用可。
4. **尺同期＆連結（vp-core）**：各カットを固定タイムラインの尺へ `setpts` で合わせて連結。ビートに合わせて繋ぎ位置を微調整。
5. **検証（vp-core）**：`references/seamless-continuation.md` の frame-diff QA で (a) モーション有無 (b) 継ぎ目の一致（A末 vs B頭の meanAbsDiff < 約5）(c) ムーブボード線の非映り込み、を自動チェック。
6. **仕上げ**：音楽ダッキング（ナレ下でBGMを引く）・色・エンドカード。Phase 6〜8（`ai-video-production`）へ接続。

## 鉄則
- ✅ 繋ぎは「最終フレーム連鎖」。フラッシュは代替でなく“味付け”。
- ✅ カメラ方向は一貫（前進なら前進）。
- ✅ 疾走感は「音楽の緩急・ビート」に同期させて作る（恣意的なタイミングにしない）。
- ✅ 固定ナレの尺は死守（setptsで合わせる、trimで山場を落とさない）。
- ❌ 人物を静止画＋Ken Burnsで誤魔化さない。別人化は edit_image で修復。

生成・承認・連結ループは `vp-core` に委譲する。
