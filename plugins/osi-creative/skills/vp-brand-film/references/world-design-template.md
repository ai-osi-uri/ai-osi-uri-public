# 世界観設計書の雛形

vp-brand-film の手順2で作る。**相手に見せる版**なので、相手の内情の分析やこちらの勝ち筋は書かない。
ここで決めた「見た目と音の決まり」は、そのまま `../../ai-video-production/references/brandkit.md` の `kit.yaml` に書き出す。

---

## 0. 誰に・なぜ・何を

| | |
|---|---|
| 誰に | 依頼主（決める人）と、映像を最後に見る人 |
| なぜ | この映像で何を確かめたい・何を伝えたいか |
| 何を | 本編の尺・ナレの有無・短尺版の有無。この資料が台本と全カットの元になること |

## 1. 材料：その会社自身の言葉

| 言葉 | 出てくる場所 | 映像での使い方 |
|---|---|---|
| （理念・タグライン） | （サイトのどのページか） | 背骨・最後の一言 |
| （代表の言葉・価値観） | | 比喩の候補 |
| （行動指針） | | 人の振る舞い（構図） |
| （サービス名） | | 比喩の候補 |

※ 他者の著作の引用がある場合：考え方だけ受け取り、引用文・作中の絵・登場人物は映像に使わないと明記する。

## 2. 映像が言い当てること（見る人の本音）

`../../ai-video-production/references/hook-insight.md` の手順（WHYを2階層掘る）で書く。

| 段階 | 中身 |
|---|---|
| ① 口に出して言うこと | 見る人がふだん口にする悩みを、そのままの言葉で5つほど |
| ② まとめると | 3語程度に（例：伝わらない／まとまらない／始められない） |
| ③ なぜそうなるのか | 構造的な理由（例：当たり前すぎて自分では見えない） |
| ④ 本音の種 | 1文。見た人が「そうそう」と思う核 |

- **冒頭の一言（3案）**：④から作る。**選ぶのは書いた人以外**（相手か、別の人）。
- **それが解けるとどうなるか（気持ち）**：
- **信じてよい理由**：

## 3. 世界観の核：方向案3つ

どの案も同じ芯（例：見えないものが少しずつカタチになる）を描き、**たとえだけを変える**。
各案に：たとえ／推す理由 or 良い点／注意（AIで作ると陳腐になりやすい点・崩れやすい点・作法の誤りが出やすい点など）。**3案のうち1つを推奨**する。

| 案 | たとえ | 推す理由／良い点 | 注意 |
|---|---|---|---|
| A（推奨） | | | |
| B | | | |
| C | | | |

推奨の基準：その会社の言葉がそのまま映像になる／人の顔を描かずに成立する／**繰り返し使えるモチーフ**がある（音のロゴにできる音を持つ。例：小石が水に落ちる音）。
「よくある広告」に寄る表現（光る未来都市・ホログラム・ロボット・握手・右肩上がりのグラフ・過剰なキラキラ）は案に入れない。

## 4. 見た目の決まり

| 項目 | 決まり |
|---|---|
| 色 | 地の色・墨の色・差し色1色（コーポレートカラーが分かれば置きかえる） |
| 光 | 時間帯・光の向き・山場に向けた変化 |
| 質感 | 写実か、画風か。主役の素材 |
| カメラ | 固定／ゆっくり寄る 等。使わない動き |
| 人物 | 出し方を**2通りから1つ選ぶ**：①アニメ調・イラスト調（設定シートで見た目をそろえる：`../../ai-video-production/references/character-consistency-pipeline.md`）②**顔を映さない実写寄り**（手元・後ろ姿・並んで同じ方を見る構図だけ。既定）。②は人の不自然さが出にくく、静物の接写と相性がよい。どちらでも実在の人の顔は作らない |
| 仕事の場面 | その会社の実際の仕事が分かる場面（手元で） |
| 文字 | 画面内の文字は最小限。最後の一言とロゴのみ。書体 |
| 使わないもの | 陳腐な記号（光る未来都市・握手・右肩上がり等）、実在の作家・スタジオ名、他者の著作の絵 |

**画風の固定文（style_lock）**を英語で1つ書き、**全カットの画像・動画プロンプトの先頭に同じ文言で入れる**（キャラの見た目の固定文と同じ扱い。言い換えない）。例：
```
Quiet cinematic still-life, macro close-up, soft morning window light from the side,
shallow depth of field, natural textures of water, glass, stone, paper and wood,
paper-white and ink-black palette with a single accent color, calm and unhurried,
no people's faces, no text overlays
```
- これを全カットの先頭に入れると、机・小物・窓の光が最後までそろう。同じ机・同じ小物・同じ窓の光を何度も出すと、カットが変わっても世界がつながって見える。
- 冒頭と最後に同じ絵を置くと、短い版ではループにもなる。

## 5. 音の決まり

- ナレーション：第一希望（本人の声 等）と代替（AIの声の性格）、場面ごとの演技の指示。
- 音楽：楽器・テンポ・ボーカルなし。止める場所。
- 演技の指示を場面ごとに書く（例：冒頭＝深夜にひとりで考えている人にそっと話しかけるように、少し間を置いて／中盤＝隣で同じものを見ながら、説明しない／終盤＝声を張らず確かに、最後の一言の前に間）。
- 耳のロゴ（音のロゴ）：モチーフの音から作る短い音。本編は約2秒、**SNS 向けの短い版は1.5秒以内**。全動画の最後に置く。
- 山場の直前で音楽を止め、効果音だけにする瞬間を1か所決める（本編は約3秒、短い版は1秒以内）。

## 6. 流れの骨格

`beats-and-sound.md` の9ビートに、方向案の映像を当てはめた表（# / 映像 / 伝えること）。短尺版はどのビートを残すか。

## 7. 相手に確かめたいこと

相手が答えられる具体的な問い（選択肢・名前・データで答えられるもの）にする。例：どの案が一番らしいか／冒頭の一言はどれか／声は本人かAIか／コーポレートカラーとロゴデータ／最初に使う場所／映してよい実際の現場・制作物。

## 8. 制作用の設定（仮）

`kit.yaml` 形式で、色・書体・画風・声・音楽・尺・アスペクト比を書く。最低限次の項目を埋める：
```yaml
concept: <最後の一言>
metaphor: <採用した比喩>
people: anime | faceless-real
palette: {bg: "#F5F1E8", ink: "#1E1E1E", accent: "要確認"}
font: {telop: "<書体>"}
style_lock: "<画風の固定文。全カットのプロンプト先頭にそのまま入れる>"
voice: <本人／AIの声の条件>
music: {main: "<楽器と温度>", drop: "<音を止める場面>", sting: "<音のロゴ>"}
length: ["90-120s", "30s", "5-10s"]
aspect: "16:9"
```

## 9. 作ってみて分かったこと（短い版・縦型に切り出すとき）

- 横長の映像に小さな明朝の字幕は、スマホの縦画面では読めない。縦型では字幕を大きく、1行15字前後にする。
- 最後の無音のロゴ画面が4秒を超えると SNS では長すぎる。音のロゴは1.5秒以内、最後の静止は1秒程度にする。
- 手を細かく動かす（字を書く）カットは崩れやすい。下書きで確かめる。
