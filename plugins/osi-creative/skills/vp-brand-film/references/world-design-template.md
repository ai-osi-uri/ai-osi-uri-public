## 0. 誰に・なぜ・何を

| | |
|---|---|
| 誰に | 依頼主（決める人）と、映像を最後に見る人 |
| なぜ | この映像で何を確かめたい・何を伝えたいか |
| 何を | 本編の尺・ナレの有無・短尺版の有無。この資料が台本と全カットの元になること |

## 3. 世界観の核：方向案3つ

どの案も同じ芯（例：見えないものが少しずつカタチになる）を描き、**たとえだけを変える**。
各案に：たとえ／推す理由 or 良い点／注意（AIで作ると陳腐になりやすい点・作法の誤りが出やすい点など）。

## 4. 見た目の決まり

| 項目 | 決まり |
|---|---|
| 色 | 地の色・墨の色・差し色1色（コーポレートカラーが分かれば置きかえる） |
| 光 | 時間帯・光の向き・山場に向けた変化 |
| 質感 | 写実か、画風か。主役の素材 |
| カメラ | 固定／ゆっくり寄る 等。使わない動き |
| 人物 | 顔は映さない（手元・後ろ姿・遠景） |
| 仕事の場面 | その会社の実際の仕事が分かる場面（手元で） |
| 文字 | 画面内の文字は最小限。最後の一言とロゴのみ。書体 |
| 使わないもの | 陳腐な記号（光る未来都市・握手・右肩上がり等）、実在の作家・スタジオ名、他者の著作の絵 |

**画風の固定文**（全カットの指示の先頭に入れる・英語）を1つ書く。

## 5. 音の決まり

- ナレーション：第一希望（本人の声 等）と代替（AIの声の性格）、場面ごとの演技の指示。
- 音楽：楽器・テンポ・ボーカルなし。止める場所。
- 耳のロゴ：モチーフの音（約2秒）。全動画の最後に置く。

## 6. 流れの骨格

`beats-and-sound.md` の9ビートに、方向案の映像を当てはめた表（# / 映像 / 伝えること）。短尺版はどのビートを残すか。

## 7. 相手に確かめたいこと

相手が答えられる具体的な問い（選択肢・名前・データで答えられるもの）にする。例：どの案が一番らしいか／冒頭の一言はどれか／声は本人かAIか／コーポレートカラーとロゴデータ／最初に使う場所／映してよい実際の現場・制作物。

## 8. 制作用の設定（仮）

`kit.yaml` 形式で、色・書体・画風・声・音楽・尺・アスペクト比を書く。
