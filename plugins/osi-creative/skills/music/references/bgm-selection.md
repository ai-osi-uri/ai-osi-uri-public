# BGM選定（特にショート動画／9:16・〜60秒）

ショート動画（TikTok / Reels / YouTube Shorts、縦9:16・〜60秒）は **BGMが命**。
AI生成（Stable Audio）でも作れるが、"今っぽさ・流行り感" を出したいときは、
**有名YouTuberが実際に使っているフリーBGM（DOVA-SYNDROME 等）から選ぶ**方が刺さる。
このファイルは「調査 → リスト化 → 商用可否確認 → 選定 → 取得 → ミックス」の定型手順。

## いつこの方式を使うか

- ショート（9:16・〜60秒）、切り抜き風、Vlog風、密着ドキュメンタリー、SNS拡散狙い
- ユーザーが「流行りのBGM」「YouTuberが使ってる感じ」「バズってる曲」を求めたとき
- 長尺の企業/IR動画で世界観を作り込みたいときは Stable Audio 生成の方が合うことも多い（使い分け）

## 重要な前提：著作権

- **ヒット曲（チャート曲）は商用利用ほぼ不可**。TikTok/IGのアプリ内ライブラリは「個人・非商用」のための包括契約。
  ビジネス用途（クリニック・店舗の宣伝等）はアプリ内の商用ライブラリに限定され、ヒット曲は入っていない。
  音源を焼き込んでアプリ外配信すると**原盤権侵害**。→ 流行りの"質感"は **フリー音源 or AI** で再現する。
- **DOVA-SYNDROME**：背景音楽としての**商用利用OK・クレジット不要・フェード等の加工OK**（[ライセンス](https://dova-s.jp/contents/license)）。
  ただし配信もされている曲はYouTubeで稀に Content ID 申し立てが来る → 正規利用なので異議申立で解除可能。
- **魔王魂**：商用O.K.だがクレジット条件あり（要規約確認）。**甘茶の音楽工房**：商用・非商用OK。
- **クラシック**（カルメン等）：作曲はPDだが**演奏音源**の権利は別 → PD/CCの音源を使う。

## 調査→選定の手順

1. 参照したいジャンル/YouTuberを決める（美容/Vlog/切り抜き/感動 など）。
2. WebSearch で「<YouTuber名> 使用 BGM 曲名 フリー」「YouTuber よく使う BGM DOVA」等を調べる。
   DOVAの [YouTube動画内BGM検索](https://dova-s.jp/bgm/youtube-search) も有効。
3. 各曲の **配信元 / 商用可否 / クレジット要否 / Content IDリスク** を確認。
4. 動画の **尺・感情曲線・縦横** に合わせて候補を3つに絞り、ユーザーに提示して選ばせる。
5. 取得 → ミックス（下記）。

## 取得レシピ（Web音源は直DLできないため Claude in Chrome 経由）

サンドボックスからWeb上のmp3を直接ダウンロードはできない。Chrome経由で取得して移送する：

1. `mcp__Claude_in_Chrome__navigate` で DOVA等のダウンロードページへ。
2. ダウンロードボタンを `find`→`computer left_click`（※「Extension for Mac」等の広告ボタンは押さない）。
3. ファイルはユーザーの `~/Downloads` に落ちる。
4. `mcp__cowork__request_cowork_directory` で `~/Downloads` をマウント → `cp` で案件フォルダ／作業フォルダへ。
5. ミックス（下記）。

## ミックス規則（今回の学び：途切れ防止）

- **曲尺 ≥ 動画尺の曲を選ぶ**（`stream_loop` のループ継ぎ目は"途切れ"に聞こえる）。
  尺が足りない曲しかない場合はループ点を **acrossfade** で繋ぐ。
- **末尾は2秒かけて fade out**（ブツ切り防止）。冒頭は 1.2秒 fade in。
- 音量 **volume=0.16〜0.18**（ナレ／実音声の下に敷く）。会話の上に被る箇所はさらに下げる。
- 例（曲が動画尺以上の場合・ループなし）：

```bash
DUR=$(ffprobe -v error -show_entries format=duration -of csv=p=0 voice.mp4)
FOUT=$(awk "BEGIN{print $DUR-2.2}")
ffmpeg -y -i voice.mp4 -i BGM.mp3 -filter_complex \
 "[0:a]volume=1.0[a0];\
  [1:a]atrim=0:$DUR,asetpts=N/SR/TB,volume=0.17,afade=t=in:st=0:d=1.2,afade=t=out:st=$FOUT:d=2.2[b];\
  [a0][b]amix=inputs=2:duration=first:dropout_transition=0[a]" \
 -map 0:v -map "[a]" -t "$DUR" -c:v copy -c:a aac -ar 48000 final.mp4
```

- 確認：末尾1秒の mean_volume が十分小さい（例 -45dB以下）か `volumedetect` でチェックして"途切れ"が無いことを担保。

## ユーザーへの出し方

- まず候補を3曲、用途に合わせて提示（聴き比べ用に16秒プレビューを作ると親切）。
- ライセンス（商用可否・クレジット・Content ID）を一言添える。
- 「ヒット曲は使えない理由」を聞かれたら、上の著作権の要点を簡潔に説明する。
