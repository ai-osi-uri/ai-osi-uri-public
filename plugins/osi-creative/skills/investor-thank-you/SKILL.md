# 出資者お礼メッセージ生成スキル

AI OSI URI の代表（渚さん）が出資者に送るお礼メッセージを、相手に合わせてカスタム生成する。

## ワークフロー

### 1. 情報収集（最小限に）

ユーザーから以下を把握する。会話の文脈に含まれていれば改めて聞かない。

**必須：**
- 相手の名前（○○さん）

**文脈から推測、不明なら聞く：**
- 関係性（ビジネスのみ／コンサル等でもお世話に／個人的に近い・友人に近い）
- トーン（フォーマル／バランス型／フレンドリー）
- 出資の文脈（純粋な投資／応援・共感ベース／ご縁・紹介経由）

推測のコツ：
- 「コンサルでお世話に」「一緒に仕事してる」→ 関係性が深い、バランス型〜フレンドリー
- 「先輩」「目上の方」「社長」→ フォーマル寄り
- 「友達」「仲間」「昔からの付き合い」→ フレンドリー
- 特に手がかりがなければ「バランス型 × ビジネスのみ × 純粋な投資」をデフォルトにする

### 2. メッセージ生成（2〜3パターン）

以下のテンプレート構造をベースに、毎回2〜3パターンを生成する。パターンごとにトーンや表現を変え、ユーザーが好みのものを選べるようにする。

#### テンプレート構造

メッセージは以下の6パーツで構成される。各パーツを相手に合わせて組み替える。

**① 書き出し**

| トーン | 文例 |
|---|---|
| フォーマル | いつも大変お世話になっております。 |
| バランス型 | いつもお世話になっております。 |
| フレンドリー | いつもありがとうございます。 |

**② お礼の一文**

| トーン | 文例 |
|---|---|
| フォーマル | この度はご出資いただきまして、誠にありがとうございます。 |
| バランス型 | この度はご出資いただき、本当にありがとうございます。 |
| フレンドリー | この度は出資いただき、ありがとうございます！ |

**③ 関係性の一文（あれば追加）**

| 関係性 | 文例 |
|---|---|
| ビジネスのみ | （省略可） |
| コンサル等でもお世話に | コンサルティングでいつも近くで支えてくださっている〇〇さんに、このような形でもご信頼をお寄せいただけたこと、心より感謝申し上げます。 |
| 個人的に近い・友人に近い | いつも近くで見ていてくださっている〇〇さんからのご出資、本当に嬉しく、じんわりと胸に響いています。 |

この部分は相手との具体的なエピソードや関わり方が分かっていれば、テンプレートに頼らず自然な言葉で書く方がずっと良い。ユーザーが会話の中で「○○で一緒に…」のような情報を出していたら、それを活かす。

**④ 出資の文脈に合わせた一文**

| 文脈 | 文例 |
|---|---|
| 純粋な投資として | いただいたご期待に対して、しっかりと結果でお応えすることが私の責務と捉えております。 |
| 応援・共感ベース | 〇〇さんが共感してくださった想いを、必ず形にしてみせます。 |
| ご縁・紹介経由 | ご縁をいただき、こうして応援していただけること、本当に力になります。 |

**⑤ 決意の一文**

| トーン | 文例 |
|---|---|
| フォーマル | 「ご判断は正しかった」と胸を張ってお伝えできるよう、結果にこだわり全力で事業を推進してまいります。 |
| バランス型 | 「あのとき信じてよかった」と心の底から感じていただけるよう、全身全霊で走り続けてまいります。 |
| フレンドリー | 一緒に面白いことを作り上げていけるよう、全力で突き進みます。 |

**⑥ 締め**

| トーン | 文例 |
|---|---|
| フォーマル | 引き続き、ご指導のほど何卒よろしくお願い申し上げます。 |
| バランス型 | 今後とも、どうかよろしくお願いいたします。 |
| フレンドリー | これからもよろしくお願いします！ |

### 3. 出力形式

パターンごとにラベルを付けて提示する（例：「A: 丁寧・感謝重視」「B: カジュアル・温かみ重視」「C: ビジネスライク・簡潔」）。

各パターンのラベルには、そのメッセージの特徴が一言で分かる説明を付ける。ユーザーが見比べて直感的に選べるようにする。

### 4. 微調整への対応

ユーザーが「もっと温かく」「もう少し硬めに」「この部分を変えて」と言ったら、選ばれたパターンをベースに調整する。テンプレートの枠にこだわらず、ユーザーの感覚に寄り添って柔軟に対応する。

## 大事なこと

このスキルの目的は、渚さんが出資者一人ひとりに心のこもったメッセージを効率よく送れるようにすること。テンプレート感が出てしまっては本末転倒なので、以下を意識する：

- 同じ人に何度も同じフレーズを使わない。過去に生成したメッセージがあれば、表現を変える
- 相手の名前や具体的なエピソードを自然に織り込む
- 「定型文を埋めた」感じではなく、「この人のために書いた」感じを大切にする
- 日本語のビジネスメッセージとして自然な敬語・丁寧語を使う
