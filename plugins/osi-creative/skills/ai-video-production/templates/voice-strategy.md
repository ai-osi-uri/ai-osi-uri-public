# Voice Strategy Guide（ナレーターvoice 選択戦略）

ナレーション品質を**ボイス選択 × モデル × 感情タグ**で最大化するためのガイド。OKWEB×JINEN動画制作のv1〜v10で確立した知見。

---

## 1. なぜ Voice 選択が最重要か

ElevenLabsには大きく**2種類のvoice**があります。それぞれ**全く違う最適化が必要**：

| カテゴリ | 例 | 特徴 | 必要プラン |
|---|---|---|---|
| **A. 多言語汎用voice** | Sarah, Adam, Rachel, Bella | 英語話者がベース、日本語も可。**長音脱落・小書き分離**などの癖あり | Free OK |
| **B. ネイティブクローンvoice** | GENEL voice 等 | 日本人の実音声からクローン、**自然な日本語**。漢字読み判定にやや癖 | **Starter ($5/月)以上必須** |

**B（クローン）が圧倒的にナチュラル**だが、API利用にStarter以上が必要。
社内動画制作なら**Starterに即アップグレード推奨**（投資回収はすぐ）。

---

## 2. 推奨デフォルト

```
Voice    : GENEL voice (GxhGYQesaQaYKePCZDEC) ← またはチームメンバーのクローン
Model    : elevenlabs-v3 ★ 最新モデル、感情タグ対応
Stability: 0.35 〜 0.5（低いほど抑揚強）
Speed    : 1.0
感情タグ : シーン別に変える（次節）
```

GENELの商用利用可否は ElevenLabs Voice Library ページで確認。
社内動画なら**自社メンバーの声をクローン**が最終形（Creator+ プラン $22/月）。

## 3. 感情タグマップ（Eleven v3）

テキスト**先頭に角括弧**でタグを置くと、声の抑揚・温度感が変わる。

| タグ | 雰囲気 | 適用例 |
|---|---|---|
| `[calm]` | 落ち着き、信頼感 | 標準説明、IR、説明会 |
| `[thoughtful]` | 思慮深い、問いかけ | 問題提起、オープニング |
| `[serious]` | 重さ、問題意識 | 課題提示、リスク説明 |
| `[confident]` | 自信、強調 | サービス紹介、強み |
| `[hopeful]` | 期待、ビジョン | 未来、クライマックス |
| `[warm]` | 余韻、親しみ | クロージング |
| `[excited]` | テンション高め | 採用動画、商品紹介 |

### 12シーン標準マップ（IR/PR動画）

```
① 問題提起        → [thoughtful]
② 社会トレンド     → [calm]
③ 市場規模         → [calm]
④ 日本市場         → [calm]
⑤ 課題             → [serious]
⑥ サービスA強み    → [confident]
⑦ サービスB強み    → [confident]
⑧ 統合・コア       → [hopeful]
⑨ 成長モデル       → [calm]
⑩ 競争優位性       → [confident]
⑪ 未来             → [hopeful]
⑫ クロージング     → [warm]
```

### 用途別マップ

- **採用動画**：[excited]を多用、`[hopeful]`で締め
- **IR動画**：基本 `[calm]`+`[confident]`、未来 `[hopeful]`
- **商品紹介**：`[excited]`+`[confident]`、注意事項 `[serious]`

## 4. Voice タイプ別 テキスト最適化

### A. 多言語汎用voice（Sarah等）

**癖**：カタカナ長音「ー」を脱落、小書き「ャュョッ」を分離
**対策**：カタカナ強制＋二重母音

| 元 | 修正 |
|---|---|
| データ | デエタ |
| サービス | サアビス |
| プラットフォーム | プラットフォオム |
| ジネン | 々（じねん）★ふりがな括弧テクニック |
| 4,800万件 | ヨンセン ハッピャク マンケン（空白で分かち書き） |
| エンゲージメント | エンゲエジメント |

### B. ネイティブクローンvoice（GENEL等）

**癖**：自然な日本語が基本だが、**読みが複数ある漢字を独自判定**
**対策**：問題のある漢字を**ひらがな化**

| 元 | 修正 | 誤読パターン |
|---|---|---|
| 27年 | にじゅうななねん | にじゅうしち |
| 4,800万件 | よんせんはっぴゃくまんけん | 数字つぶれ |
| 最大級 | さいだいきゅう | さいだいしつ |
| 蓄え | たくわえ | あろえ |
| 力 | ちから | ちいら |
| AI | エーアイ | カイーアイ |
| 見える化 | みえるか | みえるはなし |
| OKWEB | オーケーウェブ | オーケーダブリューイービー（英字読み） |
| 2030年代 | にせん、さんじゅうねんだい | にせんじゃんじゅう |

### C. 共通ルール

- 助詞「は」は ひらがな で必ず（純粋ひらがなだと「ha」誤読）
- 中黒「・」は半角空白に置換
- 適切な読点「、」で読みリズムを作る

## 5. プラン別の使い分け

| プラン | 月額 | できること | 推奨用途 |
|---|---|---|---|
| Free | 無料 | 組込voice、月10K文字 | 個人プロト、Sarah等 |
| **Starter** | **$5** | **ライブラリvoice利用可、月30K文字** | **社内動画制作の標準** |
| Creator+ | $22 | 自分の声を Instant Clone × 10 | **チームの声を作る** |
| Pro | $99 | Professional Voice Clone | プロ用途 |

> **社内展開時の推奨**：
> 1. まず Starter で Library voice（GENEL等）を使う
> 2. 動画制作が本格化したら Creator+ で**社員の声をクローン**
> 3. これで「うちの社長の声でナレーション」が作れる＝最強の差別化

## 6. ベストプラクティス チェックリスト

新規動画制作の前に：

- [ ] 動画の用途・トーンに合うvoice/タグを決めた
- [ ] ElevenLabsプランがvoice要件を満たす（Starter以上）
- [ ] テキストはvoice型（A or B）に合わせて最適化
- [ ] 試作1本で読み・抑揚を確認した
- [ ] 並列投入（6本ずつ）で全シーン生成
- [ ] 全シーン尺をffprobeで計測してSRTに反映

## 7. トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| `402 paid_plan_required` | Free tier でライブラリvoice使用 | Starterにアップグレード |
| 漢字の読み崩れ | クローンvoiceで漢字判定ミス | 該当箇所をひらがなに |
| 長音「ー」が消える | 多言語汎用voiceの癖 | 二重母音化（デエタ等） |
| 抑揚がフラット | stability高すぎ | 0.35〜0.5に下げる |
| 抑揚が暴れる | stability低すぎ | 0.6〜0.7に上げる |

詳細は `references/pitfalls.md`、`templates/narration-rules.md` を参照。
