# ナレーション（TTS）誤読対策ルール集

**ElevenLabs（v2 / v3、組込/クローン両voice）で日本語ナレを生成する際の誤読パターンと対策。**

OKWEB事例での試行錯誤（v1〜v24）で確立。最初からこれを守れば誤読は最小化される。

> 📚 **先に読むべき**：`templates/voice-strategy.md` でvoice選択（多言語汎用 vs クローン）と感情タグマップを決めてから、本ファイルでテキスト最適化する。

---

## 0. 大原則：voice 型でルールが逆になる

| voice タイプ | 例 | テキスト最適化方針 |
|---|---|---|
| **A. 多言語汎用voice** | Sarah, Adam, Rachel, Bella等 | **カタカナ強制 + 二重母音 + 数字分かち書き** |
| **B. ネイティブクローンvoice** | GENEL voice (GxhGYQesaQaYKePCZDEC)等 | **自然な日本語 + 読み複数の漢字をひらがな化** |

**B（クローン）はElevenLabs Starter以上のプラン必須**（API利用に Library voice 権限が必要）。

このファイルの§1〜§7は **voice 型A** 向け、§8 は **voice 型B** 向け、§9 は共通ルール。

## 基本方針

✅ **漢字＋カタカナ＋ひらがな のハイブリッド表記が最強**
❌ 純粋ひらがな は **絶対NG**

## ① 文字種の使い分け

| 種類 | 表記 | 例 |
|---|---|---|
| 和語・名詞 | **漢字** | 世界、巨大、価値、組織、貢献 |
| 助詞・接続詞 | **ひらがな** | を、が、は、に、の |
| 専門語・外来語 | **カタカナ** | コミュニティ、データ、エンゲージメント |
| 英略語 | **カタカナで音写** | ISO → アイエスオー、AI → エーアイ |
| 数字 | **半角＋カタカナ単位** | 6兆円、2024年、3つ |
| 数字（複雑） | **カタカナ＋空白** | 4800万件 → ヨンセン ハッピャク マンケン |

## ② 強制発音テクニック

### A. 助詞の「は」が ha と読まれる
**症状**：「世界は」 → "せかい・ha"
**対処**：漢字を残す（×「せかいは」 ○「世界は」）

### B. 小書き仮名の脱落
**症状**：「みっつ」→「みつつ」、「きょだい」→「きよだい」
**対処**：カタカナ化 or 漢字
- ×「みっつ」 ○「ミッツ」 or 「3つ」
- ×「きょだい」 ○「キョダイ」 or 「巨大」

### C. 数字の桁誤読
**症状**：「4,800万件」→「よんじゅう・はっぴゃく」（4桁が4・800と読まれる）
**対処**：カタカナ＋空白で分かち書き
- ×「4,800万件」 ○「ヨンセン ハッピャク マンケン」

### D. 長音「ー」のスキップ
**症状**：「プラットフォーム」→「プラットフォム」
**対処**：二重母音表記
- プラットフォーム → **プラットフォオム**
- サービス → **サアビス**
- データ → **デエタ**
- スーパー → スウパア（必要に応じて）
- **エンゲージメント → エンゲエジメント**（v6で発見）

### D-2. 「エー○」が「イー○」に化ける
**症状**：「エーアイ」→「イーアイ」、「エースケース」→「イースケース」
**原因**：長音「エー」の「エ」が脱落し「イー」と誤認識される
**対処**：二重母音表記で「エ」を強調
- ×「エーアイ」 → **○「エエアイ」**
- ×「エース」 → **○「エエス」**

### D-3. 余計な長音が挿入される
**症状**：「グラティカ」→「グラティーカ」（ティの後ろに勝手に長音）
**原因**：小書き「ィ」を「ティー」のように長音化して読む
**対処**：小書き仮名を消すか、字面を簡素化
- ×「グラティカ」 → **○「グラチカ」**（ィを消す）
- ×「ティアラ」 → ○「チアラ」（必要に応じて）

### D-4. カタカナ短語が無駄に伸ばされる（v7で発見）
**症状**：「ジネン」→「ジイネン」（ジの後ろに余計な「イ」が挿入）
**原因**：短いカタカナ固有名詞で、エンジンが各音を伸ばし気味に発音
**対処**：ひらがな表記に切り替える（カタカナの「読みパターン」回避）
- ×「ジネン」 → **○「じねん」**
- ×「カイト」 → ○「かいと」
- 一般的に2〜3音節のカタカナ固有名詞は ひらがな の方が安定する場合がある

### D-5. 固有名詞の長音「ー」脱落（v7で発見）
**症状**：「オーケーウェブ」→「オーケウェブ」（2つ目の「ケー」が短くなる）
**原因**：D と同じ長音スキップだが、固有名詞では特に頻発
**対処**：すべての長音を二重母音化
- ×「オーケーウェブ」 → **○「オオケエウェブ」**
- ×「ジョージ」 → ○「ジョオジ」（必要に応じて）
- ×「フィービー」 → ○「フィイビイ」

### D-6. 短い固有名詞の頑固な長音化 — 「々（ふりがな）」テクニック（v8/v10で発見）
**症状**：「ジネン」「ジネ」のような2〜3音節の固有名詞で、どんなスペル変更でも「ジー...」と長音化される
- ×「ジネン」 → ジーネン
- ×「じねん」 → ジーネン
- ×「Jinen」 → キネン（英語モード化失敗）
- ×「ジネン」+stability=0.9 → ジーネン（変わらず）

**原因**：エンジンが特定パターンの2-3音節カタカナで、**自動的に最初の音を長音化する強い癖**を持つ。スペル変更だけでは突破不能。

**対処**：**「漢字（ふりがな）」フォーマット**を活用。ふりがな部分のイントネーションは正しく発音されるという特性を利用。
- ×「じねん」 → ジーネン
- ×「自然(じねん)」 → "しぜん・じねん"（漢字も読まれる）
- ✅ **「々（じねん）」** → ふりがな部分が活きて「ジネン」に近くなる

**ベストプラクティス**：
- 漢字部分は **「々」（くりかえし符号）** がベスト（ほぼ無視される）
- それでも「々（ふりがな）」と書くと、エンジンは「（）内を発音指示として参照」する挙動が確認されている

**応用パターン**：
| 単語 | 通常 | 修正 |
|---|---|---|
| ジネン | × | **々（じねん）** |
| ヤマ | × | **々（やま）** |
| リン | × | **々（りん）** |
| ナナ | × | **々（なな）** |

**注意**：
- 文中の他の単語にも適用すると「々」がノイズになるリスクあり
- まず通常スペルで試して、誤読する単語にだけこの手法を使う
- ふりがな部分は ひらがな で書く（カタカナだと長音化のリスクが残る）

### E. 「・」が「あら」と読まれる
**症状**：「コミュニティ・プラットフォーム」 → "コミュニティ・あら・プラットフォーム"
**対処**：「・」を**半角空白**に置換
- 「コミュニティ プラットフォオム」

### F. 漢字の同音異義誤読
特定漢字でランダムに違う読みになる。読まれた音が違ったら、その単語をカタカナ化。
- 「壁」→「カベ」
- 「測れる」→「ハカレる」
- 「世の中」→「ヨノナカ」
- 「蓄え」→「タクワエ」
- 「読み解き」→「ヨミトキ」
- 「類を見ない」→「ルイを見ない」
- 「境界」→「キョウカイ」
- 「行き交う」→「イキカう」
- 「最も」→「モットモ」（「もとも」誤読の対処）
- 「見える化」→「ミエルカ」
- 「情報開示」→「ジョウホウカイジ」（「かいし」誤読の対処）

## ③ 数字読みのテクニック

### 普通の数値
- 「2024年」「6兆円」「14兆円」「27年」 → 半角数字＋単位、そのまま
- 「14兆円」が「げん」と読まれたら → ひらがな「じゅうよんちょうえん」

### 複雑な大きな数
- 「4,800万件」 → カタカナ分かち書き **「ヨンセン ハッピャク マンケン」**
- 「12億」 → 「ジュウニオク」
- 「100万人」 → 「ヒャクマンニン」

### 単位だけ
- 「規模」 → そのまま
- 「以上」 → そのまま

### 一桁ずつ読ませたい数（ID、年号、製品番号）
**例**：ISO 25554 を「アイエスオー、ニーゴーゴーゴーヨン」と読ませたい
- 「ISO 25554」→ **「アイエスオー、ニーゴーゴーゴーヨン」**（コンマで区切り）

- [ ] 文章全部がひらがなになっていないか

## ⑧ ネイティブクローンvoice用ルール（v8〜v24で確立）

GENEL voice（`GxhGYQesaQaYKePCZDEC`）等のネイティブクローンを使う場合は、**§1〜§7のルールが逆方向に作用する**。クローンは日本語が自然なので、カタカナ強制は不要だが、漢字の読み判定が独自で行われるため、**読みが複数ある漢字をひらがな化**する必要がある。

### ⑧-1. 推奨セッティング

```typescript
generate_speech({
  text: "[calm] ...",                   // 感情タグを先頭に
  voice: "GxhGYQesaQaYKePCZDEC",        // GENEL voice_id
  model: "elevenlabs-v3",               // 最新モデル
  speed: 1.0,
  stability: 0.35,                       // 抑揚強め
})
```

### ⑧-2. クローンvoice 特有の誤読パターン

| 元の表記 | 誤読 | 修正 |
|---|---|---|
| 27年 | にじゅう**しち**ねん | **にじゅうななねん** |
| 4,800万件 | 数字つぶれ・はっぴいやく | **よんせんはっぴゃくまんけん** |
| 最大級 | さいだい**しつ** | **さいだいきゅう** |
| 蓄え | **あろえ** | **たくわえ** |
| 力（ちから） | **ちいら** | **ちから** |
| AI | カイーアイ | **エーアイ** |
| 見える化 | みえる**はなし** | **みえるか** |
| OKWEB | オーケーダブリュー・イー・ビー | **オーケーウェブ**（必ずカタカナ化） |
| 2030年代 | にせん**じゃん**じゅう | **にせん、さんじゅうねんだい**（読点で分離） |

### ⑧-3. クローンvoice ルール一覧

✅ 推奨：
- 漢字の読みが複数ある単語 → ひらがな化
- 英字の固有名詞 → カタカナ化必須（GENELは英字をアルファベット読みする）
- 大きな数字 → ひらがな大数字（よんせんはっぴゃくまんけん）
- 数字＋年代の連結（2030年代）で「さん→じゃん」化する場合 → 読点で区切る
- 感情タグでトーンを制御（[calm]/[thoughtful]/[hopeful] 等）

❌ やらない：
- カタカナ強制（デエタ、サアビス等）→ クローンには逆効果
- 二重母音（プラットフォオム）→ 不要、自然な「プラットフォーム」で読まれる
- 々（ふりがな）テクニック → 不要、シンプルにひらがなで書く

### ⑧-4. v3 モデル + 感情タグの効果

`templates/voice-strategy.md` §3 参照。テキスト先頭にタグを置くだけで抑揚・温度感が変わる。

```text
[thoughtful] 人の価値は、正しく評価されているでしょうか。…
[hopeful] 私たちは、企業から、自治体へ、そして個人へ。…
```

## ⑨ どちらのvoiceでも有効な共通ルール

- **「は」の助詞**は ひらがな で必ず（純粋ひらがな本文だと「ha」誤読）
- **「・」は半角空白**に置換
- **句読点を細かく刻む**（自然なリズム）
- **長文は短く区切る**（イントネーション崩れを防ぐ）
- **ふりがな括弧** `（よみ）` は v2 だと「両読み」リスクあり、v3 + クローン voice では不要
