# プロンプトテンプレ：アニメ調（ジブリ風）

ジブリ風の温かい手描きアニメ。OKWEBの「ありがとう」のテーマと相性◎。

## 共通アンカーフレーズ

すべてのプロンプトの**冒頭**に必ず含める：

```
Studio Ghibli style 2D hand-drawn anime animation,
warm watercolor and gouache painted background,
```

すべてのプロンプトの**末尾**に必ず含める：

```
painterly visible brush strokes,
color palette of cream white, soft mint green,
gentle sky blue and warm peach,
slow gentle camera movement,
peaceful warm mood,
traditional 2D Japanese animation aesthetics,
hand-painted illustration look,
no text, no realistic CG, no photorealistic
```

## 注意：IPフィルタ回避

「Studio Ghibli」が著作権フィルタに引っかかってForbiddenが出ることあり。
代替アンカー：
```
Warm Japanese hand-drawn 2D anime animation,
warm watercolor and gouache painted background,
```

## 推奨モデル

`veo3-fast`（コスト・品質のバランス）

## キャラクターの扱い

OKWEBのケースでは「**顔のあるシンプルキャラ**」を採用：

```
... a young woman with soft round Ghibli-style anime face and gentle expressive eyes,
... classic Ghibli anime facial features with simple expressive eyes,
... small group of diverse anime characters with soft round faces and gentle warm smiles,
```

シルエットだけだと暗く重く見える。表情ありのキャラの方が温かい。

## 共通ボキャブラリ

- 配色：cream white, soft mint green, gentle sky blue, warm peach
- 光：natural sunlight, warm golden, soft afternoon light
- 質感：painterly brush strokes, hand-painted, watercolor
- カメラ：slow gentle inward push / dolly / aerial glide
- ムード：peaceful, warm, contemplative, hopeful, togetherness

## やってはいけない

- "cinematic 4K" を強調しすぎる（CG寄りになる）
- "realistic" は厳禁
- 暗いトーン（ジブリ感が消える）
- 複雑な技術用語（ホログラム、データライン等）→ 抽象化のしすぎ
