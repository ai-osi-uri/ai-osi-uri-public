# 各フェーズのチェックリスト

スキル発動から納品までの確認項目。

---

## 着手前

- [ ] fal-video-mcp が Cowork に登録されている（`list_models` で13ツール確認）
- [ ] fal.ai に最低 $10 のクレジットがある
- [ ] Drive 出力先（FAL_OUTPUT_DIR）が設定済み
- [ ] `pitfalls.md` を読み返した
- [ ] `../../narration/SKILL.md` を読み返した

## Phase 0（ヒアリング）

- [ ] 用途（IR/採用/PR/営業）を確認した
- [ ] 想定尺を確認した
- [ ] スタイル（アニメ/実写/コーポレート/ライフスタイル）を確認した
- [ ] ナレーション声を確認した
- [ ] 字幕の有無・スタイルを確認した
- [ ] BGMの有無を確認した
- [ ] アスペクト比を確認した
- [ ] 既存台本があれば読み込んだ

## Phase 1（台本構成）

- [ ] 起承転結が成立している
- [ ] 各シーンの主旨が1〜2文で要約できる
- [ ] シーン尺の合計が想定尺の80〜100%に収まる
- [ ] 専門用語・横文字が必要最小限
- [ ] ユーザーが台本を承認した

## Phase 2（ビジュアル方向性）

- [ ] スタイル候補3つ提示した
- [ ] 配色・カメラ・主役（人物/環境）を確定した
- [ ] ユーザーが方向性を承認した

## Phase 3（プロンプト設計）

- [ ] 12シーン分のプロンプトが揃っている
- [ ] スタイルアンカー（"Studio Ghibli" / "Documentary cinematic" 等）が一貫している
- [ ] 配色キーワードが各プロンプトに含まれている
- [ ] no text overlays が含まれている

## Phase 4（試作）

- [ ] **試作シーンは2本まで**（コスト管理）
- [ ] 試作完了後、ユーザーに確認した
- [ ] 必要なら方向修正した
- [ ] 「このまま進める」の明示的承認を得た

## Phase 5（一括生成）

- [ ] 5本ずつバッチで投入した（Forbidden回避）
- [ ] バッチ間に10秒待機した
- [ ] Forbidden発生時は30秒待機 → 1本ずつ再投入した
- [ ] 全12本のジョブIDを記録した
- [ ] 全ダウンロード完了を確認した

## Phase 6（ナレーション）

- [ ] ナレ原稿は**クリーンな漢字かな混じり**（字面を壊していない／字幕と同一テキスト）
- [ ] `jp_yomi_check.py` で誤読を検出し、要レビューを消し込んだ
- [ ] 固有名詞・英字・複数読み漢字を glossary CSV → `.pls` に反映した
- [ ] 発音辞書を `create_pronunciation_dictionary` で登録し、生成時に指定した（最大3件）
- [ ] 声は日本語ネイティブ（既定 Konoha）／モデルは `elevenlabs-v3`
- [ ] 感情タグを12シーンの標準マップに沿って付けた
- [ ] 試作1本で読み・抑揚を確認してから本番を回した

> 詳細は `../../narration/SKILL.md`。旧方式（カタカナ強制・二重母音化）は使わない。

## Phase 7（SRT）

- [ ] ナレーション実時間を測った（ffprobe）
- [ ] 文字数比例でタイミング配分した
- [ ] 字幕テキストはナレ原稿と同一（v2 は同じクリーンテキストを共用できる）
- [ ] 各エントリ 15〜30文字に収まっている

## Phase 8（ffmpeg合成）

- [ ] **/tmp で作業**している
- [ ] PTS factor = target / source_video_duration で計算
- [ ] target = max(narration, source_video) + 0.3
- [ ] 全シーン合成完了
- [ ] concat 完了
- [ ] BGM ミックス完了（volume=0.18、fade in 1.5s, fade out 3s）
- [ ] 字幕焼き込み完了
- [ ] **長時間ffmpegは nohup でバックグラウンド実行**
- [ ] /tmp → Drive へ cp、sync; sleep 2 で確実に書き出し

## Phase 9（納品）

- [ ] final.mp4 が再生可能（moov atom OK）
- [ ] 3種類の出力（subs/no_subs/no_bgm）を提示した
- [ ] subtitles.srt も提示した
- [ ] 累計コストを表示した
- [ ] 次のアクション候補（特定シーンの作り直し、9:16版、等）を提示した

---

## 失敗時のリカバリ

| 失敗 | 対処 |
|---|---|
| 動画の品質がイマイチ | 該当シーンだけ再生成（プロンプト調整 or モデル変更） |
| ナレーションの誤読 | 発音辞書に正読みを追記して該当シーンだけ再生成 |
| ffmpeg ファイル破損 | /tmp で再ビルド |
| Forbidden 連発 | 30秒〜1分待機、1本ずつ再投入 |
| クレジット切れ | ユーザーにチャージ要請 |
