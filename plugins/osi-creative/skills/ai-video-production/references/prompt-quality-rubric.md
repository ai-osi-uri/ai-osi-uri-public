# プロンプト品質ルーブリック（提示前の自己採点ゲート）

各メソッド（vp-character-action / vp-moveboard / vp-corporate-narrated）が書いたプロンプトを、
**ユーザーに提示する前に**このルーブリックで自己採点する。`vp-core` STEP 1 の承認ゲートの直前に必ず通す。
proposal-self-review の動画版＝「自分が最も厳しいレビュアーになって、自分のプロンプトを叩いてから出す」。

## 使い方
1. 起草したプロンプトを下の該当チェックで採点（各項目 ✅/❌）。
2. **MUST が1つでも ❌ なら、提示せずに直す**（直して再採点）。SHOULD は ❌ を1行で理由付けできるなら可。
3. 合格したら、プロンプト＋「自己採点で確認した点」を添えてユーザーに提示（承認ゲートへ）。

---

## 共通 MUST（全タイプ）
- [ ] **目的適合**：このプロンプトで「依頼の狙い（用途・媒体・尺）」が達成できるか。盛りすぎ/外しが無いか。
- [ ] **ネガティブ**：画面内テキスト/ロゴ/透かしが不要なら `no text, no logos, no watermarks` を明記。
- [ ] **モデル整合**：使うモデルとプロンプトの相性（迫力アクション=Seedance一発、複数人物=Kling、環境=Veo Fast）。
- [ ] **コスト/尺の現実性**：尺・枚数・本数がコスト見込みと合うか（試作を挟む前提か）。
- [ ] **権利**：実在の人物・既存IP・現存作家作品を勝手に再現していないか（作例はオリジナル/PD/自前）。

## vp-character-action（A/B/C）
- A（キービジュアル）MUST：[ ] シグネチャ特徴を**具体列挙**（色・素材・小物まで） [ ] 構図/カメラ [ ] 世界観 [ ] 画風＋レンダ品質 [ ] 配色パレット
- B（設定シート）MUST：[ ] **No redesign 明記** [ ] A を参照に渡す前提（`extra.image_urls`） [ ] シート内容（ターンアラウンド/表情/アクション/パーツ/武器/パレット）網羅 [ ] NEGATIVE（背景・別キャラ無し）
- C（Seedanceビート列）MUST：[ ] 「入力画像のキャラ厳守・No redesign」 [ ] STYLE に fast-action/no idle posing [ ] **時間ビート**（0.0s〜…）でショット種別＋アクション＋カメラ [ ] クライマックス＋最後の決めポーズ
- C SHOULD：[ ] 起点は A（**B のシートを起点にしない** #17） [ ] **一発生成**（迫力用途で first-last-frame チェーンにしていない＝もっさり回避）

## vp-moveboard（カメラムーブ）
- MUST：[ ] 入力は **reference-to-video**（`bytedance/seedance-2.0/reference-to-video`。i2v で線を映り込ませない #17）
- MUST：[ ] ルート線は**コードで1本だけ**（AIに描かせない＝2本目防止）
- MUST：[ ] **番号＋動き説明ラベル**で速度/高さ/orbit を補足（線だけにしない）
- MUST：[ ] 動画プロンプトは**短い**（振り付けはムーブボードが担う／「線は出すな」）
- SHOULD：[ ] 大きな動き（フル360°等）はモーション予算を主役ビートに寄せた（#18 でカットしない）

## vp-corporate-narrated（台本/シーン/ナレ）
- MUST：[ ] 12シーンが**起承転結**で、各シーンの主旨が1〜2文で言える
- MUST：[ ] シーン別画像プロンプトが prompts-{style} の構造（SUBJECT/LIGHTING/CAMERA/SETTING/MOOD…/no text/4K）
- MUST：[ ] ナレが**TTS最適化**済み（感情タグ＋ narration-rules の誤読対策を該当箇所に適用、純ひらがな回避 #5）
- SHOULD：[ ] 試作（①と⑧の2本）を先に出す計画 [ ] BGMはショート/SNSなら定番フリー曲を検討

## 自己採点の出し方（ユーザーへの一文例）
> 「提示前にプロンプト品質ルーブリックで自己チェック済みです（特徴の具体列挙・No redesign・ビート構造・一発生成）。この内容で生成してよいですか？」

落ちやすい定番（実地）：A の特徴が抽象的／C を短尺チェーンにして"もっさり"／moveboard を i2v で渡して線が映る／ナレを純ひらがなにして助詞誤読。ここを重点的に見る。
